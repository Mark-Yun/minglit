# mds_docs — Minglit Design System Docs

Next.js 16 docs site for the Minglit Design System. Phase 1 ships 4 pages plus CSS codegen for mds_tokens.

## Pages

| Route | Content |
|-------|---------|
| `/` | Home — 4 section link cards |
| `/tokens` | Color/spacing/radius/typography catalog (auto-generated from `tokens/*.json`) |
| `/screens` | Wireframe gallery — Phase 1 has `profile_home` spec |
| `/flows` | Mermaid navigation diagrams for app_user and app_partner |

## Dev

```bash
# From apps/mds/docs/
npm install
npm run dev       # http://localhost:3003

# Rebuild tokens.css after token changes:
cd ../../../shared/packages/mds/tokens && npm run build
```

## Token Pipeline

`globals.css` imports `shared/packages/mds/tokens/lib/generated/tokens.css` (auto-generated by Style Dictionary).
After editing `tokens/*.json`, run `npm run build` in `shared/packages/mds/tokens/` to regenerate.

## Vercel Setup (TODO — Manual steps required)

This app is **not yet deployed** to Vercel. Before the CI deploy workflow will succeed, Mark must:

1. Go to [vercel.com](https://vercel.com) → New Project → Import `minglit` monorepo
2. Set **Root Directory** to `apps/mds/docs`
3. Framework: **Next.js** (auto-detected)
4. After project is created, copy the **Project ID** from Project Settings → General
5. Add the following GitHub Actions secret in the repo:
   - `VERCEL_MDS_DOCS_PROJECT_ID` = `<your-project-id>`
6. The `VERCEL_TOKEN` and `VERCEL_ORG_ID` secrets already exist (shared with other apps)

The deploy workflow job `deploy-mds_docs` in `.github/workflows/deploy.yml` will activate once the secret is set.

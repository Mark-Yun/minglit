Purpose & Context

Purpose 인증된 사용자가 추천 이벤트를 탐색하고, 관심 있는 이벤트 상세 페이지로 진입하는 앱의 중심 허브. 필터·태그·피드를 통해 원하는 모임을 빠르게 발견하도록 돕는다.
User journey Entry points: 로그인 성공 후 자동 이동 / 하단 탭 홈 버튼 탭 / 앱 재진입.
Exit points: 이벤트 카드 탭 → EventDetailPage / 검색 아이콘 → SearchPage / 알림 아이콘 → NotificationCenter / 프로필 아이콘 → MyPage / EventNowBar 탭 → phase별 routed sheet (check-in / matching / results / review) / 태그 칩 탭 → TagEventListPage.
Background 밍글릿의 핵심 가치인 "Verified Vibe" 탐색 경험을 실현하는 화면. 추천 피드는 pgvector 기반 개인화 알고리즘으로 구성되며, 필터(추천순·마감임박·가까운날짜)와 위치 기반 근거리 토글로 세밀하게 조정 가능. 오늘 참여 중인 이벤트가 있을 때에만 하단에 EventNowBar가 고정 표시되어 실시간 이벤트 상태를 빠르게 확인할 수 있다.
Frequency 매일 여러 번 — 앱의 기본 진입 화면.

EventNowBar anatomy (ⓔ)

홈 화면 하단에 떠 있는 64px persistent mini-bar. 사용자가 오늘 참여 중인 이벤트 (active event) 1건을 항상 화면 위에 노출. 좌측에 status dot — 가운데 이벤트 제목 — 우측에 status 텍스트 + 트레일링 (시간 또는 chevron). 활성 이벤트가 없으면 bar 자체가 화면에서 사라짐 (SizedBox.shrink). Scaffold의 bottomSheet 슬롯에 배치 → 스크롤 영역 위에 떠 있고 본문이 가려지지 않도록 피드 하단에 56+safeArea만큼 추가 padding.

EventNowBar 탭 → phase별 routed sheet

EventNowBar 탭 시 현재 EventNowBarState에 맞는 route을 push — 화면 하단에서 modal bottom sheet 형태로 올라옴 (top corners radius-card · 검정 ~50% alpha scrim · swipe-down dismiss). 각 phase는 독립 라우트로 배포되는 진짜 screen — sheet은 surface일 뿐이고 콘텐츠는 deep-link 가능한 페이지급. 동일 라우트를 MyPage("진행 중인 이벤트") · push 알림(매칭 결과 도착 등) · share URL 등 어디서든 진입 가능. AppBar — visual

56px 고정 AppBar. 좌측 16px 안쪽에 brand SVG 로고, 우측 끝에 액션 아이콘 3개 (search · notifications · 프로필). 배경 color-background, 하단 1px color-divider 라인.

※ 인증 상태에 따라 우측 마지막 슬롯이 바뀜: 로그인 시 28px 원형 아바타(프로필 사진), 비로그인 시 person_outline 아이콘.

Filter chip bar — visual

AppBar 바로 아래 36px 가로 스크롤 영역. 정렬(추천순 · 마감임박 · 가까운날짜) — 단일 선택. VerticalDivider — 토글(가까운 거리 · 참여 가능) — 다중 선택. 모든 칩은 아이콘 + 라벨 구조 (mds_icons.dart 직접 참조). active 상태는 primary tint 배경 + primary 보더.

Motion & timing

duration은 Dart 측에서 MinglitAnimation 토큰 클래스로 이미 선언됨 — micro 100ms · fast 200ms · medium 350ms · slow 500ms. 현재 tokens.json(canonical mds-token JSON)에는 duration 항목이 미반영(TODO(mds-tokens)) — Dart 상수가 곧 JSON에 마이그레이션될 예정. 아래 표는 토큰 이름과 실측 ms를 함께 표기.

Transition Duration (token · ms) Curve / notes

EventNowBar — action 상태 chevron blink ~1400ms loop (unscoped) action 상태에서 상단 가운데 위쪽 chevron이 primary 색으로 함께 깜빡 — "탭하면 바텀시트가 올라온다" 어포던스 강조. dot pulse와 동일 사이클로 동기화.

Edge cases

  • FeaturedTagChipBar가 비어 있을 때 — 태그 칩 바 전체가 높이 0으로 접혀 다음 컨텐츠가 바로 올라옴.
  • 첫 페이지 전체가 클라이언트 필터(근거리/참여가능)에 의해 걸러졌을 때 — 빈 목록 대신 로딩 인디케이터를 유지하며 다음 페이지 자동 fetch. 더 이상 페이지가 없으면 Empty 상태 전환.
  • EventNowBar — 노출 조건 — todayActiveEvents > 0 일 때만 보임. loading, 네트워크 offline, 활성 이벤트 0개에서는 bar 자체가 미렌더(SizedBox.shrink) — 사용자에게 불완전한 상태를 노출하지 않음.
  • EventNowBar — waiting 상태 (이벤트 시작 전) — 우측에 "N분 후" / "N시간 후" 시간 텍스트만 표시 (다른 상태에는 시간 텍스트 없음). 우측 chevron 아이콘은 모든 상태에서 사용하지 않음 — 상단 가운데 위쪽 chevron이 expand affordance 역할.
  • EventNowBar — action 상태 (checkInReady / matchingReady / results) — 사용자 입력 필요. 시각적 강조 4종 동시 적용: ① 10%→2% primary tint 배경 그라데이션, ② dot pulse + halo ring, ③ status text bold + primary color, ④ 상단 chevron primary + blink. 탭 시 phase 라우트 push (modal bottom sheet으로 올라옴). (top border 없음 — 둥근 모서리와의 픽셀 정렬을 위해 의도적으로 제거.)
  • EventNowBar — passive 상태 (waiting / checkedIn / matching / ended) — 시스템 진행 / 결과 대기 상태. dot이 1.8s 사이클로 부드러운 blink만 적용 — action 상태와 시각적으로 명확히 구분됨.
  • 피드 끝에서 무한 스크롤 중 추가 오류 — 하단 스피너가 사라지고 조용히 실패. 스낵바 표시 없음 (Pull-to-refresh로 재시도 유도).
  • 다크 모드 — 우측 상단 Dark mode 토글 체크 시 모든 .viewport + .visual-gallery 컨테이너가 dark 토큰으로 전환 (color-background #0f0f0f · color-surface #212121 · text 반전 · color-primary #aa33ff). 로고 SVG는 light/dark 버전 분기 (spec은 투명 배경 로고 사용). 필터 칩 active: 보라 계열 유지. Event card 본문 / EventNowBar bg / dot 색상 모두 자동 반응.

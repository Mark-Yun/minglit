파트너 신청 상세 (관리자 검토)

Overview

Status✅ 디자인완료
Appapp_partner
Categoryadmin · partner application review
Route / SurfacePartnerApplicationDetailRoute
Path/admin/applications/:applicationId
Hierarchy Parent: — (admin 전용 상세 화면 · 별도 list 진입)
Children: image preview Dialog (인라인 다이얼로그) · 외부 launchUrl(PDF/문서)
Purpose 관리자(파트너 앱 내부 admin 권한)가 신규 파트너 신청서의 기본 정보 · 사업자 등록증 / 통장 사본 등 첨부 파일을 검토하고 승인 / 보완 요청 / 반려 중 한 가지 처분을 내린다. 신청자(일반 파트너 후보)가 보는 status 화면은 별도(PartnerApplyStatusPage) — 본 화면은 처분 권한 있는 admin 전용.
User journey Entry points: admin 신청 목록 → 행 탭 (또는 push notification deep link) → 본 화면.
Exit points: 처분 후 toast 노출 + provider invalidate (status가 'pending' → 'approved'/'rejected'/'needs_correction'으로 갱신, 같은 화면에서 결과 섹션이 review 섹션 자리로 교체) · AppBar back으로 list 복귀.
Background 파트너 가입 심사는 사업자 진위 검증과 정산 계좌 일치성이 핵심이라 단순 form 승인이 아닌 첨부 문서 열람 + admin comment 기록이 필요. 처분 분기 3종(approved / needs_correction / rejected)을 단일 화면 하단 가로 3-button으로 묶어 "신중한 한 번"을 유도. dummy-id 모드: '/admin/applications/dummy-id' 진입 시 하드코딩 샘플 데이터로 디자인 확인 가능 (Repository 호출 없이).
Frequencyadmin이 신청 들어올 때만 (불규칙)

Layout

simpleAppBar + SingleChildScrollView. body는 4 섹션(기본정보 / 첨부파일 / 검토 또는 결과 / —). 검토 섹션은 status === 'pending'에서만 노출.

Blueprint & tree

AppBar(h56) + 스크롤 body(padding 16). Column(crossAxis: start)에 Section header → InfoRow*N → 다음 Section header → ... 패턴. status 'pending' 시 하단에 TextField + 3-button. 그 외 status는 결과 섹션(상태 + admin comment).

Global Behavior

cross-cutting interactions, motion, edge cases.

Cross-cutting interactions

사용자 액션화면에 보이는 결과
뒤로 가기 (OS back / AppBar back)이전 화면(admin 신청 list 등)으로 복귀.
처분 진행 중 다른 액션globalLoadingController가 전체 화면 overlay 노출 — 추가 입력 차단.
처분 완료 toastcontext.showMinglitSuccess('처리되었습니다 — $status') · provider invalidate → review → 결과 섹션 자동 swap.
처분 실패 (예: 네트워크)handleMinglitError(context, e, st) → SnackBar / dialog (Sentry로 전송).
외부 앱 launch (PDF)iOS/Android OS 외부 앱(파일/PDF viewer)로 위임 → app 백그라운드. 복귀 시 본 화면 그대로.

Global edge cases

  • 네트워크 끊김 — review 처분 시 timeout → handleMinglitError SnackBar. 사용자 retry 가능.
  • signedUrl 만료 — Storage 1h TTL. dialog/외부 launch 직후 오래 머물면 다음 클릭 시 재 fetch 필요 (현재는 매 클릭 재 fetch).
  • 다크 모드 — Material colorScheme dark variant 자동. ElevatedButton은 partner.primary 톤으로 자연 적응. image dialog는 항상 다크 (textPrimary 배경 유지).
  • 접근성 — InfoRow의 SizedBox(width: 100) label은 큰 글씨 시 wrap 안되고 잘림 위험 → 향후 IntrinsicHeight 또는 vertical layout 검토.
  • 다국어 — 모든 라벨/문구가 l10n.appDetail_*. 영문 fallback 존재.

Purpose 파트너의 비즈니스 관리(파티 / 인증 / 계좌 / 멤버), 앱 설정(알림 / 테마), 계정(관리 / 로그아웃), 약관 및 정보(정책 / 약관 / 앱 버전)를 모두 진입 가능한 단일 settings hub. 5개 그룹으로 나뉜 tile list + 최상단 partner 프로필 카드.

Exit points: 각 tile 탭 → 하위 관리/설정 화면 push (StatefulShell branch 내부) · 로그아웃 → confirm 다이얼로그 → LoginRoute.
Background 파트너 앱은 비즈니스 운영 도구라 settings 항목이 사용자 앱보다 많고 권한 분기가 있음 (예: SETTLEMENT_EDIT 없으면 "계좌 관리" 숨김). 그룹화는 의미 단위(비즈니스 / 설정 / 계정 / 약관)로만 — nested 카테고리 없이 평면 list.
Frequency 설정 변경 / 멤버 관리 / 정산 계좌 확인 시 — 주 1-3회.

States

2 state. baseline = Default(전권 owner). SETTLEMENT_EDIT 미보유 시 "계좌 관리" tile 숨김.

State 종류 식별 기준: ① currentPartnerInfoProvider가 data로 풀리고 currentMemberPermissionsProvider에 SETTLEMENT_EDIT이 있으면 baseline. ② 권한이 비면 ("staff" 등 제한 멤버) "계좌 관리" tile만 빠진 reduced 상태. ③ 프로필 fetch loading/error는 가장 위 ProfileGroup 자리만 spinner 또는 "정보를 불러올 수 없습니다" 폴백 — 별도 mini-table 없이 본 spec 노트에 기재.

Default · 전권 (owner / SETTLEMENT_EDIT) 🎯 baseline · 5 SettingsGroup · 4 BusinessGroup tile 모두 노출

Global Behavior

cross-cutting — 모든 state에 적용되는 액션, motion, 글로벌 에지케이스.

Cross-cutting interactions

사용자 액션화면에 보이는 결과
탭바 다른 탭 → 더보기 StatefulShell branch swap — More branch는 stack을 보존하므로 이전 nested push 위치로 복귀.
다크 모드 토글 scaffold / 그룹 카드 / tile 모두 dark 토큰으로 자동 swap. ThemeSettingsTile의 icon이 dark_mode_outlined로 즉시 갱신 (MediaQuery brightness 변동 → riverpod rebuild).
tile tap haptic 모든 InkWell tile은 ripple — 앱 버전 tile만 onTap 미연결 (무반응 · ripple 없음). 토글/스위치 trailing은 아직 사용 안 함.
약관 / 정책 tile 탭 launchUrl 외부 브라우저 호출 — 앱 컨텍스트 유지, 복귀 시 동일 화면.
로그아웃 confirm 후 authControllerProvider.signOut() → onboarding redirect → LoginRoute. PartnerScaffold도 함께 disposed.

Global edge cases

  • 스크롤 끝 도달 — TermsGroup 마지막 (앱 버전 tile)이 화면 끝. ListView padding-bottom: xxxlarge로 home bar 가림 방지 (Fix #1824 / #1803).
  • 그룹 헤더 sticky 아님 — 일반 스크롤. 그룹 헤더는 카드 바깥 위에 평범히 배치.
  • 권한 stream 늦은 도달 — currentMemberPermissionsProvider가 비어 시작 → BusinessGroup이 잠깐 3 tile로 보일 수 있음 → 권한 도착 후 4 tile로 전환 (또는 그 반대). cut 전환.
  • partnerAsync error — ProfileGroup 자리만 비활성 ProfileTile ("정보를 불러올 수 없습니다") · 나머지 group은 정상 노출 (멤버 관리만 partner.id 필요해서 탭 시 스낵바).
  • 앱 버전 fallback — PackageInfo.fromPlatform() 비동기 fail 시 하드코드 fallback "26.04.1455"가 잠깐 보일 수 있음.

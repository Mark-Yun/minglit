Global Behavior

Sheet dismiss, async fallback, contact reveal, and cross-surface behavior.

Cross-cutting interactions

BehaviorContract
Dismiss호출 surface의 modal bottom sheet 기본 동작을 따른다. 외부 tap, system back, drag down 으로 닫힘.
Card action각 card 하단에 연락처 저장하기 CTA 하나만 직접 노출한다. 저장은 해당 partner 를 OS contact save flow 로 넘긴다. 여러 명이어도 모두 저장은 제공하지 않는다.
Empty CTA다음 이벤트 찾기 tap 시 현재 sheet 를 닫고 HomeRoute 로 이동한다. Home feed 가 현재 이벤트 탐색 surface 이며, CTA 는 retry 가 아니다.
Single / multiplematches.length == 1 이면 card 1장을 중앙 정렬하고 horizontal scroll/indicator 를 만들지 않는다. matches.length > 1 이면 card 는 가로 carousel 로 넘기며 다음 card 의 일부가 보이게 한다. Dot indicator 는 multi case 에서만 표시하고, active dot 은 현재 card index 를 따른다. 각 card action 은 해당 partner contact 에 scope 된다.
Data refreshmyMatchesProvider(event.id) 가 source. 이 content 내부에는 refresh / retry 버튼이 없다.
Error fallback조회 실패는 empty state와 동일한 메시지로 처리한다. 내부 error detail 노출 금지.
Contact revealmutual match 성립 후 연락처 교환이 목적이므로 partnerContact는 전체 표시한다.
Surface parityHome EventNowBottomSheet와 event-ended 매칭 결과 보기 button sheet는 동일 MatchResultsContent를 사용해야 한다.

Motion

TransitionToken / behavior
Sheet enter/exitFlutter showModalBottomSheet 기본 Material route transition.
Loading holdProvider pending 동안 SizedBox(height: 120) 안에 MinglitCircularProgressIndicator. 최소 노출 시간은 두지 않는다. Loading slot 은 결과 전환 시 sheet height jump 를 줄이는 완충 영역.
Loading → matchedAnimatedSwitcher + MinglitAnimation.medium. Sequence: spinner fade out → check badge scale 0.92→1.0 + fade in → matched copy fade/slideY 6→0 → card area fade/slideY 10→0. 여러 card 는 40ms stagger, dot indicator 는 card 후 80ms fade in.
Loading → emptyAnimatedSwitcher + MinglitAnimation.medium. Empty icon/copy/CTA 를 하나의 group 으로 fade/slideY 8→0. Retry 성격의 흔들림이나 error motion 은 사용하지 않는다.
Interaction polishCarousel drag 는 native scroll physics. Active dot 은 page settle 후 MinglitAnimation.fast 로 width/color transition. 연락처 저장하기 tap 은 pressed state 만 사용하고 별도 success toast 는 OS save 결과 이후 구현 영역에서 처리한다.
Reduce motionOS reduce motion 감지 시 duration 0ms, 최종 상태만 즉시 표시.

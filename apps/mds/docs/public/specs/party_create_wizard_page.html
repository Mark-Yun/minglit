Party Create Wizard

Widget: PartyCreateWizardPage + Step1BasicInfo … Step6Review Role: 파티 생성 / 수정 위저드

Purpose & Context

Purpose 파트너가 새 파티(모임)를 생성하거나 기존 파티를 수정할 수 있도록 6단계 위저드로 안내한다. 각 단계에서 입력한 정보를 마지막 검토 단계에서 한눈에 확인하고 최종 생성/수정 처리한다.
User journey Entry points: 파티 목록(PartyListPage) "새 파티 만들기" 버튼 / 기존 파티 상세(PartyDetailPage) "수정" 메뉴 (partyId 전달 시 Edit 모드).
Exit points: 생성/수정 성공 → 파티 목록 복귀 + 성공 스낵바 / 뒤로 가기 → (단계 이탈 확인 다이얼로그 없음) 파티 목록 복귀.
Background 파티 정보가 복잡하고 다양한 필드(기본 정보, 위치, 정원/연락처, 입장 규칙, 티켓, 검토)로 나뉘기 때문에 단계별 위저드가 UX를 단순화한다. 수정 모드(partyId 전달)에서는 기존 데이터를 prefill하며, prefill 로딩 중에는 스피너 화면을 표시한다. double-tap 방지를 위한 guard(_isNextingStep)가 적용되어 있다.
Frequency 파트너당 파티 생성 1회 / 이후 수정 시 재진입.

Behavior

사용자 액션과 화면이 보여주는 결과.

Interactions

사용자 액션 화면에 보이는 결과
"다음" 버튼 탭 (유효성 통과) PageView가 다음 단계로 ~300ms easeInOut 슬라이드. 프로그레스 바가 증가. AppBar 타이틀이 다음 단계명으로 변경.
"다음" 버튼 탭 (유효성 실패) 스낵바로 첫 번째 오류 메시지 표시. 페이지 이동 없음. 오류 필드에 빨간 border 표시.
"다음" 버튼 연속 더블 탭 두 번째 탭은 무시 (_isNextingStep guard). 단계가 2번 건너뛰어지지 않음.
"이전" 버튼 탭 PageView가 이전 단계로 슬라이드. 입력 데이터 유지. Step 1에선 "이전" 버튼 없음.
뒤로 가기 (시스템) 위저드 종료 확인 없이 파티 목록으로 이동. 입력된 데이터 유실.
파티 제목 입력 입력 커서 표시 · 상태 실시간 업데이트.
커버 이미지 "+ 추가" 탭 OS 이미지 피커 또는 갤러리 시트 오픈. 선택한 이미지가 그리드에 추가. 최대 슬롯 채움 시 추가 버튼 숨김.
커버 이미지 "×" 탭 해당 이미지 즉시 제거. 그리드 재배열.
장소 검색 버튼 탭 (Step 2) 장소 검색 화면(LocationSearchPage)으로 이동. 선택 후 복귀 시 장소 정보 자동 입력.
"그룹 추가" 탭 (Step 4) 입장 그룹 생성 바텀시트 또는 inline 폼 출현.
입장 그룹 삭제 아이콘 탭 해당 그룹 즉시 제거. 관련 티켓의 targetEntryGroupId도 연결 해제.
검토(Step 6) 섹션 "수정" 탭 해당 단계(e.g. "기본 정보")로 PageView가 즉시 이동. 검토 화면 없이 바로 해당 step 보임.
"생성하기" 버튼 탭 (유효성 OK) 전체 로딩 오버레이(GlobalLoading) 표시. 완료 시 "파티 정보가 생성되었습니다" 스낵바 + 파티 목록 화면으로 자동 이동.
"생성하기" 버튼 탭 (유효성 오류) 버튼이 disabled 상태 — 탭 불가. 오류 카드가 상단에 표시되며 미완성 항목 목록 나열.
생성 실패 (서버 오류) 로딩 오버레이 해제 + 에러 다이얼로그/스낵바 표시. 검토 화면으로 복귀, 재시도 가능.

Motion & timing

Transition Duration Curve / notes
단계 간 PageView 전환 MinglitAnimation.medium (~300ms) Curves.easeInOut. 좌→우 slide (다음) / 우→좌 slide (이전).
프로그레스 바 증가/감소 ~300ms width animation (CSS transition). 단계 전환과 동시 진행.
AppBar 타이틀 변경 ~150ms Flutter AppBar 기본 — step 전환 시 함께 변경. fade 없이 즉각 교체.
유효성 오류 → 스낵바 ~200ms Material Snackbar slide-up. 자동 닫힘 4초.
전체 로딩 오버레이 진입 ~150ms Opacity fade-in. 배경 scrim + 중앙 white spinner.
검토 → 수정 단계 점프 MinglitAnimation.medium PageView.animateToPage(step.index) easeInOut.

※ mds_tokens에 motion duration token은 아직 미정의 — 위 수치는 임시값.

Edge cases

  • 수정 모드 진입 (partyId 전달) — AppBar 타이틀 "수정" 표시. prefill 로딩 중에는 전체 스피너 화면. prefill 완료 후 Step 1 노출, 모든 필드에 기존 값 채워짐.
  • 수정 모드 완료 버튼 — "생성하기" 대신 "수정 완료" 텍스트. 성공 스낵바: "파티 정보가 수정되었습니다."
  • Step 1 이미지 없이 다음 탭 — 커버 이미지 없이 진행 가능 (필수 아님). 검토 단계에서 이미지 없음 경고가 나올 수 있음.
  • 비공개 파티 토글 ON — 스위치 보라색으로 전환. 메인 피드에서 노출되지 않으며 링크 공유로만 진입 가능한 상태 표시.
  • Step 4 그룹 없이 다음 탭 — 유효성 오류: "최소 1개의 입장 그룹이 필요합니다." 스낵바. 페이지 이동 없음.
  • Step 5 티켓 없이 다음 탭 — 유효성 오류: "최소 1개의 티켓이 필요합니다." 스낵바.
  • 검토 단계 유효성 오류 카드 — 오류 항목 목록 나열 (예: "파티 제목이 비어 있습니다" · "티켓이 없습니다"). "생성하기" 버튼 비활성화(disabled). 오류 항목별 "수정" 클릭 시 해당 단계로 이동.
  • 다크 모드 — AppBar · PageView 배경: color-background(dark). 프로그레스 바 fill: color-primary(dark:#aa33ff). 입력 필드 테두리: color-divider(dark). "다음" 버튼: color-primary 유지. 오류 테두리/텍스트: color-error 유지.

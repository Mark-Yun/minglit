Purpose 파트너가 앱에 진입했을 때 가장 시급한 액션(승인 대기 신청, 임박/진행 중 이벤트, 첫 파티 만들기)으로 한눈에 도달할 수 있게 하는 단일 대시보드. 파트너 lifecycle의 모든 단계 (onboarding · 운영 중 · 이벤트 종료 직후)를 같은 화면에서 phase-별 UI로 분기한다.
User journey Entry points: 앱 cold start (로그인 후 → 홈 redirect) / 다른 탭에서 홈 탭 재선택 / 푸시 알림 → 홈.
Exit points: 알림 센터(우측 상단), 장소 가이드 배너, EventActionCard CTA(신청관리/체크인/이벤트 생성), TodoSummaryChips(승인 대기 → 신청관리 탭), Onboarding CTA(파티/이벤트 생성), 하단 NavigationBar(신청관리/체크인/정산/더보기).
Background 파트너 사용자는 1) 처음 가입 직후(이벤트가 한 번도 만들어진 적 없음) 또는 2) 운영 중(이벤트 1개 이상 존재)이라는 두 가지 상태를 가진다. 홈은 그 둘을 구분해 완전히 다른 화면을 그린다. 운영 중인 파트너에겐 가장 임박한 이벤트 1개를 강조 카드로 보여주고, 이벤트 단계(모집 중 / 준비 중 / 진행 중 / 종료 후 24시간 이내)에 따라 메인 CTA가 달라진다.
Frequency 로그인 세션마다 진입. 운영 중인 이벤트가 있을 땐 하루 수회. 진행 중 이벤트(LIVE) 동안엔 새로고침 빈번.

Cross-cutting interactions

사용자 액션 화면에 보이는 결과
아래로 당기기 (pull-to-refresh) 대시보드 데이터를 다시 불러옴. 갱신이 끝나면 자동으로 화면에 반영. 로딩 화면에선 새로고침 동작 자체가 비활성.
알림 아이콘 탭 알림 센터 화면이 셸 밖으로 push되어 진입 (하단 nav 사라짐). 미읽음 카운트는 99 초과 시 "99+"로 캡.
버그 리포트 액션 (개발 빌드 한정 · 알림 좌측) 운영 빌드에서는 노출되지 않음. 디자인 1:1 비교 시 운영 빌드 기준으로 무시.
하단 탭 전환 홈 스택은 유지된 채 다른 탭으로 전환. 정산 탭은 권한이 있을 때만 노출되며, 권한이 없으면 탭 자체가 보이지 않음.
다크 모드 토글 scaffold/카드 배경이 다크 톤으로 자동 전환. partner primary는 다크 변형(#9b7bec)으로 매핑. 장소 가이드 배너의 민트 톤은 다크에서도 비슷한 채도 유지.

Global edge cases

  • 파트너 정보 로딩 중 — 인사말의 이름 자리에 "파트너" placeholder가 잠깐 노출됨. 다른 컴포넌트는 영향 없음.
  • 활성 파티 수 — 0개이면 온보딩의 "첫 파티" CTA · 1개이면 이벤트 생성으로 바로 진입 · 2개 이상이면 파티 선택 시트 노출 후 선택.
  • 이번 주 성과 데이터 부재 — 매출/체크인율은 아직 임시값. 데이터가 없을 땐 ₩0 / 0%로 노출. 신청 카운트만 처리 대기 건수와 동일하게 재사용.
  • 다가오는 이벤트 칩 카운트 — 7일 이내 시작 예정인 이벤트 수 (모집 중·준비 중·진행 중 모두 포함, 종료된 건 미포함).
  • 정산 권한 미보유 — 하단 nav에서 정산 탭이 노출되지 않음. URL 직접 진입 시 라우팅에서 처리.

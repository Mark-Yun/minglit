Widget: LoginPage + MinglitLoginScreen (kit-shared) Role: 인증 진입 화면

Purpose & Context

Purpose 소셜 로그인(Google / Apple / Kakao)으로 사용자를 인증해 앱의 모든 보호된 기능 (이벤트 참여, 파티 생성, 알림 수신, 결제 등)에 진입할 수 있도록 한다. 이메일/비밀번호 자체 인증은 지원하지 않는다 — OAuth 전용.
User journey Entry points: 앱 첫 실행 / 로그아웃 직후 / 보호된 화면 직접 진입(from 파라미터로 redirect).
Exit points: 인증 성공 → HomeRoute (또는 from이 가리키는 원래 화면). 외부 OAuth 페이지로 이탈했다가 callback으로 자동 복귀.
Background 밍글릿은 검증된 사용자(Verified Vibe)만 모임에 참여할 수 있는 컨셉이라 OAuth 기반 신원 확인이 핵심. 이메일/비밀번호 가입은 신원 위변조 위험이 커서 의도적으로 배제. User / Partner 두 앱이 widget을 공유 — Partner 변형은 입점 문의 link만 다름.
Frequency 로그아웃 상태에선 매번. 인증된 사용자에겐 1회 / 세션 만료 시.

Behavior

사용자 액션과 화면이 보여주는 결과. user-visible only — 내부 구현은 컴포넌트 spec 참조.

Interactions

사용자 액션 화면에 보이는 결과
Google 버튼 탭 버튼 영역이 잠깐 눌린 모양 → 화면 전체가 로딩 스피너로 전환 → 외부 브라우저로 OAuth 페이지가 열림. 인증 완료 후 앱으로 자동 복귀하면 홈 화면(또는 가려던 화면)으로 이동.
Apple 버튼 탭 Google과 동일 흐름. Apple 인증 시트가 OS 레벨에서 표시됨.
Kakao 버튼 탭 Google과 동일 흐름. Kakao 인증 페이지(또는 KakaoTalk 앱)로 전환.
Logo를 2초 안에 5번 탭 dev 환경에서만: Dev User Switch 화면으로 전환되어 미리 정의된 테스트 계정 목록이 표시됨. production에선 아무 일도 일어나지 않음.
"이용약관" 링크 탭 외부 브라우저가 열리며 약관 페이지로 이동. 이 화면은 그대로.
"개인정보처리방침" 링크 탭 외부 브라우저로 이동. 이 화면은 그대로.
"파트너 입점 문의" 탭 (Partner) 외부 브라우저로 입점 문의 페이지 이동.
뒤로 가기 (시스템 back / 스와이프) 보호된 화면에서 redirect되어 온 경우: 홈 화면으로 이동.
그렇지 않으면(앱 첫 진입): 시스템 기본 동작 (Android는 앱 종료, iOS는 동작 없음).
인증 실패 (서버/네트워크) 공통 에러 다이얼로그/스낵바가 잠깐 떴다 사라짐. 화면은 default 상태로 복귀하여 재시도 가능.

Motion & timing

Transition Duration Curve / notes
화면 진입 (cold start / 로그아웃 후) — Native scaffold 전환 — 별도 entry animation 없음.
버튼 탭 → 로딩 상태 ~150ms 전체 화면이 spinner로 즉시 교체. fade 없이 cut. 사용자에게 액션이 받아졌다는 즉각 피드백.
로딩 → 외부 OAuth 브라우저 OS 기본 OS-level 외부 브라우저 전환 애니메이션 (custom 불가).
OAuth 복귀 → 홈/원래 화면 ~250ms GoRouter 기본 라우트 전환 — slide / fade. 자동 redirect라 사용자 입력 없이 진행.
에러 다이얼로그 노출 ~200ms 중앙 fade-in scale (Material default). 닫힐 때도 동일.

※ mds_tokens에 motion duration token은 아직 미정의 — 위 수치는 임시값. 향후 motion scale 토큰 신설 시 대체될 것.

Edge cases

  • Apple 사인인 미지원 환경 (Android 등) — Apple 버튼이 사라지고 그 자리는 빈 공간 없이 Kakao 버튼이 위로 올라온다.
  • 이미 로그인된 사용자가 이 URL 직접 진입 — 화면이 잠깐 보이지 않고 바로 홈으로 이동.
  • 보호된 화면에서 redirect — 인증 후 처음 가려던 화면으로 자동 복귀 (홈이 아님).
  • Dev 트리거 5탭 타이밍 — 마지막 탭 후 2초가 지나면 카운트가 리셋된다. 너무 천천히 탭하면 트리거되지 않음.
  • OAuth 도중 사용자가 외부 브라우저를 닫음 — 앱으로 돌아오면 default 상태로 복귀. 별도 에러 표시 없음.
  • 다크 모드 — 우측 상단 토글로 확인. Google은 흰 → 어두운 배경, Apple은 검정 → 흰 배경으로 자동 swap. Kakao만 brand-locked 노랑 유지.

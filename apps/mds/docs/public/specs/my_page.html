Hierarchy Parent: — (top-level — HomePage AppBar 아바타 탭으로 진입)

Purpose 사용자의 활동(구매 내역 / 내 티켓), 설정(알림 / 테마), 개인정보 / 보안, 약관 / 정보, 계정 관리를 모두 진입 가능한 단일 settings hub. 6개 그룹으로 나뉜 tile list.
User journey Entry points: HomePage AppBar 우측 아바타 탭 (인증 후) / push 알림에서 일부 settings로 deep-link.
Exit points: 각 tile 탭 → 하위 settings 화면 / 로그아웃 → LoginRoute / 뒤로 가기 → HomePage 복귀.
Background 밍글릿은 settings를 가능한 한 평면 list로 노출해 사용자가 원하는 항목을 빠르게 찾도록 함 — 그룹화는 의미 단위(활동 / 설정 / 개인정보 / 약관 / 계정)로만, 카테고리 페이지 내 nested 구조 회피. 현재 HomePage의 아바타 탭이 유일한 진입점 — 하단 탭바 없는 단독 화면.
Frequency 설정 변경 시 또는 활동 내역 확인 시 — 주 1-2회 정도.

States

2 state. baseline = Default(로그인). 비로그인 시 auth guard로 settings list 미노출.

State 종류 식별 기준: currentUserProvider 분기 — null이면 auth guard, 아니면 default. Loading state는 별도 미상세 — currentUserProvider는 cached + sync 접근 (auth provider state) → 진입 직후 즉시 분기.

Global edge cases

  • 스크롤 끝 도달 — AccountGroup 마지막 (로그아웃 tile)이 화면 끝. 추가 padding 없음 — safeArea로 처리.
  • 그룹 헤더 스크롤 위 체류 — sticky 아님. 일반 스크롤 (다른 spec에 sticky 패턴 있다면 분리).
  • placeholder tile — "구현 준비 중" 스낵바로 임시 응답. 후속 spec에서 라우팅 활성화.

Purpose 유료 이벤트 구매 전에 사용 가능한 티켓을 추천하고, 사용자가 결제 wizard로 넘길 ticketId를 확정하는 결제 진입 게이트. balance / 프로필 / 인증 조건을 한 번에 평가해 추천 티켓을 자동 선택한다.
User journey Entry: EventBottomTicketBar의 구매 가능 admission action → eventCoordinator.showTicketSelection().
Exit: "다음" 탭 → sheet dismiss → goToApplicationWizard(eventId, ticketId). Scrim/drag dismiss는 구매 취소로 간주하고 EventDetailPage 유지.
Background 결제 flow의 실제 첫 관문이지만 별도 MDS spec이 없어 ticket 선택, 추천, 잠금 사유의 시각 SSOT가 비어 있었다. 수량 선택은 친구와 함께하기 기능이 열릴 때까지 노출하지 않고, 현재는 단일 ticket 선택만 확정한다.
Frequency유료 이벤트 상세에서 구매 action을 누를 때마다 표시. 구매 의도가 높은 핵심 CUJ surface.

Layout

Bottom sheet 구조와 ticket option / CTA의 고정 순서.

Blueprint & tree

Sheet는 상단 rounded container 안에 제목, async state branch, full-width CTA를 세로로 쌓는다. 키보드가 아니라 손가락 조작 중심 surface라 각 option row는 MinglitSpacing.medium 이상의 터치 여백을 유지한다.

② Section label

showModalBottomSheet(isScrollControlled: true) └─ TicketSelectionSheet └─ Container(surface · top radius MinglitRadius.card · padding large) └─ Column(mainAxisMin · crossAxisStart) ├─ Text("티켓 선택", headlineSmall bold) ← ① ├─ Gap MinglitSpacing.medium ├─ State branch │ ├─ loading → MinglitSkeleton shimmer/pulse (ticket option shape) │ ├─ tickets empty → MinglitEmptyState.card("현재 구매 가능한 티켓이 없습니다.") │ ├─ no recommendation → empty card + locked ticket list │ └─ recommendation → section labels + ticket option cards ← ②③④ ├─ MinglitButton(label: "다음", disabled if selectedTicketId null) ← ⑤ └─ Bottom inset: MediaQuery.viewPadding.bottom

Sub-anatomy

RegionSpec
Ticket option card GestureDetector + Container. 기본은 1px colorScheme.outlineVariant border, MinglitRadius.input, MinglitSpacing.medium padding. 선택 시 2px primary border와 MinglitOpacity.tintFill primary fill. locked는 전체 opacity 0.5, tap 비활성, 사유 텍스트 인라인 표시.
Recommendation badge MinglitBadge(label: "추천", compact: true). 추천 티켓이 잠기지 않았을 때 우상단에 표시.
Balance badge MinglitBadge(label: "선택 불가", compact: true). balanceStatus가 false인 locked ticket 우상단에 표시. 상세 사유는 현재 모집 상황에 따라 선택할 수 없어요.로 운영 로직을 직접 노출하지 않는다.
CTA MinglitButton(label: "다음"). ticket 선택 전 disabled, 선택 후 sheet를 닫고 application wizard로 ticketId를 전달.

Global Behavior

추천, 선택, CTA, dismiss, accessibility 규칙.

Interaction rules

RuleBehavior
Auto recommendationbalanceStatus, userProfile, approvedVerificationIds가 모두 준비되면 TicketRecommendationUtil.recommend() 실행. eligible ticket은 가격 오름차순, 이름 오름차순으로 정렬하고 첫 항목을 추천한다.
Auto-select guard_hasAutoSelected가 false일 때만 최초 추천 ticket을 자동 선택한다. 이후 사용자가 선택한 ticket이 eligible이면 유지한다.
Selection update사용자가 eligible ticket을 선택하면 _selectedTicketId를 갱신한다. 수량 선택은 친구와 함께하기 기능이 열릴 때까지 노출하지 않는다.
Locked optionisLocked이면 tap handler 없음, opacity 0.5, ineligibleReason을 ticket description 아래에 노출한다.
Next CTA선택 ticket이 없으면 disabled. enabled 상태에서 탭하면 Navigator.pop(context) 후 onTicketSelected(event.id, ticketId) 호출.
Dismiss기본 modal bottom sheet dismiss 동작 유지. 별도 confirm 없음.
A11yTicket card locked reason은 badge만으로 처리하지 않고 시각 텍스트로도 노출한다.

Motion & async

Sheet motionFlutter showModalBottomSheet 기본 진입/퇴장 motion. MDS 별도 override 없음.
Async degradationbalance fetch 실패는 logger에 기록하고 추천 계산은 계속 진행한다. 사용자에게 blocking error surface를 띄우지 않는다.
Future quantity친구와 함께하기 기능을 추가할 때 수량 컨트롤, 총액 row, balance/stock 재검증을 함께 설계한다. 현재 sheet에는 노출하지 않는다.

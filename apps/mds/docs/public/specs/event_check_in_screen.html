Event Check-In

Overview

Status 🚧 디자인중 — 4 state · routed bottom sheet · kit-shared 예정 (현재 구현은 EventNowBottomSheet의 phase 1 콘텐츠로 inline)
App app_user (widget은 minglit_kit 패키지에 거주 — kit-shared)
Category event · check-in · modal sheet
Route / Surface EventCheckInRoute (ModalBottomSheetRoute · GoRouter pageBuilder) · widget: EventCheckInScreen (kit-shared)
Path /events/:id/check-in
Hierarchy Parent: HomePage (HomeRoute) — 시트가 push 되는 동안에도 parent route 그대로 유지. 진입은 EventNowBar의 checkInReady / waiting 탭.
Children: — (체크인 완료 시 EventCheckedInScreen 시트로 transition — 별도 spec)
Purpose 오늘 참여 중인 이벤트 입장을 위한 QR 티켓을 즉시 보여주는 routed 바텀시트. 사용자는 이 한 화면에서 QR 스캔, 이벤트 정보 확인, 위치 deeplink까지 한 번에 끝낸다.
User journey Entry points: ① EventNowBar 탭 (waiting / checkInReady state) — 가장 흔한 경로. ② push 알림 "곧 입장 시작" → deeplink. ③ MyTickets "오늘 입장 가능한 티켓" 탭.
Exit points: 파트너가 QR 스캔 → 백엔드 phase 변경 → EventNowBarState.checkedIn → 시트 자동 전환 (또는 dismiss + EventCheckedInScreen push). · scrim / 핸들 swipe-down → dismiss (parent HomeRoute 유지).
Background 기존 TicketQRRoute(/tickets/:ticketId/qr)는 풀-페이지 Scaffold이지만, 체크인 흐름은 "홈에서 한 탭, 끝나면 바로 복귀"가 자연스러운 UX다. 그래서 ModalBottomSheetRoute로 분리 — Material 3 / GoRouter pageBuilder → ModalBottomSheetRoute 패턴. 동일 콘텐츠를 deep-link 가능한 라우트로 두면 push 알림 / share URL / MyPage "진행 중인 이벤트" 등 어디서든 진입 가능하다. 향후 TicketQRRoute와 통합 또는 alias 처리 예정 (event_now_bar spec 참고).
Frequency 이벤트 시작 직전 — 사용자당 이벤트 1회 (체크인 완료 후에는 checkedIn 시트로 자동 전환).

States

시각 변형 4종. baseline = default (QR ready). loading / error / checked-in으로 분기. checked-in은 시트가 dismiss 되거나 EventCheckedInScreen으로 전환되는 transient state.

State 종류 식별 기준: eventTicketTokenProvider(eventId)의 AsyncValue + EventNowBarState phase. data → default · loading → loading · error or token == null → error. phase가 checkedIn으로 변하면 시트 자동 전환.

Global Behavior

cross-cutting — 모든 state에 공통 적용. modal sheet dismiss · brightness · phase stream.

Cross-cutting interactions

Interaction Behavior
Sheet dismiss (swipe-down) 핸들 영역 또는 시트 본문을 아래로 드래그 → 임계값 초과 시 dismiss. parent HomeRoute는 유지 — back stack pop 1회. EventNowBar는 그대로 노출.
Sheet dismiss (scrim 탭) 시트 외부(scrim) 탭 → 동일하게 dismiss. Material default barrier behavior.
Sheet dismiss (system back) 안드로이드 back 버튼 / iOS swipe-from-edge → dismiss. parent route로.
Screen brightness 자동 최대 TicketQRViewer의 initState에서 ScreenBrightness().setApplicationScreenBrightness(1) 호출. dispose에서 원래 값 복원. 어두운 환경에서 QR 스캔 성공률↑.
Phase stream 자동 갱신 eventNowBarStateProvider(activeEvent) Riverpod stream을 ref.watch — 백엔드 phase 변경 시 즉시 reflect. checkedIn으로 전환되면 시트 콘텐츠가 success view로 swap 후 transition.
다크 모드 토글 sheet bg → color-dark-background. scrim, QR(검정 모듈)은 그대로 (대비 유지). 다크 토큰 자동 swap.

Global edge cases

  • Deeplink 진입 — push 알림 / share URL로 직접 /events/:id/check-in 진입 시 parent stack에 HomeRoute가 없을 수 있다. dismiss 시 context.go('/')로 fallback (라우트 가드 필요).
  • 이벤트 시작 24시간 초과 (no-active) — EventNowBar가 hidden 처리되는 시점. 직접 deeplink 진입은 가능하나, 토큰 fetch 시 권한 체크에서 fail → error state.
  • 스크린샷 / 화면 녹화 — anti-fraud 안내문은 TicketQRScreen(풀-페이지)에는 있고 이 시트에는 없다. 의도적 — EventNowBar 진입은 즉시성이 우선이고 scaffold 영역이 좁다. 향후 fraud 신호가 늘면 추가 검토.
  • Offline — ticketTokenServiceProvider가 로컬 wallet 캐시를 우선 시도(Fix #1206). 캐시 hit 시 offline에서도 QR 노출 가능. miss 시 error state.
  • 다중 활성 이벤트 — bar가 1건만 노출하므로 진입도 1건. 다른 이벤트 QR은 MyTicketsPage 경유 진입.

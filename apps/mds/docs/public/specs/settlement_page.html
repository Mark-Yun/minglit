Settlement

Overview

Status ✅ 디자인완료 — 5 state · 정산 dashboard + 내역 list parent
App app_partner
Category settlement · list · dashboard
Route / Surface SettlementRoute · widget: SettlementPage (Scaffold + 2-tab TabBar: 대시보드 / 정산 내역)
Path /settlement
Hierarchy Parent: — (StatefulShellBranch top-level — bottom nav "정산" 탭)
Children: SettlementDetailPage (정산 내역 탭의 카드 탭으로 진입 · /settlement/:id) · BankAccountPage (AppBar 우측 지갑 아이콘 · /settlement/bank-account · SETTLEMENT_EDIT 권한 보유 시만)
Purpose 파트너가 (1) 월별 정산 대시보드(완료 매출 / 대기 / 상태별 카운트)와 (2) 정산 항목 list(상태 필터 + 월별 그룹)를 한 화면에서 확인한다. 개별 항목 상세는 SettlementDetailPage로 진입.
User journey Entry points: 하단 NavigationBar "정산" 탭 / 푸시 알림(정산 완료) 탭.
Exit points: 카드 탭 → SettlementDetailPage · AppBar 지갑 아이콘 → BankAccountPage (SETTLEMENT_EDIT 권한 보유 시) · 빈 상태 CTA "첫 이벤트 만들기" → PartyCreate (root GoRouter 위임 · cross-branch).
Background 정산 status enum(PENDING / READY / PROCESSING / COMPLETED / FAILED / HOLD / CANCELED)은 partner_settlement_repository에서 정의. 대시보드 카드는 completed_gross_total(COMPLETED만 합산 · #1935) / completed_net_total / pending_gross_total / status_counts를 사용. List는 createdAt 기준 월별 그룹.
Frequency 월 1–2회 + 정산 완료 알림 수신 시 즉시 진입.

Global Behavior

cross-cutting — 모든 state에 적용되는 액션, motion, 글로벌 에지케이스. 각 state 한정 액션은 위 mini-table 참고.

Cross-cutting interactions

사용자 액션 화면에 보이는 결과
탭 전환 (대시보드 ↔ 정산 내역) TabController.animateTo · TabBarView swipe/tap 모두 수용. 두 탭은 별도 controller (DashboardController · ListController)로 fetch — 한쪽 새로고침이 다른 쪽 invalidate 안 함.
AppBar 지갑 IconButton SETTLEMENT_EDIT 권한 보유 시만 노출 (#1568). 탭 → settlementCoordinator.goToBankAccount() → BankAccountRoute(/settlement/bank-account).
지원되지 않는 status 값 응답 SettlementStatus.fromString이 unknown으로 fallback · 배지 라벨 "알 수 없음" · bg surfaceContainerHighest + text onSurfaceVariant. (Empty state UI 변화 없음)
다크 모드 토글 scaffold/list bg → color-dark-surface(#212121) · primary → color-partner-dark-primary(#9b7bec) · 배지 색상은 status별 10% opacity 유지 (자동 조정 · settlement_detail 동일).
금액 포맷 (모든 state 공통) SettlementCard amount: ${negative ? '-' : ''}₩{formatted} — 마이너스 부호는 ₩ 앞 (Fix #1932). 천 단위 콤마는 자체 _formatAmount(NumberFormat 미사용 · 직접 join). Dashboard total은 NumberFormat('#,###') + ₩ prefix.

  • SETTLEMENT_VIEW 권한만 보유 — AppBar 지갑 아이콘 미렌더 (#1568). list / dashboard는 정상 표시.
  • infinite scroll race — maxScrollExtent - 200 도달 시 loadMore(). isLoading 가드는 controller에 있어야 중복 호출 방지 (현재 source는 가드 위치 점검 필요 — drift 후보).
  • cross-branch CTA — Empty state CTA "첫 이벤트 만들기"는 SettlementBranch → MoreBranch 경계를 넘어야 하므로 root GoRouter를 쓰는 settlementCoordinator에 위임 (Fix #1680). context.push() 직접 호출은 무음 실패 — 사용 금지.
  • dashboard error — Error 상태에서 다시 시도 버튼은 단순 FilledButton (MinglitEmptyState 아님 · 인라인 Center column). list 탭 Error와 시각적 결이 다름 — 후속 통일 후보.

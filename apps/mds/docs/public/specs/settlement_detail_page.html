Settlement Detail

Widget: SettlementDetailPage + _DetailContent Role: 정산 상세 · 금액 내역 · 지급 이력

Purpose & Context

Purpose 파트너가 특정 정산 항목의 상세 내용(상태, 금액 내역, 지급 이력)을 확인하고, 필요 시 재지급 요청 또는 CSV 다운로드 액션을 수행한다.
User journey Entry points: 정산 목록(SettlementListPage)에서 특정 항목 탭.
Exit points: 뒤로 가기 → 정산 목록 / "재지급 요청" 성공 → 상태 갱신 + 현재 화면 유지 / "CSV 다운로드" → DownloadBottomSheet → 파일 공유 시트.
Background 밍글릿은 PG사 수수료, 플랫폼 수수료, VAT를 차감한 순 정산금을 파트너에게 지급한다. 각 정산 항목은 PENDING → READY → PROCESSING → COMPLETED 흐름을 따르며 HOLD / FAILED / CANCELED 예외 상태도 존재한다. FAILED이고 retryable=true인 경우에만 "재지급 요청" 버튼이 표시된다.
Frequency 이벤트 종료 후 정산 주기마다 1–2회 확인.

Motion & timing

Transition Duration Curve / notes
화면 진입 (목록 → 상세) ~250ms 좌→우 slide 전환 (~250ms). 진입 직후 데이터 fetch 시작.
로딩 → 데이터 표시 데이터 fetch 완료 시 cut 전환 (애니메이션 없음). 즉각 표시.
CSV 바텀시트 진입 ~300ms Material 바텀시트 slide-up. scrim fade-in.
재지급 요청 처리 중 서버 응답 대기 버튼 비활성화. 별도 전체 로딩 오버레이 없음 (버튼 레벨 피드백).

※ mds_tokens에 motion duration token은 아직 미정의 — 위 수치는 임시값.

Edge cases

  • histories 없음 — StatusTimeline 섹션 전체 숨김. AmountBreakdown 바로 아래 ActionButtons로 이어짐.
  • FAILED + retryable == false — "재지급 요청" 버튼 미표시. CSV 다운로드만 가능.
  • CANCELED 상태 — 배지 텍스트에 strikethrough 스타일 적용. "정산이 취소되었습니다." 메시지. CSV 다운로드만 표시.
  • payoutId == null 이면서 재지급 요청 — _retryPayout()에서 early return. 버튼 비활성화 처리 필요 (현재 source에서 payoutId null guard 있음).
  • currentPartnerInfoProvider null — 재지급 요청 시 early return. 파트너 정보 없으면 요청 불가.
  • 금액 포맷 — 모든 금액은 NumberFormat('#,###').format(value) 적용. 천 단위 콤마 포함. 정산금은 '₩' 접두사 포함.
  • 상태 timeline dot 색상 — 정상 전환: color-primary. 실패 전환(FAILED 포함): color-error. 현재 Dart 소스는 모든 dot을 color-primary로 표시 — FAILED 전환 dot에 color-error 적용은 디자인 개선 권고.
  • 다크 모드 — 카드 배경: color-background(dark:#0f0f0f). 배지 bg: 각 상태별 색상의 10% opacity 유지 (dark mode token 자동 조정). 타임라인 dot: color-primary(dark:#aa33ff). 금액 텍스트: color-text-primary(dark:white). CSV 버튼 border: color-divider(dark:#3d3d3d).

— Card (Material) 각 섹션 래퍼 StatusMessageCard / AmountBreakdown / StatusTimeline — 모두 Card 사용. radius는 Material default (radius-card와 유사).

MinglitButton

Primary CTA button with loading + variants (primary / secondary / destructive).

Variants

primary bg=color-primary · text=color-on-primary
secondary border=color-primary · text=color-primary
destructive bg=color-error · text=color-on-primary

Sizes

sm py=spacing-small · px=spacing-sm · 13px
md (default) py=spacing-sm · px=spacing-medium · 14px
lg py=spacing-medium · px=spacing-large · 15px

default
disabled
loading

Accessibility

  • Disabled state announced to screen readers (aria-disabled="true")
  • Loading state replaces label semantically (aria-busy="true")
  • Min touch target 44px on size=md (Flutter default tap region)
  • Focus ring follows platform conventions

Guidelines

  • DO: one primary per screen (main CTA)
  • DON'T: stack multiple destructive buttons in same view
  • DO: use isLoading for async actions (prevents double-tap)
  • DO: pair destructive with confirm dialog (MinglitAlert.showConfirm)

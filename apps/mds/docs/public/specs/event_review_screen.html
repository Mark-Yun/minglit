Event Review

Overview

Status 🚧 디자인중 — EventReviewRoute / EventReviewScreen 클래스 미구현. 현재는 EndedContent widget이 EventNowBottomSheet 내부 Phase 5 (ended)로 렌더 (showModalBottomSheet · 별도 route 아님). 본 spec은 routed sheet 추출 후 형태 + 제출 backend 도입 후의 사양 기준.
App app_user
Category event · routed bottom-sheet · review capture (5-star)
Route / Surface EventReviewRoute — ModalBottomSheetRoute (Material 3 sheet · top corners radius-card · scrim ~50% · no AppBar)
Path /events/:id/review
Hierarchy Parent: HomeRoute via EventNowBar (ended state · bar tap → router.push(EventReviewRoute))
Children: — ("리뷰 작성하기" CTA는 현재 sheet dismiss만 수행 — 별도 long-form review route는 미정의)
Purpose 이벤트 종료 후 사용자가 1탭으로 별점(1~5)을 남길 수 있는 가벼운 캡처 surface. 64px hero(event_available 아이콘 · text-secondary 톤 · 종료 무드)와 그 아래 prompt + 5-star row + 제출 CTA로 구성. 장문 리뷰는 후속 화면(미설계) 또는 외부로 위임.
User journey Entry points: HomePage 하단 EventNowBar의 ended state 탭 → sheet 슬라이드업. push 알림 / MyPage "지난 이벤트" 등에서도 같은 route로 재진입 가능 (deeplink).
Exit points: swipe-down dismiss · scrim tap · system back · CTA 제출 성공 시 자동 dismiss → HomePage 복귀. 한 번 제출하면 EventNowBar는 다음 stream tick에서 사라지거나 read-only로 전환.
Background 매칭 phase의 마지막 단계 — 사용자에게 거절감 없이 가볍게 "이벤트 어땠어?"를 묻는 자리. 별점만 받고 즉시 dismiss 가능하도록 friction 최소화. 현재 Flutter 구현(EndedContent)은 별점 select state만 로컬 보관하고 CTA 탭 시 그대로 pop — backend 제출 로직은 아직 미구현(Fix #665 TODO).
Frequency 이벤트 1회당 최대 1회(제출 후 read-only). 미제출 상태에서는 dismiss / 재진입 반복 가능.

Cross-cutting interactions

사용자 액션화면에 보이는 결과
swipe-down sheet drag-to-dismiss (Material 3 default detents). drag distance threshold 넘으면 slide-down + scrim fade-out → HomePage 복귀. submitting 중에는 차단 권장.
scrim tap (sheet 외부 영역) sheet dismiss (위와 동일 motion). isDismissible: true default. submitting 중에는 차단 권장.
system back / 안드로이드 back gesture sheet pop. 미제출이면 EventNowBar는 ended state 유지 — 다음 진입에 같은 sheet를 다시 push 가능.
제출 성공 auto pop → HomePage 복귀 + parent에서 success snackbar("리뷰가 등록되었어요"). EventNowBar는 다음 stream tick에 사라지거나 read-only 전환.
다크 모드 토글 sheet bg → color-dark-background. handle / 텍스트 / 별 컬러 dark 토큰으로 자동 swap. scrim 그대로.
existingReview 갱신 (실시간) sheet 열려 있는 상태에서 stream이 새 데이터 emit하면 default → alreadySubmitted로 cut 교체 (transition 미정의).

Global edge cases

  • 0별 제출 방지 — _rating == 0 상태의 CTA는 disabled가 권장 정책. 현재 widget은 그대로 pop만 하므로 향후 backend 도입 시 수정 필요.
  • 1회 한정 — 한 사용자 / 한 이벤트 / 한 리뷰. alreadySubmitted state에서는 별점 수정 불가. 정책 변경 시 별도 edit 화면 도입 검토.
  • 재진입 deeplink — push 알림 / MyPage "지난 이벤트" 등 EventNowBar 외에서도 같은 route로 진입 가능. 이 경우 alreadySubmitted state로 자주 진입.
  • submitting dismiss 차단 — 네트워크 진행 중 swipe/scrim/back으로 닫으면 user intent ambiguity 발생. WillPopScope + sheet isDismissible: false로 차단 권장 (현재 미구현).
  • 익명성 — 별점은 partner side에 평균값으로만 노출. 개별 사용자 식별 X. 본 spec은 capture surface — 노출 surface는 별도(파트너 분석 페이지).

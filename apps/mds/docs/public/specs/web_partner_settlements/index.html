Children: 상세 펼침 패널 · 계좌 관리 섹션은 internal — 별도 spec 없음.
Purpose 파트너가 "언제 얼마가 들어오는지"를 한 화면에서 확인한다. 이벤트가 끝나면 정산이 자동으로 만들어지고 14일 보류 후 등록된 계좌로 자동 지급되므로, 이 화면은 조회 전용이다 — 파트너가 할 수 있는 유일한 액션은 정산 계좌 등록/변경.
User journey Entry points: 사이드바 "정산" 클릭 · 홈 "최근 정산" 카드 클릭 · 지급 완료 알림 메일의 링크 · URL 직접 진입.
Exit points: 사이드바 다른 메뉴 · 정산 행의 이벤트명 → 해당 이벤트 상세 (파티·이벤트) · 비로그인이면 파트너 로그인으로. 계좌 등록/변경은 이 화면 안에서 완결.
Background 정산 파이프라인은 이벤트 완료 → 정산 자동 생성 → 14일 환불 보류 → 자동 지급으로 동작하며 수수료는 PG 3.5% + 플랫폼 5% (docs/features/settlement/partner-settlement/prd.md). 파트너 액션이 끼어들 지점이 없으므로 웹에서는 모바일의 "목록 → 상세 → 계좌" 3-화면 push 구조를 요약 카드 → 테이블(행 펼침) → 계좌 섹션의 단일 페이지로 평탄화했다. 모바일의 7개 상태 중 파트너에게 의미 있는 3개(보류 중 / 지급 준비 / 지급 완료)를 기본 badge로 쓰고, 실패·보류 등 예외는 "지급 보류 — 확인 필요"로 묶어 계좌 확인을 안내한다. 계좌 미등록은 가장 중요한 경고 — 보류가 끝나도 지급이 멈추므로 배너 + 카드 + 섹션 3중으로 안내한다.
Frequency 월 1–2회 + 지급 완료 알림 수신 직후. 계좌 관리는 입점 직후 1회 + 비정기 변경.

Responsive Layout

화면 구조 — 영역, 정렬, 간격 규칙. 색·타이포 무시. web_partner는 데스크톱 우선 (web_foundation_responsive surface priority) — Desktop(≥1280) blueprint가 1차 산출물.

Breakpoint variants

Breakpoint · 컨테이너 · 그리드 정의의 SSOT는 web_foundation_responsive. 콘솔 셸 규칙은 web_partner_home과 동일 — 셸 전체 폭 1440px 캡, 사이드바 240px 고정 + 메인 fluid.

Sub-anatomy ① — 사이드바 (콘솔 셸 네비)

구조·치수·토큰의 SSOT는 web_partner_home Sub-anatomy ① — 여기서 재정의하지 않는다. 이 화면에서의 차이는 단 하나: active 항목이 "정산" (color-primary 10% tint bg + primary text). 신청 관리 badge 등 다른 규칙은 셸 공통.

Sub-anatomy ③ — 요약 카드 (SummaryCard)

3장 고정: 지급 예정 금액(보류 중 + 지급 준비 합계) · 다음 지급일 · 정산 계좌(마스킹 계좌 + 인증 상태). 카드는 조회 전용 — 정산 계좌 카드의 하단 링크만 페이지 하단 계좌 관리 섹션으로 스크롤 이동. 계좌 미등록이면 정산 계좌 카드가 경고 variant로 바뀐다.

Sub-anatomy ④ — 정산 테이블 (SettlementRow + ExpandedDetailPanel)

1행 = 이벤트 1건의 정산. 정렬은 이벤트 종료일 내림차순, 기간 선택(기본: 최근 3개월) 안에서만 표시. 금액 흐름이 왼→오로 읽히도록 컬럼 순서는 매출 → 환불 차감 → 수수료 → 지급액 (환불을 뺀 금액에 수수료가 걸리는 계산 순서 그대로). 행 전체가 클릭 타깃 — 클릭 시 행 아래로 상세 패널이 펼쳐진다 (한 번에 1행만, 다른 행 클릭 시 기존 펼침은 닫힘).

Global edge cases

  • 네트워크 끊김 — 메인 콘텐츠 영역만 "다시 시도" 안내로 교체 (사이드바는 유지). 계좌 저장 중 끊기면 "저장하지 못했어요 — 다시 시도해 주세요" 안내, 입력값은 보존.
  • 다크 모드 — 우측 상단 Dark 토글로 확인. surface/배경/텍스트 토큰 전환 + primary → color-partner-dark-primary. 상태 badge·경고 배너는 색 tint만 전환.
  • 접근성 — 테이블 행은 펼침 토글 버튼 의미 (Enter/Space로 펼침·접힘, 펼침 여부가 보조기기에 전달). tab 순서: 사이드바 → 요약 카드 링크 → 기간 선택 → 행 순서대로 → 계좌 섹션 버튼/폼. 모든 클릭 타깃에 visible focus ring. badge는 색만이 아니라 텍스트로 상태 전달. 차감 금액은 "차감"이 라벨로 함께 읽히도록.
  • reduced motion — prefers-reduced-motion 시 펼침은 즉시 전환, shimmer 정지, 부드러운 스크롤은 점프로.
  • SEO / 공유 — 비공개 콘솔 화면. noindex — og 메타 불필요.
  • 초광폭 (≥1920px) — 콘솔 셸 1440px 캡 중앙 정렬, 잉여 폭은 배경 (web_foundation_responsive 도구 화면 규칙).
  • 권한 분기 없음 — 모바일의 "정산 편집 권한 보유 시만 계좌 진입" 게이트는 웹 MVP에 없음: 멤버/권한 관리가 deprecated라 파트너 계정 1개 = 전체 권한. 계좌 섹션 항상 노출.
  • 재지급 요청 · CSV 다운로드 범위 외 — 모바일 상세의 두 액션은 웹 MVP에서 제외. 지급 실패는 자동 재시도 + 계좌 확인 안내로 대체, 명세 다운로드는 후속 단계 (모바일 PRD의 PDF 다운로드와 함께 검토).

구현 가이드

1 DialogTheme -- MaterialTheme에 추가

앱 전역 다이얼로그 스타일을 통일합니다. surfaceTintColor: transparent로 Material 3 기본 틴트를 제거합니다.

dialogTheme: DialogThemeData( backgroundColor: MinglitColors.background, surfaceTintColor: Colors.transparent, shape: RoundedRectangleBorder( borderRadius: BorderRadius.circular(MinglitRadius.dialog), // 28 ), elevation: 0, shadowColor: Colors.transparent, titleTextStyle: textTheme.titleMedium?.copyWith( fontWeight: FontWeight.bold, ), ),

2 신규 토큰 -- MinglitRadius.dialog

기존 MinglitRadius 클래스에 dialog = 28을 추가합니다. 기존 card = 16과 구분합니다.

class MinglitRadius { static const double small = 8; static const double button = 12; static const double card = 16; static const double dialog = 28; // NEW static const double chip = 100; }

3 Selection Dialogs -- SimpleDialog를 BottomSheet로 전환

showDialog + SimpleDialog 사용처를 showModalBottomSheet + MinglitBottomSheetPicker로 교체합니다. 터치 타겟은 56px 이상을 보장합니다.

await showModalBottomSheet( context: context, backgroundColor: MinglitColors.background, shape: const RoundedRectangleBorder( borderRadius: BorderRadius.vertical( top: Radius.circular(MinglitRadius.dialog), ), ), builder: (_) => MinglitBottomSheetPicker( title: '테마 설정', items: themeOptions, selected: currentTheme, onChanged: (value) { ... }, ), );

4 Background Color 전략

다이얼로그 배경은 MinglitColors.background (#FFFFFF)를 사용하여 scaffoldBackgroundColor (#F9FAFB) 대비 미묘한 elevation 효과를 만듭니다. 이는 스크림 위에 떠 있는 느낌을 강화합니다.

다크 모드에서는 MinglitColorsDark.surface (#212121)를 사용하여 #0F0F0F 배경 대비 동일한 계층 분리를 유지합니다.

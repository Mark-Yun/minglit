## 감사 결과

### 배경

2026년 1월 22일부터 **AI 기본법(인공지능 발전과 신뢰 기반 조성 등에 관한 기본법)**이 시행되었다. 현재 1년간 과태료 유예 기간이나, 시정명령은 가능하다.

또한 개인정보보호법에 **자동화된 결정에 관한 정보주체의 권리** 조항이 신설되어, 자동화된 결정이 정보주체의 권리·의무에 영향을 미치는 경우 설명 요구권과 거부권이 인정된다.

### 현황

| 항목 | 현재 상태 |
|------|----------|
| OpenAI 임베딩 사용 | 개인정보처리방침 제3자 제공 테이블에 "프로필 임베딩 생성" 기재 ✓ |
| 추천 알고리즘 작동 방식 고지 | ❌ 없음 — 사용자에게 AI 기반 추천임을 알리지 않음 |
| 자동화된 의사결정 설명 요구권 | ❌ 미구현 — 추천/매칭 결과에 대한 설명 제공 수단 없음 |
| AI 산출물 표시 | ❌ 없음 — AI가 생성한 추천/매칭 결과에 AI 관여 표시 없음 |

### 필요 조치

| # | 조치 | 긴급도 |
|---|------|--------|
| 1 | 개인정보처리방침에 "자동화된 의사결정" 항목 추가: AI 기반 추천/매칭 작동 방식, 처리되는 데이터, 사용자에 미치는 영향 기술 | 중 |
| 2 | 이용약관에 AI 활용 고지 조항 추가 | 중 |
| 3 | 추천/매칭 UI에 "AI 추천" 라벨 표시 검토 (AI 기본법 표시 의무) | 하 |
| 4 | 자동화된 의사결정 설명 요구 채널 마련 (고객센터 또는 인앱) | 하 |

### 참고

- AI 기본법 과태료 유예 기간: ~2027년 1월까지
- 개인정보보호위원회 '자동화된 결정' 고시 제정안 공개 상태
- 현재 밍글릿의 AI 사용은 임베딩 기반 유사도 추천이므로 "중대한 영향을 미치는 자동화된 결정"에는 해당하지 않을 가능성 높음 → 그러나 고지 의무는 별도

### 위험도

현재 유예 기간이므로 즉시 제재 위험은 낮으나, 2027년 이전에 대응을 완료해야 한다. 선제 대응 시 사용자 신뢰도 제고 효과도 기대할 수 있다.

### AI 기본법 적용 평가

#### 밍글릿의 AI가 "고영향 AI"인가?

**아닙니다.** AI 기본법 제27조의 "고영향 인공지능"은 사람의 생명·신체·안전, 기본권에 중대한 영향을 미치는 경우입니다. 밍글릿의 임베딩 기반 이벤트 추천과 태그 추출은 이에 해당하지 않습니다.

#### 그러나 아래 의무는 적용됩니다:

| 의무 | 법적 근거 | 현재 상태 | 조치 필요 |
|------|----------|----------|----------|
| AI 활용 사전 고지 | AI 기본법 제22조 (투명성) | ⚠️ "AI 추천" UI 라벨만 존재 | 이용약관/처리방침에 명시 필요 |
| 자동화된 결정 설명 요구권 | 개인정보보호법 제37조의2 | ❌ 미구현 | 설명 요구 채널 마련 필요 |
| AI 산출물 표시 | AI 기본법 제23조 | ⚠️ "AI 추천" 라벨 부분 충족 | 태그 추출 결과에도 표시 필요 |

### 구체적 조치 권고

#### P1 — 즉시 (개인정보처리방침 정확성)

**1. 해외이전 테이블 오기재 수정** (유저 처리방침)
- 현재: "프로필 텍스트 → 프로필 임베딩 생성"
- 수정: "이벤트 정보(제목, 설명, 태그, 장소명) → 이벤트 추천을 위한 벡터 임베딩 생성 및 태그 자동 추출"

**2. 파트너 처리방침에 OpenAI 해외이전 추가**
- `apps/landing_partner/src/app/privacy/page.tsx`에 OpenAI 해외이전 항목 추가
- 이전 항목: "파트너가 등록한 이벤트 정보(제목, 설명, 태그, 장소명)"
- 이전 목적: "이벤트 추천 벡터 생성 및 태그 자동 추출"

#### P2 — 이번 분기 (AI 기본법 대응)

**3. 이용약관에 AI 활용 조항 추가** (#1450과 병합 가능)
```
제N조 (인공지능 활용)
1. 회사는 서비스 품질 향상을 위해 인공지능(AI) 기술을 활용합니다.
2. AI가 활용되는 기능:
   - 이벤트 추천: 이용자의 관심사와 활동 이력을 바탕으로 맞춤형 이벤트를 추천합니다.
   - 태그 추출: 이벤트 설명에서 관련 태그를 자동으로 추출합니다.
3. AI 기반 추천은 참고 정보이며, 최종 참여 결정은 이용자에게 있습니다.
4. 이용자는 AI를 활용한 자동화된 결정에 대해 설명을 요구할 수 있으며, support@minglit.com으로 문의할 수 있습니다.
```

**4. 개인정보처리방침에 자동화된 의사결정 섹션 추가**
```
## 자동화된 의사결정

1. 회사는 이용자의 서비스 이용 기록(조회, 좋아요, 참여 이력)을 분석하여 맞춤형 이벤트를 추천합니다.
2. 추천 알고리즘은 벡터 유사도 기반으로 작동하며, 이용자의 활동에 가중치를 부여합니다.
3. 이용자는 자동화된 결정에 대해 설명을 요구하거나 거부할 수 있습니다 (support@minglit.com).
4. 임베딩 벡터는 회원 탈퇴 시 즉시 파기됩니다.
```

#### P3 — 여유 시

- 추천 피드에 "AI가 추천한 이벤트입니다" 설명 추가 검토

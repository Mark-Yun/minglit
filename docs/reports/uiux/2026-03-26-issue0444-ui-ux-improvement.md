## UI/UX 개선 제안 — 2026-03-26

감사 결과 + 2026 업계 트렌드 기반 개선 제안입니다.

---

### 1. 다크모드 골든 테스트 부재

**현재 문제:** 골든 테스트가 라이트 모드만 커버하고 있어, 다크모드 UI 회귀를 감지할 수 없음.
**업계 트렌드:** 2026년 다크모드는 기본 기대 기능으로, 라이트/다크 전환이 앱 리텐션에 직접적 영향.
**개선 방향:**
- 기존 5개 골든 테스트에 다크모드 variant 추가
- `MinglitColorsDark` 토큰이 실제 화면에서 올바르게 적용되는지 시각적 검증
- 골든 테스트 헬퍼에 `brightness: Brightness.dark` 옵션 추가

### 2. 하드코딩 스페이싱 일괄 마이그레이션 (101건)

**현재 문제:** 45개 파일에서 `SizedBox(height/width: 숫자)` 직접 사용 — 디자인 시스템 일관성 저해.
**개선 방향:**
- `MinglitSpacing` 토큰에 누락된 값 추가 검토 (2, 3, 6, 24, 32, 48, 100 등 현재 사용되지만 토큰에 없는 값)
- Lint rule `minglit_no_hardcoded_spacing` 커스텀 린트 도입 검토
- 우선순위: settlement 관련 파일(11건), event_card(9건), bug_reporter(8건) 순서로 마이그레이션

### 3. 골든 테스트 커버리지 확대 (현재 10.4%)

**현재 문제:** 48개 페이지/스크린 중 5개만 골든 테스트 존재. app_partner는 PNG 이미지도 미생성.
**개선 방향:**
- 핵심 사용자 플로우 페이지 우선 커버: `event_detail_page`, `party_curation_page`, `partner_apply_page`
- app_partner 골든 이미지 생성 파이프라인 점검 (테스트 파일은 있으나 PNG 미생성)
- 골든 테스트 내 한국어 폰트 로딩 설정 추가 (현재 squares로 렌더링 — 시각 회귀 검증 불가)

### 4. 접근성(Accessibility) 강화

**업계 트렌드:** WCAG 2.2 기준 터치 타겟 최소 44x44dp 필수. 2026-2027 미국 HHS 규제 강화.
**현재 문제:** 골든 이미지 분석 결과, 일부 소셜 버튼 및 필터 칩의 터치 영역이 작아 보임.
**개선 방향:**
- `minglit_social_action_chip.dart`, `minglit_filter_chip.dart` 등 인터랙티브 요소의 최소 터치 영역 44dp 보장
- `MinglitDesignTokens`에 `MinglitTouchTarget.minimum = 44.0` 토큰 추가 검토
- Semantics 위젯 활용도 점검 (스크린 리더 지원)

### 5. 마이크로 애니메이션 & 모션 디자인

**업계 트렌드:** 2026년 모션 디자인이 핵심 차별화 요소. 미세한 루프, 작은 애니메이션이 사용자 참여도 향상.
**현재 상태:** `MinglitAnimation` 토큰(fast/medium/slow)은 정의되어 있으나 실제 적용 범위 미확인.
**개선 방향:**
- 이벤트 카드 로딩 시 staggered animation 적용
- 빈 상태(empty state) 화면에 subtle illustration animation 도입
- 페이지 전환 시 shared element transition 활용 확대

### 6. 디자인 토큰 문서화 완성

**현재 문제:** `MinglitBorders`, `MinglitDecorations`, `MinglitTextStyles` 3개 클래스가 코드에 존재하지만 `01-foundation.md`에 문서화되지 않음. `MinglitElevation` vs `MinglitShadows` 네이밍 불일치.
**개선 방향:**
- 누락된 3개 클래스를 foundation 문서에 추가
- `MinglitElevation` TODO를 `MinglitShadows`로 업데이트하여 코드와 일치시키기

## UI/UX 개선 제안 — 2026-03-26

감사 결과(#440)와 업계 트렌드 조사를 기반으로 한 개선 제안입니다.

### P1 — 높은 임팩트, 낮은 노력

#### 1. `MinglitTypography` 토큰 클래스 추가
`fontSize: 13`, `fontSize: 11` 등 하드코딩된 폰트 사이즈를 제거하기 위한 토큰 클래스.

```dart
class MinglitTypography {
  static const double micro = 11;   // 디버그 오버레이, 마이크로 라벨
  static const double label = 13;   // 카드 칩, 뱃지, 보조 정보
  static const double small = 14;   // 작은 본문, 칩 라벨
  static const double body = 16;    // 본문 (bodyMedium 대응)
  static const double appBarTitle = 18;
}
```

**대상 파일**: `event_card.dart` (4곳), `user_session_info.dart` (5곳), `minglit_social_button.dart`, `ticket_list_item.dart` 등 총 18곳

#### 2. 접근성: `MinglitFilterChip` 시맨틱스 + 최소 터치 영역
WCAG 2.2 기준 2.5.8 — 최소 터치 영역 44×44px 미달. `small` 사이즈 칩의 실제 높이 ≈ 16px.

```dart
Semantics(
  label: label,
  selected: isSelected,
  button: true,
  child: ConstrainedBox(
    constraints: const BoxConstraints(minHeight: 44),
    child: /* 기존 Container */,
  ),
)
```

#### 3. 접근성: `MinglitParticipantGauge` 시맨틱 라벨
스크린 리더가 "12/20"을 맥락 없이 읽음. 시맨틱 라벨 필요.

```dart
Semantics(
  label: '참여자 $current명 / 최대 $max명',
  excludeSemantics: true,
  child: /* 기존 위젯 */,
)
```

### P2 — 중간 임팩트, 중간 노력

#### 4. `minglit_kit` 공유 위젯 Golden 테스트 추가
현재 `minglit_kit` 자체에 golden 테스트가 0개. 디자인 토큰 변경 시 공유 위젯 회귀를 감지할 수 없음.

**권장 테스트 매트릭스 (MinglitEventCard)**:
- `event_card_loading.png`
- `event_card_full_data.png`
- `event_card_sold_out.png`
- `event_card_today.png`
- `event_card_dark.png`

**전체 페이지 커버리지**: 현재 5/48 페이지만 golden 테스트 보유 (10.4%)

#### 5. 다크 모드 Golden 테스트 추가
기존 golden 헬퍼가 항상 `MinglitTheme.materialTheme`만 사용. `MinglitColorsDark` 관련 회귀 감지 불가.

#### 6. `MinglitOpacity` 토큰 클래스 추가
`event_card.dart`에서 `withValues(alpha: 0.55)`, `0.45`, `0.3` 등이 인라인으로 사용됨.

```dart
class MinglitOpacity {
  static const double tintFill = 0.05;
  static const double placeholder = 0.2;
  static const double muted = 0.3;
  static const double overlay = 0.55;
  static const double scrimLight = 0.8;
}
```

#### 7. 누락된 토큰 추가
- `MinglitAnimation.micro = Duration(milliseconds: 100)` — 마이크로 인터랙션용
- `MinglitRadius.chip = 100` — 현재 `MinglitFilterChip`에서 `100` 하드코딩
- `MinglitSpacing.xxlarge = 48` — WCAG 2.2 권장 터치 영역 대응

### P3 — 장기 개선

#### 8. `animations` 패키지 도입
`SharedAxisTransition` (파티→이벤트 네비게이션), `FadeThroughTransition` (하단 탭 전환). Material 3 모션 스펙 준수.

#### 9. `MinglitChipGroup` 합성 위젯 추출
탐색/피드 화면의 필터 행이 매번 수동으로 `SingleChildScrollView + Row + MinglitFilterChip` 조합. DRY화.

#### 10. 이벤트 카드 상태별 시각화 강화
- **마감 상태**: `currentParticipants >= maxParticipants` 시 반투명 스크림 + "마감" 라벨 오버레이
- **오늘 마감**: `dDayLabel == '오늘'` 시 펄싱 amber 보더 (`MinglitAnimation.slow`)
- **스크롤 진입**: 카드가 뷰포트에 들어올 때 이미지 opacity 0.85→1.0 애니메이션

#### 11. 다크 테마 통합
`materialThemeDark`가 `_MinglitComponentThemes`와 별도로 스타일을 하드코딩. `ColorScheme` 파라미터를 받는 팩토리 메서드로 통합하여 light/dark 드리프트 방지.

#### 12. 접근성 추가 개선
- `MinglitColors.secondary` (0xFFFF9900, amber) 흰 배경 대비 비율 ≈ 2.8:1 — WCAG AA 미달 (4.5:1 필요). 가격 라벨 등에서 사용.
- `MinglitEventCard` 이미지 영역 `Semantics(label:...)` 누락
- `event_application_wizard_page.dart` — `FocusScope` 트래버설 순서 설정 필요

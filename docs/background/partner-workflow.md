# Partner Workflow

> Partner가 minglit을 통해 모임을 운영하는 전체 흐름. 각 단계에서 minglit이 자동화/보조하는 부분 + Partner 책임 영역 구분.

## 12-Step End-to-End Flow

| # | 단계 | Partner 책임 | minglit 자동화/보조 |
|---|------|------------|------------------|
| 1 | **파티 기획** | 컨셉, 인원, 가격, 타겟 설정 | Party 템플릿 등록 UI |
| 2 | **장소 대여** | 외부 플랫폼(스페이스클라우드 등)에서 검색·예약 | (외부 — 향후 연동 검토 가능) |
| 3 | **장소 결제 미리** | 본인 비용으로 선결제 | (외부) |
| 4 | **이벤트 공지** | 컨셉 설명, 사진, 시간/장소 입력 | Event 등록 + 사용자 피드 노출 + 추천 알고리즘 |
| 5 | **참여자 모집 + 승인 관리** | Qualification 검토 + 승인/거부 결정 | Application 결제 자동 + Qualification 통과자 자동 추가 + 미통과자 승인 대기 큐 |
| 6 | **최소 인원 확정 또는 다음 이벤트로 이월** | 진행 여부 결정 (현재 수동) | **(미구현 기능)** 최소 참여자 미달 시 자동으로 다음 RecurrenceRule 이벤트로 사용자 이월 |
| 7 | **진행** | 현장 운영 (자리 안내, 로테이션 진행) | (외부 — 현장 운영 도구는 향후 검토) |
| 8 | **체크인** | QR 스캔 (Staff 권한) | QR 검증 (Ed25519) + 매칭 자격 게이트 + 정산 대상 확정 |
| 9 | **파티 진행** | 라운드 운영, 분위기 관리 | (외부) |
| 10 | **매칭 서비스 가동** | (자동) | MatchVote 수집 → mutual interest 검출 → MatchPair 자동 생성 |
| 11 | **연락처 교환** | (자동) | 매칭된 User들에게 상호 연락처 공유 |
| 12 | **정산** | 정산 계좌만 등록 | 체크인 기반 정산 산정 + 14일 hold 후 PortOne 자동 송금 (수수료 차감) |

## 미구현 핵심 기능 (Feature Gap)

### 최소 참여자 미달 시 다음 이벤트 이월
**상태**: 미구현
**이유**: Partner가 정기 운영 시, 최소 인원 미달 이벤트를 취소하지 않고 다음 회차로 사용자를 자동 이월하면 cancel-rebook 마찰 제거 + RecurrenceRule와 시너지 + Partner retention ↑.
**관련 entity**: Event, RecurrenceRule, Application

### 외부 자동화 후보
- 장소 대여 플랫폼 연동 (스페이스클라우드 API)
- 현장 운영 도구 (자리 안내, 로테이션 타이머)

## minglit이 자동화하는 핵심 가치

**Partner는 컨셉/큐레이션에 집중, minglit은 인프라 처리** (product-thesis.md 분업 모델):
- ✅ 결제·환불·정산
- ✅ 신원 인증 (Identity)
- ✅ 자유폼 Verification 양식
- ✅ 참여자 자동 매칭
- ✅ 추천/유저 유입
- ✅ 정기 반복 자동화 (RecurrenceRule)
- 🔲 미구현: 최소 인원 이월
- ❌ 외부: 장소 예약, 현장 진행

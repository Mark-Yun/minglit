# Personas

> minglit이 명확히 타겟하는 사용자 그룹 정의. WHY는 product-thesis.md, WHAT은 glossary.md 참조.

## 1차 타겟: Partner

### 페르소나 P-1 — 모임 전문 사업자
- **누구**: 로테이션 소개팅, 파티 운영을 본업/부업으로 하는 사업자
- **현재 채널**: 네이버 카페, 인스타그램, 자체 웹사이트, 오프라인 입소문
- **고통점**:
  - 매번 결제·환불·정산 수동 처리
  - 참가자 인증 (재직증명서, 사진 등)을 카톡/메일로 받아서 검토
  - 매칭 결과를 엑셀이나 종이로 정리
  - 정기 운영 시 매번 새 모임 셋업 반복 (자동화 부재)
- **minglit 가치**: 위 고통점 전부 자동화 → 본업인 "모임 컨셉/큐레이션"에 집중
- **운영 빈도**: 보통 매월 1회 정기
- **모임 규모**: 4:4 ~ 12:12 (로테이션 표준 규모)

### 페르소나 P-2 — 개인 호스트 / 프리랜서
- **누구**: 사람 맺어주는 걸 좋아하는 개인 (결정사 매니저 출신, 네트워킹 호스트)
- **현재**: 정식 사업 X, 친구·지인 모임으로 시작
- **고통점**: 사업화 진입장벽 (결제 인프라, 법적 책임, 유저 모집)
- **minglit 가치**: 사업자 등록 없이 minglit 위에서 운영 가능 → 사이드잡 → 본업 전환 경로
- **장기 진화**: 본업 사업자 P-1으로 성장

## 2차 타겟: User (참가자)

### 페르소나 U-1 — 미혼 직장인 (1차 GTM 타겟)
- **연령**: 20대 중후반 ~ 30대 (1차 핵심)
- **성별**: 미혼 남녀 (성비 균형 모델 — EntryGroup 쿼터로 강제)
- **직업**: 직장인 위주 (학생·프리랜서도 일부)
- **라이프 스테이지**: single (향후 돌싱 확대 예정)
- **시장 포지션**: **결정사 vs 데이팅앱 사이의 mid-market**
  - 결정사 (듀오/가연): 비싸고 부담 — 부모 재력까지 노출되는 "투머치"
  - 데이팅앱 (틴더/범블): 노이즈 많고 진지함 부족, 검증 X
  - 카페/인스타 모임: 검증 부족, 안전 우려, 환불 X
  - **minglit = 평범한 사람들의 평범한 만남** (검증된 mid-market)

### 페르소나 U-2 — 미래 확장 (보류)
- **돌싱 / 재혼 시장** — 향후 확대 예정
- **전제**: U-1으로 PMF 확보 후

### 가격 민감도
- 1회 참가비 적정선: **4-6만원** 
- 무료 모임 비중: 미정
- 기존 시장 시세: 2-5만원 (감정적인 오렌지 일반 28K / 한남 특집 40K-65K) — 우리는 약간 프리미엄
- 정기 구독 모델: 검토 단계 아님

### 사회 트렌드 컨텍스트 (미들마켓이 존재하는 이유)

현대 사회 변화로 새로운 시장이 열림:
- **AI/개인화 가속** → 사람들이 점점 알고리즘 안에서 살게 됨
- **친구 수 감소** → 자연스러운 소개 채널 약화
- **검증 없는 만남에 대한 거부감** → 데이팅앱 피로 ↑
- **결혼 압박 회피** → 결정사는 부담스러움
- **결과**: "검증은 됐으면 좋겠지만 결혼 압박은 없는" 평범한 만남 수요가 빈 자리로 남음

### USP 방향성 (카피라이트 작성용 메모)
사용자가 minglit을 선택할 핵심 이유 3가지 + 1:
1. 한 번 가입하면 모든 컨셉의 모임이 한 플랫폼 안에 (vs 데이팅앱마다 가입/인증 반복)
2. 검증된 사람들과만 (vs 카페/인스타 모임의 unverified)
3. 결정사 가격의 일부, 압박 없음 (vs 결정사 투머치)
4. **+ 데이팅앱보다 신뢰할 수 있는** (검증·결제·환불·매칭 자동화 — 플랫폼 책임)

⚠️ 카피라이트 자체는 별도 작업 (마케팅 카피 도출은 추후)

## 흡수 대상 시장 (간접 페르소나)

한국 로테이션 소개팅 업체 중 minglit이 흡수하려는 1차 대상:
- **감정적인 오렌지들** — 핵심 벤치마크. 사실상 진행 모델 그대로. 강점: 신분증 검사로 신뢰 형성. 빠른 전국 확장 (21개 지역, 주 1,300명+ 참여).
- **토크블라썸** — 16:16 모델, 직업/재력/매력 인증 엄격.

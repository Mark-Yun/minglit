**적용 범위:** minglit은 회원 이름·생년월일·성별·휴대폰번호·CI/DI·이메일·관심 태그·기기 정보·이용 기록을 수집하며 전면 적용.

**최근 개정 시행일:**

**minglit 핵심 영향:**

| 조항 | 내용 | 우리 영향 |

- PII 마스킹: Axiom 로그 경로에 `pii_masker.ts` 적용, `maskJsonString` 유틸 (Fix #763)
- 개인정보처리방침: landing_user + landing_partner 분리 게시
- 자동화된 의사결정 섹션: 추천 알고리즘 방식·처리 데이터·설명 요구권 명시 (PR #1455)

## 3. 전자상거래 등에서의 소비자보호에 관한 법률 (전자상거래법)

**적용 범위:** 통신판매업자 (minglit은 플랫폼 결제 운영).

**2026-07-21 개정 시행 예정** — 환불 정책 점검 필요.

**minglit 핵심 영향:**

| 조항 | 내용 | 우리 대응 |
|------|------|----------|
| 제6조 거래기록 보존 | 계약·청약철회 5년, 소비자불만·분쟁처리 3년 보존 | `event_applications`·`tickets`·`ticket_templates`: `legal_min_days=1825`, `enabled=false` (20260422000003_payment_retention_protection.sql) |
| 제17조 청약철회 | 7일 이내 청약철회 가능 | 자동 환불 cutoffDays=7 (이벤트 7일 전) |
| 제18조 환불 처리 | 3영업일 이내 환불 | PortOne 즉시 취소 API 호출 |
| 제21조의2 약관변경 고지 | 7일(불리한 경우 30일) 전 고지 의무 | 이용약관 §5 약관게시 및 변경 조항 추가 (PR #1454) |
| 제33조 분쟁해결 절차 | 관할법원·소비자원 안내 의무 | 이용약관 §7 분쟁해결 조항 추가 (PR #1454) |

**우리가 하고 있는 것:**
- 자동 환불 정책: `get_current_policy('refund')` RPC로 동적 조회
  - `grace_period_hours=2`: 결제 후 2시간 이내 cooling off 환불
  - `cutoff_days=7`: 이벤트 시작 7일 전까지 환불 가능
  - 과거 약관(3/2/1일 기준)과 코드 불일치 → 현행 코드(2시간/7일)로 약관 통일 (PR #1144, Fix #1140)
- 5년 보존 방어: `payment_retention_protection` migration으로 `event_applications`, `tickets`, `ticket_templates` 테이블에 `legal_min_days=1825` 등록 → 후속 개발자가 실수로 삭제 정책 작성 시 CHECK 제약으로 차단
- **통신판매업 신고**: ❌ **현재 미보유** (2026-04-27 기준)
- **표시 위치**: `<TODO: 신고 후 어느 페이지에 어떻게 표시할지 결정 — 일반적으로 푸터, 사업자정보 페이지>`
- **위험**: 미신고 운영은 전자상거래법 위반 — 우선순위 ↑

**알려진 갭/이슈:**

| minglit AI 기능 | 기술 | OpenAI 전송 여부 |

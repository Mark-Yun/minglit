## 2. 플로우별 테스트 케이스

### U04: 내 티켓 → QR → 입장

#### TC-U04-001: 내 티켓 목록 정상 표시
- Given: 로그인 상태, 유료 이벤트 1건 결제 완료
- When: 내 티켓 페이지 진입
- Then: 결제완료/승인됨 티켓만 표시, 대기/거절/환불 제외

#### TC-U04-002: QR 코드 정상 생성 및 표시
- Given: 승인된 티켓 보유
- When: 티켓 카드 탭 → QR 페이지 진입
- Then: QR 코드 렌더링, 이벤트명/날짜/좌석 정보 표시

#### TC-U04-003: QR 코드 자동 갱신
- Given: QR 페이지 열린 상태
- When: 30초 경과
- Then: QR 토큰 갱신 (replay attack 방지)

#### TC-U04-004: 오프라인 상태에서 QR 표시
- Given: QR 페이지 진입 후 네트워크 끊김
- When: 화면 유지
- Then: 마지막 생성된 QR 유지, "오프라인" 배너 표시

#### TC-U04-005: 빈 티켓 상태
- Given: 로그인 상태, 활성 티켓 없음
- When: 내 티켓 페이지 진입
- Then: "참가 예정인 이벤트가 없어요" + 이벤트 탐색 CTA

#### TC-U04-006: 과거 이벤트 티켓 분리
- Given: 과거 + 미래 티켓 보유
- When: 내 티켓 페이지 진입
- Then: "예정" / "지난 이벤트" 섹션 분리, 시간순 정렬

### U05: 체크인 → 매칭 투표 → 결과

#### TC-U05-001: 체크인 완료 후 매칭 투표 화면 전환
- Given: QR 스캔으로 체크인 완료
- When: 이벤트 시작 시간 도래 + 매칭 활성화
- Then: 이벤트 나우바 "매칭" 상태, 투표 바텀시트 표시

#### TC-U05-002: 매칭 투표 제출
- Given: 매칭 화면, 참가자 목록 표시
- When: 관심 있는 참가자 선택 → 제출
- Then: "투표 완료" 확인, 결과 대기 상태 전환

#### TC-U05-003: 매칭 결과 확인
- Given: 투표 마감 후 결과 생성
- When: 결과 알림 수신 or 나우바 "결과" 상태 탭
- Then: 매칭 성공/실패 결과 표시, 성공 시 상대 정보 공개

#### TC-U05-004: 매칭 미참여 (시간 초과)
- Given: 매칭 시간 내 투표 미제출
- When: 투표 마감
- Then: "참여하지 않은 매칭" 표시, 결과에서 제외

#### TC-U05-005: 매칭 대상 없음 (1인 체크인)
- Given: 체크인 참가자 1명
- When: 매칭 시간 도래
- Then: "매칭 가능한 참가자가 부족합니다" 안내

### U07: 계정 삭제

#### TC-U07-001: 탈퇴 사유 선택 화면
- Given: 마이페이지 → 개인정보 → 회원 탈퇴
- When: DeletionReasonPage 진입
- Then: 6개 사유 라디오 버튼 + "기타" 자유 입력 (200자 제한)

#### TC-U07-002: 활성 예약 차단
- Given: 예정된 이벤트 티켓 보유
- When: 탈퇴 시도
- Then: "예정된 이벤트가 있어 탈퇴할 수 없습니다" + 이벤트 목록

#### TC-U07-003: 미정산 잔액 차단
- Given: 환불 처리 중 건 존재
- When: 탈퇴 시도
- Then: "처리 중인 환불이 있습니다" 안내

#### TC-U07-004: 정상 탈퇴 흐름
- Given: 차단 조건 없음, 사유 선택 완료
- When: 사유 → 안내 → 본인인증 → 완료
- Then: deleted_at 설정, 7일 유예기간, 3초 후 로그아웃

#### TC-U07-005: 유예기간 내 철회
- Given: 탈퇴 요청 후 7일 이내
- When: 재로그인 → 철회 다이얼로그 → "돌아가기"
- Then: deleted_at 초기화, 정상 이용 복귀

#### TC-U07-006: 유예기간 만료 후 재가입 차단
- Given: 탈퇴 확정 (7일 경과)
- When: 동일 DI로 회원가입 시도
- Then: "30일간 재가입이 불가합니다" 안내

- Then: QR 스캐너 활성화

#### TC-P04-002: 유효 QR 스캔 → 체크인 성공
- Given: QR 스캐너 활성
- When: 유효한 티켓 QR 스캔
- Then: "체크인 완료" + 참가자 정보 표시 + 진동 피드백

#### TC-P04-003: 무효 QR (만료/위조)
- Given: QR 스캐너 활성
- When: 만료 또는 위조 QR 스캔
- Then: "유효하지 않은 QR입니다" 에러 + 적색 표시

#### TC-P04-004: 중복 체크인 방지
- Given: 이미 체크인된 참가자
- When: 동일 QR 재스캔
- Then: "이미 체크인된 참가자입니다" 안내

#### TC-P04-005: 다른 이벤트 QR 스캔
- Given: 이벤트 A 선택 상태
- When: 이벤트 B의 QR 스캔
- Then: "이 이벤트의 티켓이 아닙니다" 안내

- Given: 기존 반복 규칙 설정됨
- When: 규칙 변경 (주간 → 격주)
- Then: 미래 이벤트 재생성 확인 다이얼로그 → 적용

#### TC-P09-003: 반복 규칙 삭제

- When: "삭제" → 확인
- Then: 규칙 삭제, 이미 생성된 미래 이벤트 유지 (개별 관리)

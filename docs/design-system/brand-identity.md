# Brand Identity — minglit voice + visual

> 코드/SSOT에 안 담기는 minglit 고유의 보이스/톤/시각 정체성.
> 새 텍스트(앱 카피 / 마케팅 / 알림) 작성 시, UI 컴포넌트 디자인 시 이 문서가 단일 진실.
> 미션/원칙: [founding-story.md](../background/founding-story.md), 페르소나: [personas.md](../background/personas.md)

## 1. 핵심 원칙

### Voice ≠ Visual (분리 원칙)
- **Voice (텍스트)**: 정중 + 신뢰 + 무겁지 않음. "잘 큐레이션된 매니저"
- **Visual (디자인)**: MZ 틱 + 세련 + 트렌디

→ 같은 화면에서 정중한 글 + MZ 시각 = "신뢰할 수 있는데 답답하지 않다" 느낌.

### Why this hybrid?
- 너무 무거우면 → 결정사 분위기 (mid-market 가치 잃음)
- 너무 가벼우면 → 데이팅앱 노이즈 (검증·신뢰 시그널 약함)
- **mid-market 포지션의 voice/visual 표현**

## 2. Voice + Tone

### 기본 — 존댓말 정중

✅ **Do**:
- "함께해주세요"
- "이번 모임에 모시고 싶습니다"
- "참가비를 안내드립니다"
- "신원 확인을 도와주시겠어요?"

❌ **Don't**:
- 반말 ("같이 가자")
- 너무 격식 ("귀하의 참여를 정중히 요청드리는 바입니다")
- 카피라이팅 강압 ("지금 신청 안 하면 후회!")
- 영업 톤 ("절대 놓치지 마세요!")

### Why 존댓말?
- **사용자가 돈 내고 신뢰하고 오게 하려면 정중함 필수**
- 결제 후 허무함 X → 시작부터 끝까지 "모셔지는 느낌"
- 검증된 신원 사용자들의 매너 있는 만남 = 정중한 voice가 그 분위기 셋업

### 톤 — 무겁지 않게
- 정중하지만 → 친구 매니저 느낌
- 격식보다 → 진심
- 한국식 정중 (~해주세요, ~드립니다) but 결정사처럼 무겁지 않게

### 비교 — 토스 + 인스타그램 hybrid
| 앱 | 가져올 요소 | 안 가져올 요소 |
|---|---------|------------|
| **토스** | 깔끔한 존댓말, 효율적 정보 전달, 최소한의 군더더기 | 너무 metallic한 fintech 느낌은 X |
| **인스타그램** | 시각 우선, 트렌디한 디자인 언어 | 가벼운 톤, 익명성 X |

## 3. Visual Identity

### 디자인 방향성
- **MZ 틱 세련됨** — 2030대가 보고 "촌스럽다" 느끼지 않을 수준
- 컬러: 보라색 계열 (현재). 4축 표현: 트렌디 + 설렘 + 신뢰 + 프로페셔널
- 타이포: 한글 위주 (한국 사용자), 깔끔한 산세리프

### 로고
- **현재**: 채팅 풍선 + 그라디언트 (대화 + 인연 매개 의미)
- **계획**: **네온사인 컨셉으로 교체** 예정. 4축 자연스럽게 모두 표현:
  - **트렌디** — 네온사인 = 2020년대 디자인 언어 (lounge/luxury/카페 시그널)
  - **설렘** — 빛나는 효과 = "마음에 불 켜짐", 만남의 expectation
  - **신뢰** — 또렷한 typography (네온은 형태가 명확)
  - **프로페셔널** — 고급 매장/lounge 분위기 (mid-market 포지셔닝과 일관)

### 4축의 Visual 표현
| 축 | 표현 |
|---|------|
| 트렌디 | 그라디언트, 모던 layout, 적당한 여백 |

| 신뢰 | 정렬, 일관된 spacing, 명확한 hierarchy |

## 4. 금기 (Anti-patterns)

### 절대 X — 사용자 신뢰를 무너뜨리는 것
- ❌ **외모 품평** — "비주얼 인증" 같은 거 X. 사용자가 외모로 평가받는다는 인상 절대 X.
- ❌ **익명성** — "익명 채팅", "익명 매칭" 등 익명 관련 메커닉 절대 X. minglit의 핵심 = **검증된 신원**.
- ❌ **외모/스펙 강조 마케팅** — 결정사처럼 "엘리트", "고스펙" 같은 표현 X.
- ❌ **결혼 압박** — "결혼 상대 찾기", "신혼", "맞선" 같은 키워드 X. 결정사와 거리 두기.
- ❌ **가벼운 데이팅 표현** — "썸", "꼬시기", "꽂히는 사람" 같은 데이팅앱식 표현 X.

### 핵심 differentiation
> **신분이 증명된 사람들이 정중하게 매너를 지키며 만나는 곳**

이 한 문장이 minglit의 brand 본질. 모든 텍스트/디자인은 이 본질에 부합해야 함.

## 6. 운영 가이드

### 새 텍스트 작성 체크리스트
1. ✅ 존댓말? (반말 X)
2. ✅ 격식 정도 — 너무 딱딱하지 않은가?
3. ✅ 위 §4 금기 키워드 없는가?
4. ✅ 사용자가 "모셔지는 느낌" 받는가?
5. ✅ 군더더기 없는가? (토스처럼 효율적)

### 새 디자인 검토 체크리스트
1. ✅ MZ 트렌디 vs 너무 fancy? balance?
2. ✅ 4축 (트렌디·설렘·신뢰·프로페셔널) 모두 표현되는가?
3. ✅ 결정사 분위기 X, 데이팅앱 분위기 X?
4. ✅ 한국 사용자 직관적?

### 새 마케팅 카피 작성 시
- USP 4개 (personas.md §USP 방향성)을 base로
- "신뢰할 수 있는 mid-market 만남" 핵심 메시지
- 본 가이드 §4 금기 strict 적용

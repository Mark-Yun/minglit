승인 — Pretendard Variable 전환을 적극 지지한다

Pretendard는 한글 가독성에 최적화된 폰트로, 토스·당근·네이버·쿠팡·야놀자 등 국내 톱티어 앱들이 채택한 업계 표준이다. 높은 x-height, 명확한 스트로크 대비, 컴팩트한 자폭이 모바일 환경에서 텍스트를 또렷하게 보이게 만든다. 현재 NotoSansKR의 "글자가 배경에 가라앉는 느낌" 문제를 근본적으로 해결할 수 있다.

항목 현재값 권고 상태 이유
fontFamily NotoSansKR Pretendard 변경 이슈 스펙대로 전환
fontSize 전체 10–32px 유지 유지 Pretendard의 높은 x-height로 체감 크기가 자연스럽게 개선됨. 사이즈 변경 불필요.
fontWeight 전체 w400–w700 유지 유지 Pretendard Variable의 weight axis가 동일 범위를 커버. 매핑 변경 불필요.
line-height 전체 1.25–1.5 유지 유지 현재 line-height는 4pt grid 기반으로 잘 설계됨. Pretendard에서도 적절한 여백 유지.
letterSpacing (11–13px) 없음 letterSpacing: 0.1 후속 검토 Pretendard는 컴팩트해서 소형 텍스트가 다닥다닥 붙을 수 있음. 1차 PR에서는 추가하지 않고, 실기기 테스트 후 필요 시 후속 PR로 조정.
NotoSansKR 에셋 유지 1차: 유지 (Option B) 유지 안전한 폴백. 후속 PR에서 제거 (Option A) 권장. Pretendard가 KS X 1001 전체 커버하므로 폴백 필요성은 낮음.
RacingSansOne 브랜드 로고용 절대 변경 금지 유지 브랜드 아이덴티티. 교체 대상 아님.

총 9곳의 fontFamily: 'NotoSansKR' 하드코딩을 'Pretendard'로 교체해야 한다. ThemeData.fontFamily가 전체 앱에 적용되므로, fontFamily를 명시하지 않은 TextStyle들은 자동으로 Pretendard를 상속한다.
시각적 검증 체크리스트 (UX 리뷰 시 확인할 것)
x-height 개선 — 동일 px 대비 글자가 더 또렷하게 보이는지. 특히 13px 이하 소형 텍스트에서 차이가 명확해야 한다.
Weight 구분 — w400(본문) ↔ w500(라벨) ↔ w600(AppBar) ↔ w700(타이틀) 각 단계가 육안으로 구분되는지.
복잡 자소 — ㅉ, ㅎ, ㅙ, ㅢ, 됐, 뷁 등 복잡한 한글 자소가 깨지거나 뭉개지지 않는지.
숫자·영문 혼합 — "참가자 12/20명", "D-3", "4.8점" 등 한영 혼합 텍스트에서 baseline 정렬이 맞는지.
긴 텍스트 줄바꿈 — 이벤트 설명 등 multi-line 본문에서 줄간격(line-height)이 답답하지 않은지.
칩/배지 오버플로 — Pretendard가 컴팩트하므로 기존에 빡빡했던 칩이 여유로워질 수 있음. 반대로 padding이 과해 보이지 않는지 확인.
다크 모드 — Pretendard의 스트로크 대비가 다크 배경에서도 가독성을 유지하는지.
RacingSansOne 무결성 — 브랜드 로고/히어로 텍스트가 Pretendard로 바뀌지 않았는지 반드시 확인.

구매 내역 화면 — 색상 위계 리디자인
Issue #1236 · needs-uiux-claude-1 · 2026-04-10
문제 요약 & 디자인 원칙
1

60-30-10 색상 규칙

화면의 60%는 중성색(흰/회), 30%는 보조색(회색 변형), 10% 이하만 브랜드 컬러. 현재는 보라가 40%+ 차지하여 피로도가 높다.

2

상태 배지는 의미 기반 색상

결제완료=초록(성공), 승인됨=파랑(정보), 심사중=노랑(주의), 결제대기=회색(비활성), 취소/반려=빨강(오류). 브랜드 컬러는 상태를 전달하지 않는다.

3

버튼 위계를 시각적으로 분리

Primary CTA만 브랜드 컬러, 보조 액션은 중성색 outline, 3차 액션은 text only. Destructive 액션은 최소 visual weight로 실수 방지.

상태 배지 색상 재정의
결제완료 success
승인됨 info
심사중 warning
결제대기 neutral
취소됨 error
반려됨 error
상태 현재 (Before) 리디자인 (After) 이유
결제완료 결제완료 → 결제완료 결제 성공 = 긍정 상태. 초록은 보편적 성공 색.
승인됨 승인됨 → 승인됨 승인 = 정보성 확인 상태. 파랑으로 결제완료와 구분.
심사중 심사중 → 심사중 대기/주의 상태. 민트→노랑으로 주의 의미 강화.
결제대기 결제대기 → 결제대기 유지. 비활성/대기 = 회색이 적절.
취소됨/반려됨 취소됨 → 취소됨 유지. 오류/취소 = 빨강이 적절.
핵심: 결제완료(paid)와 승인됨(approved)을 더 이상 같은 색으로 표시하지 않는다. 결제완료는 금전 거래 완료(초록), 승인됨은 참가 확정(파랑)으로 의미 분리.
버튼 위계 재설계
버튼 현재 리디자인 이유
영수증 영수증 → 영수증 보조 액션. 중성 outline으로 강도 낮춤.
문의하기 문의하기 → 문의하기 3차 액션. text button으로 최소화.
예매 취소 예매 취소 → 예매 취소 Destructive action. 최소 visual weight + 탭 시 confirm dialog.
버튼 위계: Primary(filled) > Secondary(outlined neutral) > Tertiary(text) > Destructive(text muted). 구매 내역에는 Primary CTA가 없으므로 가장 강한 버튼이 neutral outline. 보라색은 이 화면에서 사라진다.

신규 디자인 토큰 제안

minglit_design_tokens.dart에 추가할 시맨틱 상태 색상 토큰. 기존 MinglitColors.success/warning/error와 함께 사용.

토큰명 색상 Hex 용도
statusSuccess
#22C55E (= 기존 success) 결제완료 배지
statusInfo
#3B82F6 승인됨 배지
statusWarning
#F59E0B (= 기존 warning) 심사중 배지
statusNeutral
#9CA3AF 결제대기 배지
statusError
#EF4444 (= 기존 error) 취소됨/반려됨 배지
기존 success/warning/error와 값이 같은 토큰도 별도 시맨틱 이름을 부여하는 이유: status* 토큰은 배지 전용이고, success/warning/error는 범용이다. 나중에 배지 색만 변경해야 할 때 분리되어 있어야 안전하다.
구현 명세 — StatusBadge 수정

apps/app_user/lib/src/common/widgets/status_badge.dart 변경: 

// Before
case 'approved':
  color = theme.colorScheme.primary;  // ← 보라
case 'paid':
  color = theme.colorScheme.primary;  // ← 보라

// After
case 'approved':
  color = MinglitColors.statusInfo;   // ← 파랑 #3B82F6
case 'paid':
  color = MinglitColors.statusSuccess; // ← 초록 #22C55E
case 'pending_review':
  color = MinglitColors.statusWarning; // ← 노랑 #F59E0B

purchase_history_card.dart 버튼 변경: 

// 영수증: OutlinedButton → neutral outline
OutlinedButton(
  style: OutlinedButton.styleFrom(
    foregroundColor: theme.colorScheme.onSurface,
    side: BorderSide(color: theme.colorScheme.outlineVariant),
  ),
  child: const Text('영수증'),
),

TextButton(

),

디자인 전략 및 명세

1. 시각적 계층 (Visual Hierarchy)

단순 텍스트 대신 'Glow' 효과가 적용된 일러스트레이션 영역을 추가하여 시선이 자연스럽게 머물도록 유도합니다. 브랜드 컬러(Purple)를 활용하여 서비스 아이덴티티를 강화합니다.

2. 탐색 유도 (Call to Action)

현재 상태를 해결할 수 있는 '필터 초기화' 버튼을 메인 CTA로 배치합니다. 유저가 무엇을 해야 할지 고민하지 않게 합니다.

3. 추천 태그 (Contextual Suggestions)

하단에 인기 있는 카테고리나 지역 태그를 노출하여, 직접 검색어를 입력하지 않아도 탐색을 시작할 수 있는 트리거를 제공합니다.

4. 문구 개선 (Microcopy)

'없습니다'의 딱딱한 종결 어미 대신 '~없어요', '~어떨까요?' 등의 친근한 어조를 사용하여 서비스의 소셜한 성격을 반영합니다.

개발 가이드 (Component Sync)

`MinglitEmptyState` 위젯에 `illustration` 또는 `customWidget` 파라미터를 추가하여 확장성 있게 구현할 것을 권장합니다.

// 제안하는 위젯 사용 예시
MinglitEmptyState(
  title: '아직 추천할 이벤트가 없어요',
  subtitle: '주변 지역을 탐색하거나\n다른 필터를 적용해 보는 건 어떨까요?',
  icon: Icons.auto_awesome_outlined, // 또는 별도 일러스트
  actionLabel: '필터 초기화하기',
  onAction: () => _resetFilters(),
  bottomWidget: PopularTagCloud(), // 추가 제안
)

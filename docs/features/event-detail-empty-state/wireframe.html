디자인 결정 요약

  • 컴포넌트 — MinglitEmptyState.card (이미 디자인 시스템에 존재, 재사용).
  • 아이콘 — Icons.description_outlined. 섹션 성격(본문/설명)을 중립적으로 암시.
  • 카피 — 현재 "없습니다"(선언형) → "아직 … 없어요"(진행형 + 대화적). 호스트를 탓하지 않으면서도 미래 가능성을 열어둔다.
  • 서브카피 — "궁금한 점은 호스트에게 문의해 보세요." 로 유저에게 다음 액션을 제시 (디자인 시 데드엔드 방지).
  • 여백 — 기존 섹션 간격(sectionGap 40px, screenEdge 16px)을 그대로 유지. 카드 내부 패딩은 xlarge 32px.
  • 배경/라운드 — surfaceContainerLowest + MinglitRadius.card(16px). 다크모드 자동 대응.

토큰 (참고)

Icon color · colorScheme.outlineVariant
Title · textTheme.titleMedium
Subtitle · textTheme.bodyMedium · onSurfaceVariant
Card bg · colorScheme.surfaceContainerLowest
Card radius · MinglitRadius.card (16px)
Card inner padding · MinglitSpacing.xlarge (32px)
Title→Subtitle gap · MinglitSpacing.small (8px)

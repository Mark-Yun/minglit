## Functional Requirements

- **FR-1**: 홈 피드 상단(기본 필터 칩바 아래)에 인기 태그(큐레이션된 노출 대상) 가로 스크롤 칩바를 노출한다. 칩 탭 시 해당 태그 페이지로 이동.
- **FR-2**: 칩바에서 다수 태그를 동시 선택 가능(OR 필터). 선택 칩은 filled + 체크마크 상태로 구분. 인라인 필터링은 현재 피드를 갱신.
- **FR-3**: 핫 태그 섹션은 최근 7일 신규 연결 수 상위 10개를 가로 카드로 노출. 데이터 부족 시 섹션 자체를 숨긴다.
- **FR-4**: 이벤트 카드 하단에 해당 파티의 태그 뱃지 최대 3개를 노출. 초과분은 `+N` 으로 표기. 뱃지 탭 시 태그 페이지 이동.
- **FR-5**: 태그 페이지는 활성 이벤트만, 시작일 가까운 순으로 페이지네이션(10개 단위) 로드한다. 빈 상태 안내 노출.
- **FR-6**: 검색창 입력 시 500ms 디바운스 후 태그 prefix 검색을 실행하고, 결과를 이벤트 검색 결과 위에 별도 섹션으로 표시한다.
- **FR-7**: 검색 페이지 초기 상태(검색어 없음)에서는 인기 태그와 최근 검색어를 노출한다.
- **FR-8**: 온보딩 관심 태그 선택 화면에서 인기 태그를 3열 그리드로 표시. 3개 이상 선택 시 "다음" 활성, 5개 초과 비활성.
- **FR-9**: 온보딩에서 선택 완료 시 유저의 관심 태그로 저장. "건너뛰기" 선택 시 미저장 + 홈 직진. 어느 경우든 재진입 강제 없음.
- **FR-10**: 관심 태그 보유 유저의 홈 피드에 "관심사 추천" 섹션을 노출(매칭 이벤트가 있을 때만).
- **FR-11**: 마이 페이지의 관심 태그 설정에서 토글 추가/제거 가능. 저장 즉시 관심사 추천 피드를 갱신.
- **FR-12**: 파트너 파티 생성/편집 위저드 Step 1 에 태그 입력 UI 를 노출. 인기 태그 퀵 선택 + 검색 자동완성 + 선택 chip(삭제 가능).
- **FR-13**: 파티당 태그 최대 5개. 5개 도달 시 추가 입력 UI 비활성 + 안내 toast. 저장 요청 시 서버에서도 5개 제약 검증.

## Non-Functional Requirements

- **NFR-1**: 홈 피드 진입 시 인기 태그 칩바 first paint 500ms 이내 (에뮬레이터 baseline, p50 기준). 5분 keepAlive 캐시 활용.
- **NFR-2**: 태그 페이지 첫 페이지 로드 800ms 이내 (에뮬레이터 baseline, p50 기준).
- **NFR-3**: 검색 자동완성 input → 결과 표시 700ms 이내 (디바운스 500ms 포함, p50). 자동완성 실패는 silent fail — 이벤트 검색은 계속 동작.
- **NFR-4**: 접근성 — 칩/뱃지에 스크린리더 라벨 + 최소 터치 영역 48dp. 선택 상태는 색상 외에 체크마크 아이콘으로도 구분.
- **NFR-5**: 태그명 길이 제한 16자 이하 (UI 한 줄 보장).

## Edge Cases

| CUJ ID | 케이스 | 기대 동작 |
|--------|--------|----------|
| 1-1 | 인기 태그 fetch 실패 | 칩바 섹션 숨김 (silent fail). 나머지 홈 피드는 정상 노출 |
| 1-1 | 비활성 태그 id 로 직접 진입 | 빈 상태 안내 + 홈 복귀 버튼 |
| 1-2 | 다중 선택 OR 결과 0건 | "선택한 태그의 이벤트가 없어요" + 선택 해제 안내 |
| 1-3 | 핫 태그 데이터 부족(이벤트 < 10건) | 섹션 자체 숨김 |
| 1-4 | 이벤트가 태그를 갖지 않음 | 뱃지 영역 자체 미렌더 (높이 차지 없음) |
| 1-5 | 페이지네이션 도중 네트워크 끊김 | 마지막 페이지 유지 + 재시도 인라인 버튼 |
| 2-1 | 입력 도중 빠른 keystroke | 디바운스 타이머 리셋, 마지막 입력만 실행 |
| 2-3 | 매칭 태그 0건 | 태그 섹션 숨김(또는 안내) + 이벤트 검색은 계속 |
| 3-1 | 온보딩 도중 앱 kill | 다음 실행 시 다시 관심 태그 선택 화면 진입 (관심 태그 미저장) |
| 3-2 | 건너뛰기 후 사후에 설정 원함 | 마이 페이지 관심 설정에서 추가 가능 |
| 3-3 | 관심 태그는 있지만 매칭 이벤트 0건 | 관심사 추천 섹션 숨김 |
| 3-4 | 관심 태그 저장 실패 | 토글 원복 + 스낵바 + 재시도 |
| 4-1 | 인기 태그 fetch 실패 (파트너) | 검색 자동완성으로만 입력 가능 안내 |
| 4-2 | 6번째 추가 시도 | 입력 비활성 + "최대 5개까지 선택할 수 있어요" toast |
| 4-3 | 편집 중 다른 파트너가 동일 파티 수정 | 저장 시 충돌 시 서버 응답에 따라 최신 상태 reload + 재편집 안내 |

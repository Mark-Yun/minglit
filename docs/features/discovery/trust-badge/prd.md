# PRD: 신뢰 배지 (Trust Badge)

## Summary

플랫폼이 직접 검증한 데이터(본인확인, 자격인증, 활동 출석률)를 3-Layer 아이콘 배지로 시각화하여 유저 간 신뢰를 정량적으로 표현. 정성·상대적 매너온도 대신 Hard Trust 를 디폴트로 제공한다.

## Motivation / Problem to Solve

- 소셜 매칭 플랫폼의 핵심 자산은 유저 간 신뢰지만, 현재는 검증 데이터를 한곳에 노출하는 UI 가 없음
- 매너온도 등 정성 지표는 상대적·조작 가능하며, 처음 매칭 신청 시 의사결정 근거로 부족하다는 정성 피드백
- 본인확인(CI) / 파트너 인증(직장·학력 등) / 출석률 등 이미 보유한 데이터를 활용하면 별도 수집 없이 가치 노출 가능
- 프리미엄 포지셔닝상 검증된 유저 위주 매칭이라는 메시지를 시각적으로 강화할 필요

## Goals

### Target Users

- **신청자**: 처음 보는 이벤트 참여자의 신뢰도를 빠르게 판단해야 하는 유저
- **본인 (마이페이지)**: 자신의 신뢰 등급과 다음 단계 진입 조건을 명확히 인지하고 인증을 진행하는 유저
- **호스트·파트너**: (Phase 2) 신뢰 등급별 우선 매칭 등 혜택 운영 주체

### Key Goals

- **P0**: 본인확인 / 자격인증 / 출석률 기반 3-Layer 배지 산출 + 유저 노출 위치 (프로필, 참가자 목록, 채팅 등) 모두에서 표시
- **P0**: 배지 탭 시 신뢰 상세 시트로 인증 근거 (직장·학력 항목, 출석률 등) 투명 공개
- **P0**: 본인 마이페이지에서 현재 등급 + 다음 등급 조건 + 미인증 항목 인증 CTA 노출
- **P1**: 등급 산출 로직 단일 SSoT (서버 또는 클라이언트 derived) — 노출 위치별 결과 불일치 0

### Non-Goals

- 배지 컬렉션 / 전문 분야 배지 (Phase 2)
- 신뢰 등급에 따른 매칭 우선순위 / 수수료 차등 (Phase 2)
- 파트너 측 신뢰 배지 (이벤트 호스트 대상 — 별도 PRD)
- 매너온도 / 평점 시스템 (정성 지표는 본 PRD 범위 외)

## Product Principles

1. **Layered Trust**: 본인확인(Identity) → 자격인증(Qualification) → 활동지표(Reliability) 3단계 계층, 상위 등급은 하위 조건을 포함한다.
2. **투명한 근거 공개**: 배지는 결과일 뿐, 시트에서 어떤 인증 / 어떤 활동 기록으로 부여됐는지 정확히 노출한다.
3. **단일 진실원**: 등급 산출은 한 곳에서 결정되며, UI 는 그 결과를 표시만 한다 — 노출 위치별 결과 불일치 금지.
4. **프리미엄 감성**: 단순 컬러 닷이 아닌 브랜드 아이콘(Shield / Sparkles / Diamond) + 일관된 모션·컬러로 차별화한다.

## Technical Approach

- **화면**: 배지 위젯(`TrustBadge`) 전 노출 위치 임베드 + 배지 시트(`TrustSheet`) + 마이페이지 신뢰 섹션 + 인증 관리 페이지
- **저장**: 기존 본인확인 테이블, 파트너 자격인증 스냅샷 테이블, 이벤트 출석 통계 — 신규 테이블 없음 (derived)
- **외부 의존성**: 본인인증 (Portone), 파트너 인증 승인 워크플로우
- **가드 / 정책**: 마이페이지에서만 자기 자신의 미인증 내역 노출 가능 (RLS). 타인 시트에서는 인증 결과만 노출, 원본 문서 / 사진 비공개

## User Journey

### Scenario 1: 인증 유도 — 본인 등급 확인 (CUJ 1-x)

마이페이지에서 자신의 신뢰 등급(또는 미인증 상태)을 보고 다음 등급 진입 조건을 파악, 인증하기 CTA 로 본인확인 / 파트너 인증 플로우 진입.

### Scenario 2: 매칭 신청 전 타인 신뢰 확인 (CUJ 2-x)

이벤트 상세 / 참가자 목록에서 타인의 배지를 보고 배지 탭 → 신뢰 시트에서 인증 근거를 확인한 뒤 안심하고 매칭 신청.

### Scenario 3: 자격인증 승인 → 등급 자동 상승 (CUJ 3-x)

파트너 인증(직장·학력 등)이 승인되는 순간 유저 등급이 Verified → Certified 로 자동 상승, 활동 출석률 95% 이상 도달 시 Elite 로 상승.

## Data Flow

### Scenario 1

마이페이지 진입 → 현재 등급 산출 (본인확인 여부 + 자격인증 카운트 + 출석률) → 신뢰 섹션 카드 노출 → 미인증 항목 있으면 "인증하기" CTA → 본인인증 / 파트너 인증 페이지

### Scenario 2

이벤트 상세 / 참가자 카드 진입 → 각 참여자별 등급 산출 (캐시 우선) → 배지 위젯 노출 → 배지 탭 → 신뢰 시트 (인증 항목 리스트 + 활동 지표 메시지) → 닫기 / 매칭 신청 CTA

### Scenario 3

파트너 인증 승인 (서버 트리거) → 유저 등급 재계산 → 캐시 무효화 → 다음 노출 시 새 배지 반영 (또는 realtime 이벤트로 즉시 반영)

## KPIs / Success Metrics

- **본인확인 완료율**: 신규 가입자 중 30일 내 본인확인 완료 — baseline 측정 후 +10%p
- **자격인증 신청율**: 본인확인 완료 유저 중 30일 내 자격인증 신청 — baseline + 5%p
- **배지 탭 → 시트 열람율**: 노출 대비 클릭율 ≥ 8% (호기심 + 신뢰 검증 시그널)
- **이벤트 신청 전환율**: 시트 열람 후 매칭 신청율 — 신뢰 노출의 conversion 영향 측정
- **노출 위치별 등급 일관성**: 동일 유저 동일 시점 배지 결과 불일치 = 0

## Launch Strategy

- 단계 1: 표시만 (마이페이지 + 이벤트 상세 + 채팅)
- 단계 2: 등급별 혜택 / 우선 매칭 실험 (Phase 2)
- A/B: 배지 노출 ON / OFF 가 매칭 신청 전환에 미치는 영향 측정

설계 노트

1. "위험 영역" 패턴

로그아웃/회원탈퇴는 "위험 영역(Danger Zone)" 카드 안에 그룹핑합니다.

  • 붉은 테두리 + 연한 붉은 배경으로 시각적 경고
  • "위험 영역" 라벨로 파괴적 액션임을 명시
  • 참고: GitHub Settings의 Danger Zone 패턴
  • 실수로 탭할 확률을 줄이면서도, 2탭 이내 접근(마이페이지 → 계정 관리 → 로그아웃) 유지

2. 양 앱 일관성

app_user와 app_partner 모두 동일한 AccountManagementPage 패턴을 사용합니다.

  • 공통: 로그아웃 + 회원탈퇴 (위험 영역)
  • app_user 전용: 비밀번호 변경 (향후 확장 가능)
  • app_partner 전용: 파트너 프로필 (현재 "준비 중" → 서브페이지로 이동)

3. 마이페이지에서 제거되는 항목

  • app_user: 하단 "로그아웃" ListTile 제거. 개인정보 페이지의 "회원 탈퇴" → 계정 관리로 이동
  • app_partner: 하단 "로그아웃" ListTile 제거. 계정 섹션의 "회원 탈퇴", "파트너 프로필" → 계정 관리로 이동. 비활성이었던 "계정 관리" 메뉴가 실제 서브페이지로 연결

4. 확장성

향후 계정 관리 페이지에 추가될 수 있는 항목:

  • 비밀번호 변경 / 소셜 로그인 연결
  • 로그인 기록
  • 연결된 기기 관리
  • 알림 수신 동의 관리

5. 구현 가이드

  • AccountManagementPage를 minglit_kit 공유 패키지에 생성 (양 앱 공유)
  • 앱별 차이는 콜백/플래그로 처리: showPasswordChange, showPartnerProfile
  • 로그아웃 로직은 기존 코드 재활용 (GoRouter-first 패턴 유지)
  • 회원탈퇴는 기존 AccountDeletion 플로우로 네비게이트

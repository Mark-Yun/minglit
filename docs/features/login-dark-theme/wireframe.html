설계 의사결정

  • Scaffold 배경 — 하드코딩된 MinglitColors.background 제거. Scaffold가 theme.scaffoldBackgroundColor를 상속하도록 비움. 라이트=#F9FAFB(홈과 동일한 surface), 다크=#0F0F0F(홈과 동일한 배경).
  • Google 버튼 — 브랜드 가이드가 라이트/다크 변형을 모두 허용. 라이트=흰 바탕+near-black 글자, 다크=#212121(surface dark)+흰 글자. 보더는 outlineVariant로 테마 연동.
  • Apple 버튼 — Apple Sign-In HIG를 따름. 라이트=검정 바탕+흰 글자, 다크=흰 바탕+검정 글자(Apple 가이드의 "white on dark" 변형).
  • Kakao 버튼 — 테마와 무관하게 노랑 고정(Kakao 브랜드). 글자는 near-black 유지.
  • 슬로건·약관 텍스트 — 이미 theme.colorScheme.outline / theme.textTheme을 사용하므로 변경 없음.
  • 회귀 방지 — login_scenarios.dart에 Brightness.dark 시나리오 추가 → 다크 골든 login_page_default_dark.png 생성.

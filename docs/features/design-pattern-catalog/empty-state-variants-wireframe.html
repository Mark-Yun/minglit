Variant 정의

3개의 variant로 현재 6개의 커스텀 구현을 모두 커버합니다. 맥락에 맞는 시각적 무게감을 부여하되, 구조(아이콘→텍스트→CTA)는 일관되게 유지합니다.

Variant 용도 Icon Title Subtitle CTA Background
fullPage (기본) 전체 화면 빈 상태 48px
MinglitIconSize.display		 titleMedium
onSurface		 bodyMedium
onSurfaceVariant		 FilledButton transparent
card 카드/섹션 내 빈 상태 32px
MinglitIconSize.xlarge		 bodyMedium, onSurfaceVariant (단일 메시지) — surfaceContainerLowest
radius: card (16px)
inline 폼/입력 컨텍스트 플레이스홀더 — bodyMedium, onSurfaceVariant (단일 메시지) — surfaceContainerHighest 30%
border: outlineVariant
radius: card (16px)
신규 토큰 제안: MinglitIconSize.display = 48 — 빈 상태, 히어로 영역 등 시각적 초점이 필요한 대형 아이콘용. 기존 xxlarge(40)와 하드코딩(56, 64) 사이의 간극을 채웁니다.

API Preview

제안하는 위젯 API입니다. variant enum으로 레이아웃/스타일을 전환하고, 기존 파라미터(icon, title, subtitle, CTA)는 유지합니다.

// Variant enum
enum MinglitEmptyStateVariant {
  fullPage,  // 전체 화면 (기본)
  card,      // 카드/섹션 내
  inline,    // 폼/입력 플레이스홀더
}

// fullPage — CTA 있는 전체 화면
MinglitEmptyState(
  icon: Icons.confirmation_number_outlined,
  title: '아직 티켓이 없어요',
  subtitle: '관심 있는 이벤트를 찾아보세요',
  actionLabel: '이벤트 둘러보기',
  onAction: () => navigateToExplore(),
)

// card — 섹션 내 빈 상태
MinglitEmptyState.card(
  icon: Icons.verified_user_outlined,
  title: '제출한 인증이 없습니다',
)

// inline — 폼 내 플레이스홀더
MinglitEmptyState.inline(
  title: '아직 추가된 입장 그룹이 없습니다',
)

Before / After

Before — 현재 문제

  • 아이콘 크기 6종: 32, 48, 56, 64px + xlarge*1.5
  • 아이콘 색상 3종: outline, outlineVariant, onSurfaceVariant
  • 배경 처리 4종: transparent, surfaceContainerLowest, surfaceContainerHighest 30%, 없음
  • CTA 버튼 스타일 비통일 (커스텀 padding, font 등)
  • 공유 위젯 사용 0건 → 디자인 시스템 무용화

After — 통합 후

  • 3 variant × 일관된 토큰 기반 스타일
  • 아이콘: fullPage=48px, card=32px, inline=없음
  • 컬러: 시맨틱 토큰만 사용 (하드코딩 제거)
  • CTA: 표준 FilledButton (커스텀 스타일 제거)
  • 공유 위젯 사용 5건 + 예외 1건

Design Decisions

주요 설계 결정과 근거입니다.

결정 선택 근거
fullPage 아이콘 크기 48px (신규 토큰) 현행 64px는 시각적으로 과도. 디자인 시스템의 32px(xlarge)는 전체 화면에서 너무 작음. 48px는 충분한 시각적 초점을 제공하면서 콘텐츠 영역을 압도하지 않음. 토스(~44px), Linear(~40px), Things(~48px) 참고.
CTA 버튼 타입 FilledButton 디자인 시스템 문서는 OutlinedButton이나, 빈 상태의 CTA는 화면의 유일한 액션. 시각적 계층에서 가장 높은 무게감이 필요 → FilledButton이 적합. 디자인 시스템 문서를 업데이트할 것.
card variant 배경 surfaceContainerLowest surfaceContainerHighest(alpha 0.3)보다 surfaceContainerLowest가 일관성 있음. Material 3 surface tint 계층과도 정합.
inline variant 아이콘 없음 폼 맥락에서는 텍스트만으로 충분. 아이콘은 주변 UI 요소와 시각적으로 충돌할 수 있음. 필요 시 icon 파라미터로 추가 가능하나 기본값은 없음.
party_location_input 예외 통합 제외 맵 슬롯은 empty state가 아닌 input placeholder에 가까움. 범용 컴포넌트에 도메인 특화 케이스를 억지로 끼우면 API가 복잡해짐.

## Functional Requirements

> 제품 행동 정의 — DB schema SQL / Provider 이름 / Repository 메서드 시그니처 같은 dev detail 은 제외 (코드/migration 이 SSoT).

- **FR-1**: 유저는 마이페이지 → 개인정보 설정에서 탈퇴 진입 가능. 파트너는 더보기 → 계정 설정 경로.
- **FR-2**: 탈퇴 사유는 선택. 라디오 5종 + "기타(자유 입력 ≤200자)" + "선택하지 않고 계속" 텍스트 버튼 제공.
- **FR-3**: 안내 화면은 (a) 삭제되는 정보, (b) 법정 보존 정보 + 보존 기간, (c) 7일 유예 + 30일 재가입 제한을 모두 노출.
- **FR-4**: 본인 확인은 가입 시 사용한 인증 수단으로만 진행 (소셜 → 동일 provider 재인증, 이메일 → 비밀번호).
- **FR-5**: 본인 확인 통과 후에만 최종 확인 다이얼로그 진입 가능. 통과 전 다이얼로그 호출 차단.
- **FR-6**: 최종 확인 다이얼로그는 "탈퇴하기"(error 컬러) / "돌아가기"(default) 2 버튼. dismiss 시 진행 중단.
- **FR-7**: 탈퇴 확정 시 유저 프로필에 탈퇴 시각 기록 + 익명 사유 저장 + 푸시 구독 해제를 한 트랜잭션에서 수행. 부분 실패 시 전체 rollback.
- **FR-8**: 탈퇴 직후 push 알림 발송 중지. 세션은 완료 화면 후 정리.
- **FR-9**: 완료 화면은 3초 후 자동 로그아웃 + 홈 화면(`/`) 진입. 백버튼 무시.
- **FR-10**: 파트너 탈퇴 시 (a) 예정 / 진행 중 이벤트, (b) 미정산 잔액, (c) 진행 중 환불 건 중 하나라도 있으면 탈퇴 차단.
- **FR-11**: 차단 화면은 항목별 카드 + 각 항목 해결 페이지(이벤트 관리 / 정산 / 환불 상세) 로 바로가기 제공.
- **FR-12**: 파트너 차단 통과 후 플로우는 유저와 동일 (사유 → 안내 → 본인 확인 → 다이얼로그 → 완료).
- **FR-13**: 파트너 안내 화면은 유저 안내 위에 사업자 의무(정산 / 세금계산서 / 미수령 정산금) 섹션 추가.
- **FR-14**: 유예 기간(7일) 중 동일 계정 로그인 시도 → 로그인 직후 복구 다이얼로그 노출. dismiss 하면 로그아웃 처리.
- **FR-15**: "탈퇴 취소" 탭 시 `deleted_at` null 복원 + FCM 구독 재등록 + 홈 진입.
- **FR-16**: CRON 잡이 매일 1회 실행되어 `deleted_at` + 7일 ≤ now 인 row 를 일괄 처리 (아카이브 → cascade 삭제 → DI 차단 등록).
- **FR-17**: 영구 삭제와 동시에 DI 해시 + 차단 만료(30일 후) 등록. 동일 DI 본인인증 시도 시 가입 중단 + 남은 일수 안내.
- **FR-18**: 유예 기간 중 유저는 검색 / 매칭 후보 / 피드 / 알림 발송 대상에서 모두 제외 (RLS 또는 어플리케이션 필터).

## Non-Functional Requirements

> 측정 가능해야 함 — "빨라야 함" 금지. 환경 + 분위수 명시 (예: "에뮬레이터 baseline, p50 200ms 이내").

- **NFR-1**: 각 단계 화면 진입 → first paint 200ms 이내 (에뮬레이터 baseline, p50). 차단 조건 조회는 500ms 이내 (p95, 파트너 데이터셋 평균 기준).
- **NFR-2**: 탈퇴 API 호출 응답 ≤ 2s (p95, 프로덕션 평균 네트워크). 실패 시 재시도 1회 후 스낵바 + 재시도 버튼.
- **NFR-3**: 본인 재인증 SDK 타임아웃 30s. 타임아웃 시 명시적 에러 메시지 + 재시도 가능 상태로 복구.
- **NFR-4**: 익명 사유 row 에는 user_id / 이메일 / DI / IP / device id 모두 포함 금지 (PII 감사 통과 기준).
- **NFR-5**: CRON 영구 삭제 잡은 일 1회 실행, 단일 실행에서 1,000건 이하 처리 시 ≤ 5분 (에뮬레이터 베이스라인). 5분 초과 시 다음 회차로 split.

## Edge Cases

| CUJ ID | 케이스 | 기대 동작 |
|--------|--------|----------|
| 1-1 | 사유 화면에서 시스템 백 | 다이얼로그 없이 이전 화면 복귀. 입력 사유는 폐기 |
| 1-3 | 소셜 재인증 중 SDK 에러 / 사용자 취소 | 인라인 에러 메시지 + 재시도. 다음 단계 차단 |
| 1-4 | 탈퇴 API 호출 중 네트워크 끊김 | 재시도 1회 → 실패 시 스낵바 + 재시도 버튼. `deleted_at` 미커밋 상태 유지 |
| 1-4 | 탈퇴 API 응답 후 앱 kill | 서버 측 `deleted_at` 기록 완료 → 다음 로그인 시 복구 다이얼로그 진입 |
| 1-5 | 완료 화면 진입 후 3초 전 백 | 백버튼 무시 (시스템 백 차단) |
| 2-1 | 차단 조건 조회 실패 (네트워크) | 차단 화면 대신 에러 카드 + 재시도 버튼. 탈퇴 진행 차단 (안전 default) |
| 2-2 | 차단 항목 해결 후 재진입 | 매 진입마다 최신 조회. 캐시 신뢰 금지 |
| 2-3 | 사업자 의무 안내 누락 | (Open Q) — 모든 파트너 동일 안내 vs 활성 정산 잔액 기준 |
| 3-1 | 유예 기간 중 다른 계정으로 로그인 | 복구 다이얼로그 미노출 (다른 user_id) |
| 3-1 | 복구 다이얼로그에서 시스템 백 | 다이얼로그 dismiss + 로그아웃 (확정 행동 요구) |
| 3-2 | CRON 잡 실행 중 실패 (DB 락 / 아카이브 오류) | 실패한 row 는 다음 회차 재시도. 알림 / 모니터링 채널로 알람 |
| 3-3 | 30일 차단 중 DI 가 변경된 본인인증 (개명 등) | (Open Q) — 신규 DI 로 재가입 허용 vs 차단 |
| 3-4 | 유예 기간 중 매칭 진행 중이던 이벤트 | (Open Q) — 즉시 빠짐 vs 이벤트 종료까지 유지 |

## 화면 구성 (참고)

> dev 가 아닌 product/UX detail 만. MDS spec 이 SSoT.

### 화면 1: 탈퇴 사유 선택 (`AccountDeletionReasonPage`)

**표시 시점**: 마이페이지 → 개인정보 설정 → "회원 탈퇴" 탭 직후.

**레이아웃** (위→아래): 헤더 → 안내 텍스트 → 라디오 목록 (5개) → 기타(자유 입력) → "선택하지 않고 계속하기" 텍스트 버튼 → "다음" CTA.

**사유 항목**:

| # | 사유 | reason_code |
|---|------|-------------|
| 1 | 더 이상 사용하지 않아요 | `not_using` |
| 2 | 원하는 이벤트가 없어요 | `no_events` |
| 3 | 다른 서비스를 이용하고 있어요 | `using_alternative` |
| 4 | 개인정보가 걱정돼요 | `privacy_concern` |
| 5 | 앱 사용이 불편해요 | `app_ux` |
| 6 | 기타 (자유 입력, ≤200자) | `other` |

### 화면 2: 탈퇴 안내 (`AccountDeletionInfoPage`)

**표시 시점**: 사유 선택 다음.

**섹션 구성**:
1. 경고 아이콘(error 컬러) + "탈퇴하면 이런 것들이 사라져요"
2. 삭제되는 정보 목록 (프로필 / 관심 태그 / 신청 내역 / 알림 설정 / 차단 목록 / 구매 내역 열람 권한)
3. 법정 보존 정보 + 기간 (아래 표)
4. 안내문 3종 (유예 / 영구 삭제 / 재가입 제한)

**법정 보존 정보**:

| 항목 | 근거 법령 | 보존 기간 |
|------|----------|----------|
| 계약·청약철회 기록 | 전자상거래법 | 5년 |
| 대금결제·공급 기록 | 전자상거래법 | 5년 |
| 소비자 불만·분쟁 처리 기록 | 전자상거래법 | 3년 |
| 로그인 기록 | 통신비밀보호법 | 3개월 |

### 화면 3: 본인 확인 (`AccountDeletionVerifyPage`)

**표시 시점**: 안내 화면에서 "동의하고 계속" 후.

**조건별 UI**:
- 소셜 로그인 유저: 가입한 소셜 provider 버튼 1개 + "다시 로그인" 안내
- 이메일 로그인 유저: 이메일(읽기전용) + 비밀번호 입력 + "확인"

### 화면 4: 최종 확인 다이얼로그

**제목**: "정말 탈퇴할까요?"
**본문**: "7일 유예 후 모든 데이터가 삭제되며 복구할 수 없어요."
**Primary**: "탈퇴하기" (error `#EF4444`)
**Secondary**: "돌아가기"

### 화면 5: 완료 화면 (`AccountDeletionCompletePage`)

**구성**: 체크 아이콘 + "탈퇴 요청이 완료됐어요" + "7일 후 계정이 영구 삭제돼요" + "그동안 밍릿을 이용해 주셔서 감사해요". 3초 후 자동 로그아웃 + 홈 진입.

### 파트너 추가: 차단 화면

차단 카드 (제목 + 카운트 + "확인하러 가기" 버튼). 차단 사유별 목적지:

| 차단 사유 | 이동 페이지 |

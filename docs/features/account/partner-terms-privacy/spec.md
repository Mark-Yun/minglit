## Functional Requirements

> 제품 행동 정의 — DB schema / 컴포넌트 이름 같은 dev detail 은 제외 (코드가 SSoT).

- **FR-1**: 파트너 이용약관 페이지(`/terms`) 는 5개 챕터로 구성 — (1) 가입 및 자격 (2) 파트너 의무·금지 행위 (3) 수수료 및 정산 (4) 계약 해지 및 탈퇴 (5) 회사 정보.
- **FR-2**: 약관 상단에 챕터 목차 노출. 목차 항목 탭 시 해당 챕터로 앵커 스크롤.
- **FR-3**: 수수료 챕터에 수수료율 변경 30일 사전 공지 약정, 정산 주기 / 정산 보류 사유 / 환불 시 파트너 책임이 명시.
- **FR-4**: 파트너 등록 페이지에 이용약관 / 처리방침 동의 체크박스 + 각 페이지 링크 노출. 미체크 시 등록 CTA 비활성. 링크는 새 탭에서 열림.
- **FR-5**: 파트너 처리방침 페이지(`/privacy`) 는 개인정보보호법 제30조 13개 필수 기재사항을 모두 포함.
- **FR-6**: 수집 항목 표는 분류(가입 / 사업자 신원 / 정산 / 대표자 본인확인 / 행사 운영 / 서비스 이용)별로 수집 항목 + 수집 목적을 표 형식으로 노출.
- **FR-7**: 국외이전 챕터는 수탁업체 / 소재지 / 이전 항목 / 이전 목적 / 보유 기간 5개 항목을 표 형식으로 노출.
- **FR-8**: 처리 위탁 챕터에 수탁자 / 위탁 업무 표 노출.
- **FR-9**: 제3자 제공 챕터에 참가자에게 제공되는 항목(파트너 상호 / 대표자명) 명시. 제공 목적 / 거부 권리 고지.
- **FR-10**: 자동화된 결정에 대한 거부·설명 요구권 챕터 — 현재 적용 여부와 무관하게 명시. 미적용 시 "해당 없음" 명시.
- **FR-11**: 페이지 하단에 공고일자 / 시행일자 명시. 약관 변경 시 두 일자가 함께 갱신.
- **FR-12**: 보유 기간 챕터에 전자상거래법 / 부가가치세법 / 통신비밀보호법 근거별 항목 / 보존 기간 명시.

## Non-Functional Requirements

> 측정 가능해야 함 — "빨라야 함" 금지. 환경 + 분위수 명시.

- **NFR-1**: 페이지 초기 로딩 → first contentful paint 1.5s 이내 (프로덕션 CDN, p75, 4G 모바일 baseline). 정적 페이지이므로 캐시 hit 시 500ms 이내 (p50).
- **NFR-2**: 접근성 — 챕터 헤더는 h2 / h3 위계 준수, 목차 링크는 키보드 내비 가능, 표 캡션 + 헤더 셀 명시. 본문 텍스트 대비비 4.5:1 이상.
- **NFR-3**: 법적 필수 기재사항 13개 항목 누락 0건 — 매 약관 / 방침 변경 시 법무 체크리스트 통과 후 머지.
- **NFR-4**: 반응형 — 모바일(360px) / 태블릿(768px) / 데스크톱(1280px) 3 break point 에서 본문 가독성 유지. 표는 가로 스크롤 또는 세로 스택으로 fallback.

| CUJ ID | 케이스 | 기대 동작 |
|--------|--------|----------|
| 1-1 | 모바일 360px 폭에서 목차 표시 | 목차를 접힌 상태로 노출 + 탭으로 펼침. 본문 가독성 우선 |

| 1-3 | 동의 체크 없이 직접 등록 API 호출 시도 | 서버측에서도 동의 여부 검증 (백엔드 추가 가드) |

| 2-3 | 신규 위탁사 추가 시 | 위탁 챕터 표 갱신 + 시행일자 갱신 |
| 2-4 | 향후 자동화 결정 시스템 도입 | 본 챕터를 "해당 없음" → 적용 항목 / 거부 절차로 갱신 |
| 3-1 | 13개 필수 기재사항 중 누락 발견 | 법무 체크리스트 fail → 머지 차단 |
| 3-2 | 시행일자가 미래인 경우 | 시행 전이라도 페이지 노출은 가능. footer 에 "시행 예정" 라벨 |

## Open Questions

> 결정 못한 항목 — 1주 이상 방치 시 명시적으로 결정 또는 Non-Goal 로 이동.

- [ ] **전자금융거래법 PG 등록 의무 적용 여부** — 밍글릿이 행사 참가비를 수취→정산하는 구조라면 전자지급결제대행업 등록 대상일 수 있음. PortOne 등 PG사 파트너정산 서비스로 회피 가능한지 법무 컨펌
- [ ] **수수료율 약관 기재 수준** — 구체적 요율을 약관에 직접 명시 vs 별도 요금표로 분리
- [ ] **무료 행사 주최자의 사업자 자격 면제 범위** — 개인이 무료 모임을 올리는 경우 사업자 등록 없이 가능한지
- [ ] **landing_user 처리방침 국외이전 조항 추가 시점** — 본 PR 동시 vs 별도 이슈
- [ ] **약관 변경 시 기존 파트너 재동의 플로우** — admin-dashboard 약관 버전 관리 PR 과 묶기
- [ ] **landing_user 약관과 중복 조항(파트너 의무)** — 상호 참조 vs 단일 SSoT 결정

# PRD: 파트너 약관·개인정보처리방침

## Summary

파트너(모임 주최자/사업자)용 랜딩(`landing_partner`)에 이용약관 / 개인정보처리방침 페이지를 신설. 사업자 고유 수집 항목(사업자등록번호·정산 계좌 등) + B2B 약관(수수료·정산·해지)을 별도 고지하여 법무 감사 [High] 이슈(#747, #764)를 해결한다.

## Motivation / Problem to Solve

- 법무/개인정보 감사(#747, #764)에서 파트너 측 약관·처리방침 부재가 [High] 이슈로 지적
- 정보통신망법 제27조의2, 개인정보보호법 제30조 위반 — 파트너에게도 별도 고지 의무
- 파트너는 일반 유저와 수집 항목이 다름 (사업자등록번호, 정산 계좌, 대표자 정보 등)
- 정산·수수료·입점 자격 등 B2B 특유 약관 조항이 유저 약관에 포함될 수 없음
- 현재 landing_user 처리방침에는 국외이전(Supabase) 조항도 누락 — 파트너 추가 시점에 함께 보강

## Goals

### Target Users

- **신규 파트너 후보**: 파트너 등록 직전에 약관·수수료·정산 정책을 사전 검토하는 사용자
- **기존 파트너**: 약관 변경 시 변경 사항을 확인하는 사용자
- **법무 감사 / 규제 기관**: 개인정보처리방침 필수 기재사항 13개 항목 준수 여부 확인

### Key Goals

- **P0**: 파트너 이용약관 페이지 신설 (`/terms`) — 가입 자격 / 의무 / 수수료 / 정산 / 해지 5개 챕터
- **P0**: 파트너 개인정보처리방침 페이지 신설 (`/privacy`) — 개인정보보호법 제30조 필수 기재사항 13개 항목 충족
- **P0**: 국외이전(Supabase) 조항 명시 — 수탁업체 / 소재지 / 이전 항목 / 보유 기간
- **P0**: 자동화된 결정에 대한 거부·설명 요구권 (2023년 개정 신설 항목) 명시 — 미적용 시에도 "해당 없음" 명시
- **P1**: landing_user 글로벌 스타일과 일관된 레이아웃 + 파트너 인디고 액센트 적용
- **P1**: 공고일자 / 시행일자 footer 명시 + 약관 버전 관리 토대

### Non-Goals

- 동적 약관 버저닝 / 재동의 플로우 (별도 PR — admin-dashboard 시스템 설정에서 다룸)
- 외국어 약관 (한국어 단일)
- landing_user 처리방침의 국외이전 조항 추가 (권고만, 별도 이슈)
- 실제 약관 문구 최종 확정 — 본 PRD는 구조·필수 기재사항 설계, 문구는 법무 검토 후 확정

## Product Principles

1. **landing_user 와 구조적 일관성**: 동일한 레이아웃·타이포·여백 패턴. 파트너만의 액센트는 인디고 컬러로 최소화.
2. **B2B 고유 조항 분리**: 정산·수수료·입점 자격·사업자 의무는 유저 약관과 별도. 중복 시 상호 참조.
3. **법적 필수 기재사항 우선**: 디자인보다 법무 요건이 우선. 13개 필수 항목 누락 금지.
4. **사전 정보 접근성**: 파트너 후보가 수수료·정산 주기 등 핵심 관심 사항을 약관 진입 직후 빠르게 도달 가능하게 배치.

## Technical Approach

- **화면 (신규 2개)**: 파트너 이용약관 페이지 / 파트너 개인정보처리방침 페이지
- **데이터**: 정적 콘텐츠 — 외부 API 의존 없음
- **스타일**: 공용 디자인 토큰 + Pretendard 폰트. 파트너 액센트 인디고
- **법적 근거 표**: 보유 기간 / 위탁 / 국외이전 / 수집 항목 / 자동화 결정 거부권 등 표 형식 고지

## User Journey

### Scenario 1: 파트너 후보가 약관 사전 검토 (CUJ 1-x)

신규 파트너 후보가 등록 결정 전 이용약관 페이지에 진입하여, 수수료율 / 정산 주기 / 입점 자격을 확인한 뒤 가입 여부를 결정한다.

### Scenario 2: 파트너가 개인정보 처리 항목 확인 (CUJ 2-x)

파트너가 수집 항목 / 보유 기간 / 국외이전 / 위탁 / 자동화 결정 거부권 등을 처리방침에서 확인한다.

### Scenario 3: 법무·규제 기관이 필수 기재사항 검수 (CUJ 3-x)

법무 / 규제 기관 / 내부 감사 담당자가 개인정보보호법 제30조 13개 필수 기재사항 충족 여부를 페이지에서 검수한다.

## Data Flow

### Scenario 1

랜딩 진입 → 푸터 / 파트너 등록 페이지에서 "이용약관" 링크 탭 → `/terms` 진입 → 챕터 별 스크롤 검토

### Scenario 2

랜딩 진입 → 푸터 / 파트너 등록 페이지에서 "개인정보처리방침" 링크 탭 → `/privacy` 진입 → 필수 기재사항 표 검토

### Scenario 3

직접 URL 접근 → 페이지 전체 스크롤 → 필수 항목 (수집 항목 / 보유 기간 / 국외이전 / 자동화 결정 / 보호책임자) 표 확인

## KPIs / Success Metrics

- **법무 감사 통과**: 차기 감사에서 #747 / #764 이슈 close
- **페이지 도달율**: 파트너 등록 입구에서 약관 / 처리방침 클릭률 (baseline 측정 후 추후 비교)
- **약관 페이지 체류시간**: 파트너 후보의 사전 검토 깊이 proxy

## Launch Strategy

법무 검토 완료 후 한 번에 게시. 시행일자 명시로 적용 시점 통제. 변경 시 30일 사전 공지.

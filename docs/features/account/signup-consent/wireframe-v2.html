🔍 현재 이용약관 동의 화면 UX 이슈 분석

1
Card soup: 각 항목이 개별 Card로 감싸져 시각적 노이즈가 과다. 카드 테두리/그림자 반복으로 시선이 분산됨
2
SwitchListTile: "전체 동의"에 시스템 설정 스타일 Switch 사용 → 동의 행위라기보다 설정 토글처럼 보임
3
Checkbox 정렬: Material 기본 Checkbox의 내장 패딩으로 텍스트와 정렬이 어긋남
4
"보기" 버튼: TextButton이 카드 우상단에 떠있어 각 항목마다 높이가 달라지고 시각적 일관성 부족
5
브랜드 표현 부재: 보라색 primary가 태그에만 살짝 사용됨. 밍릿다운 개성이 없는 기본 Material 느낌
6
마지막 항목 잘림: "마케팅 정보 수신 동의"가 CTA 버튼에 가려 스크롤 필요. 시각적 단서 없음
7
필수/선택 구분 약함: 작은 태그만으로 구분 → 유저가 어떤 것이 필수인지 한눈에 파악 어려움
8
CTA 비활성 상태: 회색 배경 + 회색 텍스트로 "죽은" 느낌. 활성 상태와의 시각적 격차가 커서 불안감 유발

✅ 리디자인 개선 사항

1
카드 → 플랫 리스트: 개별 Card 제거. 깔끔한 리스트 형태로 시각적 노이즈 제거. 토스/당근 스타일
2
Switch → 원형 체크: 전체 동의도 통일된 원형 체크 UI 사용. 동의 행위에 맞는 시각적 메타포
3
원형 체크박스: 커스텀 CircleCheckbox로 정렬 일관성 확보. 체크 시 보라색 fill + 애니메이션
4
"보기" → 인라인 링크: 우측에 "보기 ›" 형태로 자연스럽게 배치. 높이 일관성 확보
5
브랜드 강화: 전체 동의 배경에 보라색 틴트, 체크 시 보라색 circle fill, CTA 보라색 + 글로우 섀도
6
전체 항목 노출: 플랫 리스트로 높이 절약 → 모든 항목이 스크롤 없이 화면에 노출
7
필수/선택 구분 강화: 필수와 선택 사이에 구분선 추가. 필수 태그는 보라색, 선택은 회색으로 차별화
8
CTA 텍스트 변경: "다 같이 시작하기" → "동의하고 시작하기" (행위의 의미 명확화). 활성 시 보라색 글로우

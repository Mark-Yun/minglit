## Functional Requirements

- **FR-1**: 신규 유저 (필수 동의 3종 미완료) 만 SignupConsentScreen 진입. 라우터 가드가 모든 보호 경로 접근 시 동의 완료 여부 검증.
- **FR-2**: 필수 3개(서비스 약관 / 개인정보 수집 / 만 14세) 모두 체크되어야 CTA 활성화. 사전 체크(pre-checked) 금지.
- **FR-3**: CTA 탭 시 체크된 모든 항목을 user_consents 에 bulk upsert. (consent_key + policy_version + consented_at 기록)
- **FR-4**: "모두 동의" 토글 ↔ 5개 개별 항목 양방향 sync. 중간 상태 없음.
- **FR-5**: 약관 항목(서비스 약관 / 개인정보 수집 / 제3자 제공) 탭 시 바텀시트로 약관 전문 표시. 스크롤 + 닫기 버튼.
- **FR-6**: 시스템 백 → 확인 다이얼로그 → 확정 시 OAuth 세션 해제 (로그아웃) → 로그인 화면 복귀.
- **FR-7**: 본인인증 시작 전 IdentityVerificationConsentSheet 표시. 동의 체크 시에만 CTA 활성. 취소 시 바텀시트 dismiss.
- **FR-8**: CI/DI 동의 후에만 Portone 호출. 동의 미체크 상태에서 본인인증 진행 금지.
- **FR-9**: Portone 인증 성공 시 user_consents 의 `identity_verification` 항목 consented=true 저장.
- **FR-10**: PrivacyManagementPage 에서 선택 동의(마케팅/제3자 제공) 토글 변경 가능. 필수 동의 항목은 UI 비활성.
- **FR-11**: 제3자 제공 철회 후 이벤트 신청 시, 해당 신청마다 별도 동의 안내 표시.
- **FR-12**: 가입 완료 후 HomePage 진입. 라우터 가드가 SignupConsentScreen 재진입 차단.

## Non-Functional Requirements

- **NFR-1**: 화면 진입 → first paint 200ms 이내 (에뮬레이터 baseline, p50 기준).
- **NFR-2**: 바텀시트 약관 전문 로딩 500ms 이내 (사전 fetch + cache 활용).
- **NFR-3**: 동의 저장 실패 시 retry 1회 → 실패 시 스낵바 + 재시도 버튼. 가입 진행 차단.
- **NFR-4**: 접근성 — 모든 체크박스/토글 semanticsLabel + 최소 터치 영역 48dp. 필수 항목 disabled 시 reason 안내.
- **NFR-5**: 동의 이력 최소 2년 보존 (개인정보보호법 시행령). 권장 5년.

## Edge Cases

| CUJ ID | 케이스 | 기대 동작 |
|--------|--------|----------|
| 1-1 | 동의 저장 중 네트워크 끊김 | retry 1회 → 실패 시 스낵바 + 재시도. CTA 재활성. user_consents 미커밋 상태 유지 |
| 1-1 | 만 14세 미만 체크 안 함 | CTA 비활성 유지 (가입 진행 불가). 다이얼로그 안내는 Open Q |
| 1-1 | 저장 도중 앱 kill | 재진입 시 다시 동의 화면 (필수 동의 미완료 상태 유지) |
| 1-1 | 동일 유저 재가입 (재OAuth) | 기존 user_consents 있으면 가드 통과 → HomePage 직진 |
| 1-5 | 백 다이얼로그 중 앱 kill | 재진입 시 다시 동의 화면 |
| 1-6 | 가드 검사 중 네트워크 끊김 | 캐시된 동의 상태 사용. 캐시 없으면 동의 화면 진입 (안전 default) |
| 2-1 | 이미 본인인증 완료한 유저가 재진입 | 정책 미정 (Open Q) — 매번 동의 vs 1회만 |
| 2-2 | Portone 호출 중 에러 | 기존 Portone 에러 핸들링 유지. user_consents 의 identity_verification 미저장 |
| 2-3 | 바텀시트 dismiss 중 외부 인텐트로 앱 이탈 | 동의 미저장 상태 유지. 재진입 시 처음부터 |
| 3-1 | 마케팅 토글 저장 실패 | 토글 원상복구 + 스낵바 |
| 3-2 | 제3자 제공 철회 후 진행 중 이벤트 | 정책 미정 (Open Q) — 소급 적용 vs 안내 알림 |
| 3-3 | 필수 항목 disabled 토글 강제 탭 | 안내 다이얼로그 ("탈퇴로만 철회 가능, 탈퇴 가이드 보기") |

## 화면 구성 (참고)

### 화면 1: 회원가입 약관 동의 (SignupConsentScreen)

**표시 시점**: 최초 OAuth 로그인 후 (필수 동의 미완료 유저). 가드 redirect 로 강제 진입.

**레이아웃** (위→아래):

```
┌──────────────────────────────────┐
│  [백 버튼]                       │ ← 시스템 back 만
│                                  │
│  환영합니다! 👋                  │ ← 타이틀 large
│  서비스 이용을 위해              │ ← 본문 medium
│  약관에 동의해주세요             │
│                                  │
│  ┌────────────────────────────┐  │
│  │ ☑ 모두 동의합니다          │  │ ← 전체동의 토글
│  └────────────────────────────┘  │
│                                  │
│  ┌────────────────────────────┐  │
│  │ (필수) 서비스 이용약관     │ → │ ← 탭 → 바텀시트
│  │ (필수) 개인정보 수집·이용  │ → │ ← 탭 → 바텀시트
│  │ (필수) 만 14세 이상입니다  │ ○  │ ← 체크박스
│  │ (선택) 제3자 제공 동의     │ → │ ← 탭 → 바텀시트
│  │ (선택) 마케팅 정보 수신    │ ○  │ ← 체크박스
│  └────────────────────────────┘  │
│                                  │
│  ※ 선택 항목에 동의하지 않아도  │ ← 본문 small
│    서비스 이용에 영향이 없습니다 │
│                                  │
│  ┌────────────────────────────┐  │
│  │      동의하고 시작하기      │  │ ← CTA (필수 3개 체크 시 활성)
│  └────────────────────────────┘  │
└──────────────────────────────────┘
```

### 동의 항목 정의

| # | 항목 | 필수/선택 | consent_key | 내용 요약 |
|---|------|----------|-------------|----------|
| 1 | 서비스 이용약관 | 필수 | `terms_of_service` | 서비스 이용 조건, 금지 행위, 계정 관리 |
| 2 | 개인정보 수집·이용 | 필수 | `privacy_collection` | 수집 항목(이름·이메일·프로필), 목적, 보유기간 |
| 3 | 만 14세 이상 확인 | 필수 | `age_confirmation` | (약관 아님, 확인란) |
| 4 | 제3자 제공 동의 | 선택 | `third_party_provision` | 파트너에게 참가자 정보 제공 — 이벤트 운영 목적 |
| 5 | 마케팅 정보 수신 | 선택 | `marketing_consent` | 이벤트/혜택 안내 (Push, Email) |
| 6 | 본인인증 정보 (CI/DI) | 필수 | `identity_verification` | 본인확인 시점에 별도 수집 |

### 법적 필수 고지 (바텀시트 본문)

**개인정보 수집·이용 (`privacy_collection`)**:

| 고지 항목 | 내용 |
|----------|------|
| 수집 항목 | 이름, 이메일, 프로필 사진, 관심 태그 |
| 수집 목적 | 서비스 제공 (계정 관리, 이벤트 매칭, 프로필 표시) |
| 보유 기간 | 회원 탈퇴 시까지 (관련 법령에 따른 보존 별도 안내) |
| 거부 권리 | 동의를 거부할 수 있으나, 거부 시 서비스 이용 불가 |

**제3자 제공 (`third_party_provision`)**:

| 고지 항목 | 내용 |
|----------|------|
| 제공받는 자 | 이벤트 주최 파트너 (이벤트 신청 시 해당 파트너에 한정) |
| 제공 항목 | 이름(닉네임), 연령대, 자격 인증 정보(직업/소속 — 본인인증 완료 유저만) |
| 제공 목적 | 이벤트 운영 (참가자 확인, 매칭, 체크인) |
| 보유 기간 | 이벤트 종료 후 30일 |
| 거부 권리 | 거부 가능. 거부해도 서비스 이용 제한 없음. 이벤트 신청 시 개별 동의 재요청 |

> **위탁 vs 제3자 제공**: Portone(결제), Iamport(본인인증) 등은 **위탁** — 별도 동의 불필요 (개인정보처리방침 공개). 파트너에게 참가자 정보 제공은 **제3자 제공** — 별도 동의 필요.

### 화면 2: 본인인증 CI/DI 동의 (IdentityVerificationConsentSheet)

**표시 시점**: `/certification` 화면에서 "본인인증 시작" 버튼 탭 전.

**바텀시트 본문**:

| 고지 항목 | 내용 |
|----------|------|
| 수집 항목 | 이름, 생년월일, 성별, 휴대폰 번호, CI (연계정보), DI (중복확인정보) |
| 이용 목적 | 본인확인 및 실명 인증, 중복 가입 방지 |
| 보유 기간 | 회원 탈퇴 시까지 (관련 법령 보존) |

CTA: "본인인증 시작하기" (동의 체크 시 활성) · "취소" (TextButton).

### 화면 3: 동의 관리 (PrivacyManagementPage)

**경로**: `/my/privacy` (기존 PrivacyPage 교체)

| 항목 | 초기값 | 변경 가능 |
|------|--------|----------|
| 서비스 이용약관 | 동의 | 불가 (탈퇴로만 철회) |
| 개인정보 수집·이용 | 동의 | 불가 (탈퇴로만 철회) |
| 만 14세 이상 확인 | 동의 | 불가 |
| 제3자 제공 | 가입 시 선택 | **가능** (철회 시 이벤트 신청마다 개별 동의 안내) |
| 마케팅 정보 수신 | 가입 시 선택 | **가능** |
| 본인인증 정보 | 동의 | 불가 (탈퇴로만 철회) |
| 약관 보기 | — | 링크 → 바텀시트 |

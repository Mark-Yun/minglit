# Trust Badge (신뢰 배지) 시스템

## 개요

밍글릿(Minglit)은 프리미엄 소셜 매칭 플랫폼으로서 유저 간의 신뢰를 가장 중요한 자산으로 여긴다. 기존의 '매너온도'와 같은 정성적/상대적 지표에서 벗어나, 플랫폼이 직접 검증한 데이터 기반의 **Hard Trust**를 시각화하여 유저에게 안전하고 신뢰할 수 있는 연결을 제공한다.

### 핵심 원칙

- **Layered Trust** — 본인확인(Identity), 자격인증(Qualification), 활동지표(Reliability)의 3단계 계층 구조.
- **투명한 근거 제공** — 배지는 결과일 뿐, 클릭 시 배지를 획득하게 된 구체적인 인증 항목(삼성전자 재직, 서울대 졸업 등)을 투명하게 공개.
- **프리미엄 감성** — 단순한 뱃지가 아닌, 밍글릿의 브랜드 아이덴티티가 담긴 세련된 UI로 유저의 성취감과 소속감 고취.

---

## 3-Layer Trust 구조

| 레벨 | 명칭 | 아이콘 | 조건 | 의미 |
|---|---|---|---|---|
| **Level 1** | **Identity** | 🛡️ (Shield) | 본인확인(CI) 완료 | "실존하며 본인 확인이 된 유저입니다." |
| **Level 2** | **Qualification** | ✨ (Sparkles) | 파트너 인증(직장/학력 등) 1개 이상 승인 | "검증된 사회적 배경을 가진 유저입니다." |
| **Level 3** | **Reliability** | 💎 (Diamond) | 최근 10개 이벤트 출석률 95% 이상 | "약속을 잘 지키는 매너 있는 유저입니다." |

## 구성 요소

### 1. 데이터 요구사항 (Conceptual)

*참고: 상세 데이터 스킴은 `needs-arch` 단계에서 확정.*

- **User Trust Level**: 유저의 현재 최고 트스트 레벨 상태.
- **Verification Snapshots**: 유저가 완료한 개별 인증 데이터 (인증명, 카테고리, 완료일).
- **Attendance Stats**: 출석률, 노쇼 횟수 등 활동 지표.

### 2. UI/UX 요구사항

#### 2.1 Trust Badge 위젯 (`TrustBadge`)
- 유저 이름 옆, 프로필 카드, 채팅 등 유저가 노출되는 모든 곳에 표시.
- 현재 유저의 **가장 높은 레벨**의 아이콘을 표시.
- 클릭 시 `TrustSheet` (바텀 시트) 오픈.

#### 2.2 Trust Sheet (바텀 시트)
- **헤더**: 유저 이름 + 현재 신뢰 등급 타이틀.
- **신뢰 요약**: 3단계 레이어 중 어디까지 달성했는지 시각적으로 표시.
- **인증 내역**: 유저가 실제로 인증받은 항목들을 리스트 형태로 노출 (예: `[직장] 삼성전자`, `[학력] 서울대학교`).
- **활동 지표**: "최근 출석률 100%", "매칭 만족도 상위 5%" 등의 데이터 기반 메시지.

### 3. 클라이언트 모델

```dart
enum TrustLevel {
  none,       // 미인증
  identity,   // 본인확인 완료 (🛡️)
  qualified,  // 자격인증 완료 (✨)
  reliable    // 활동지표 우수 (💎)
}

@freezed
class UserTrustInfo with _$UserTrustInfo {
  const factory UserTrustInfo({
    required TrustLevel level,
    required bool isIdentityVerified,
    required List<UserVerificationRecord> verifications,
    required double attendanceRate,
    // ... 기타 지표
  }) = _UserTrustInfo;
}
```

## 유저 시나리오

1. **인증 유도**: 마이페이지에서 본인의 '미인증' 상태를 확인하고 '인증하기'를 통해 신뢰도를 높이도록 유도.
2. **신뢰 확인**: 이벤트 상세 페이지의 참가자 목록에서 타인의 배지를 보고 신뢰도를 판단.
3. **근거 탐색**: 배지를 클릭하여 해당 유저가 어떤 인증을 받았는지(예: 대기업 재직자 등) 확인하여 안심하고 매칭 신청.

---

## 향후 확장성 (Phase 2+)

- **배지 컬렉션**: 특정 카테고리(예: 운동, 독서) 활동이 많은 유저에게 부여하는 전문 분야 배지.
- **프리미엄 혜택**: Level 3(💎) 유저에게 이벤트 우선 매칭권 또는 수수료 할인 혜택 제공.
- **파트너 전용 배지**: 파트너 앱에서 호스트의 신뢰도를 나타내는 배지 시스템 통합.

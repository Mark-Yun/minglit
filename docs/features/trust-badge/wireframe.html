신뢰 배지 시스템

3단계 신뢰 배지를 운영해요

인증
인증됨 (Verified)
본인인증을 완료한 사용자예요. 실명이 확인된 분이에요.
필요 조건: 본인인증(정부 ID) 완료
자격인증
자격인증 (Certified)
본인인증에 더해 직장, 학력 등 자격이 파트너에 의해 확인된 분이에요.
필요 조건: 본인인증 + 1개 이상 자격 인증
엘리트
엘리트 (Elite)
자격인증은 물론, 95% 이상의 출석률을 유지하는 최상위 신뢰 등급이에요.
필요 조건: 자격인증 + 출석률 95% 이상
배지는 어떻게 받나요?
1. 회원가입 시 본인인증을 완료하면 인증 배지가 부여돼요
2. 파트너가 직장·학력을 확인하면 자격인증 배지로 승급해요
3. 꾸준히 참여하며 출석률 95%를 달성하면 엘리트가 돼요

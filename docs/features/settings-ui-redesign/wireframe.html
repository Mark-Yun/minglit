디자인 가이드라인 (Claude Style)

항목 현재 (Minglit) 변경 (Compact) 비고
타일 높이 56px ~ 64px 48px Fixed height for consistency
글자 크기 (Title) 16px (bodyLarge) 14.5px (bodyMedium) 정보 밀도 향상
아이콘 크기 24px 20px MinglitIconSize.small
섹션 구분 전체 너비 Divider 카드 그룹핑 (Radius 16) 그룹별 시각적 분리 강화
섹션 제목 없음 (Divider만) 상단 소제목 (13px Bold) 직관적인 카테고리 인지
설정값 표시 없음 (진입 후 확인) 우측 텍스트 (Value) 뎁스 이동 없이 상태 확인

코드 구현 제안 (Widget Specs)

// 1. MinglitSettingsGroup
MinglitSettingsGroup(
  title: '앱 설정',
  children: [
    MinglitSettingsTile(...),
    MinglitSettingsTile(...),
  ],
)

// 2. MinglitSettingsTile
MinglitSettingsTile(
  leadingIcon: Icons.notifications,
  title: '알림 설정',
  value: '켜짐',
  onTap: () => ...,
)

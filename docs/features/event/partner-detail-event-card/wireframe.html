변경 사항

BUG 1. 오버플로우 수정

문제: 이벤트 카드 하단 1px 오버플로우 (BOTTOM OVERFLOWED BY 1.0 PIXELS)

원인: eventCardContentHeight = 64.0이 실제 콘텐츠 높이보다 부족

수정:

  • partner_detail_view.dart L175: eventCardContentHeight를 64.0 → 68.0으로 변경
  • padding(8+8) + titleMedium(~24) + xxsmall(2) + bodySmall row(~20) = ~62px인데, 디바이스별 폰트 메트릭 차이로 1px 초과 발생. 여유 4px 확보

UX 2. 파트너 뱃지 조건부 표시

문제: 파트너 상세 페이지 안에서 이벤트 카드마다 동일한 파트너 이름/아바타가 반복 표시. 정보 중복이고 이미지 가시 영역을 불필요하게 차지

수정:

  • MinglitEventCard에 showPartnerOverlay 파라미터 추가 (기본값 true)
  • PartnerDetailView._buildHorizontalEventList()에서 showPartnerOverlay: false 전달
  • PartnerEventsPage (더 보기 전체 목록)에서도 동일하게 showPartnerOverlay: false
  • 홈 피드, 검색 등 다른 컨텍스트에서는 기존대로 파트너 뱃지 표시 유지

UX 3. 디자인 근거

파트너 뱃지를 제거하면:

  • 정보 중복 제거: 이미 "밍글 스튜디오" 페이지 안에 있으므로 각 카드에 파트너 정보를 반복할 필요 없음
  • 이미지 가시성 향상: 좌상단 오버레이가 사라져 이벤트 이미지가 더 넓게 보임
  • 시각적 밀도 감소: 작은 카드(210px)에 오버레이가 2개 → 1개로 줄어 더 깔끔
  • 참고 사례: 인스타그램 프로필 페이지의 릴스/게시물에 프로필 뱃지를 표시하지 않는 것과 동일한 패턴

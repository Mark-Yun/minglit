## Functional Requirements

- **FR-1**: 홈 인사 영역에 "👋 {파트너명} 님 / 오늘 할 일 N건" 표시. N = 승인 대기 수.
- **FR-2**: 할 일 0건 / 이벤트 진행 중 / 종료 직후에 따라 인사 문구 분기 ("오늘 할 일 없음" / "이벤트 진행 중!" / "오늘 이벤트 수고하셨어요!").
- **FR-3**: 할 일 칩 3개 표시 — 승인 대기 / 다가오는 이벤트 / 미답변 리뷰. 각 칩에 카운트.
- **FR-4**: 칩 탭 시 해당 화면으로 이동 (승인 대기 → 신청관리 탭 대기중, 다가오는 이벤트 → 더보기/파티관리).
- **FR-5**: 카운트 0 시 칩 비활성(회색). 미답변 리뷰는 시스템 미구현이므로 "준비 중" 라벨 + 탭 시 "곧 출시" 토스트.
- **FR-6**: 이번 주 성과 3칸 그리드 — 매출 / 신청 / 체크인율 + 지난주 대비 %. 신규 파트너 (데이터 없음) 시 섹션 숨김. 로딩 중 스켈레톤. 에러 시 섹션 숨김(비핵심).
- **FR-7**: 할 일 칩 / 이벤트 액션카드 / 이번 주 성과는 각각 독립 데이터 로딩 단위. 한 단위 에러가 다른 단위 표시를 차단하지 않음.
- **FR-8**: 이벤트 액션카드는 가장 시급한 이벤트 1건만 표시. 우선순위: LIVE > 준비 중(3h 이내) > 종료(24h 이내) > 모집 중. 동일 phase 면 시작 시간 빠른 순.
- **FR-9**: 액션카드는 phase(모집 중 / 준비 중 / LIVE / 종료) 에 따라 배지 + 색상 + 메인 CTA + 보조 액션이 자동 분기.
- **FR-10**: phase 정의 — 모집 중 = 시작까지 3h 초과 / 준비 중 = 시작까지 3h 이하 / LIVE = 시작 ~ 종료 / 종료 = 종료 후 24h 이내. 종료 후 24h 경과 시 카드에서 제외.
- **FR-11**: 종료 phase 의 "다음 회차 만들기" CTA 는 이벤트 생성 화면으로 이동하면서 파티 / 장소 / 인원 / 티켓 설정을 프리필. 날짜 / 시간만 비워둠.
- **FR-12**: 파티 있고 이벤트 0개 시 액션카드 자리에 "이벤트를 만들어 신청을 받아보세요" + 이벤트 생성 CTA. 파티 0개 시 온보딩 스텝 가이드 표시.
- **FR-13**: 신청관리 탭은 3 탭(대기중 / 승인됨 / 거절됨). 기본 대기중.
- **FR-14**: 대기중 탭에서 신청을 이벤트별로 그루핑. 이벤트 헤더(이름 + 날짜) + 신청자 row(이름 / 나이 / 성별 / 신청 시간).
- **FR-15**: 신청 row 우측에 인라인 승인 / 거절 아이콘. 탭 시 즉시 처리 (상세 진입 없음). 처리 후 row 사라짐 + 카운트 갱신.
- **FR-16**: 하단 고정 "전체 승인 (N건)" 버튼. 탭 시 확인 다이얼로그 후 해당 탭의 대기 신청 전원 승인. 결제 트리거 / 알림은 서버 부수 효과로 일괄 처리.
- **FR-17**: 체크인 탭 진입 시 "오늘" 진행 중/예정 이벤트 수를 판정 — 0 / 1 / 2+ 별 분기.
- **FR-18**: 이벤트 1건 → QR 스캐너 즉시 진입. 2건+ → 이벤트 선택 바텀시트 → 선택 후 스캐너. "오늘" 범위 = 시작 3h 전 ~ 종료 후 1h.
- **FR-19**: 오늘 이벤트 0건 시 "오늘 예정된 이벤트가 없습니다" + 다음 이벤트 정보(날짜 / 시간 / 이름) 표시.
- **FR-20**: QR 스캐너 화면만 다크 배경 (카메라 사용). 바텀탭 영역도 다크 배경 유지. 다른 화면 전환 시 라이트 복귀.
- **FR-21**: 파티 0개면 스텝 가이드 / 파티 1+ + 이벤트 0개면 이벤트 넛지 / 이벤트 1+ 면 일반 대시보드. 첫 이벤트 생성 시 자동으로 일반 대시보드로 전환.
- **FR-22**: 스텝 가이드 — 진행률 바 + 4단계 체크리스트(파트너 가입 / 계좌 등록 / 첫 파티 / 첫 이벤트) + 메인 CTA "첫 파티 만들기". 4단계 진행 흐름 안내 표시.
- **FR-23**: 이벤트 넛지 — 진행률 바 + 체크리스트(3/4 완료) + 방금 만든 파티 카드 + 메인 CTA "첫 이벤트 만들기".

## Non-Functional Requirements

- **NFR-1**: 홈 first paint 300ms 이내 (에뮬레이터 baseline, p50). 캐시 미스 시 600ms 이내 (p95).
- **NFR-2**: 섹션 독립 로딩 — 한 섹션의 응답 지연 / 실패가 다른 섹션 first paint 를 차단하지 않음. 각 섹션 독립 timeout.
- **NFR-3**: 할 일 칩 카운트 실시간성 — 신청 승인 후 카운트 갱신까지 p95 < 3초 (홈 재진입 또는 invalidate).
- **NFR-4**: 인라인 승인 / 거절 응답 — p50 < 800ms (네트워크 정상). 전체 승인은 비동기 + 진행 안내.
- **NFR-5**: LIVE 배지 펄스 애니메이션 60fps 유지 (저사양 기기 baseline). 다른 화면 진입 시 정지.
- **NFR-6**: 신청 승인 / 거절은 단순 상태 변경이 아닌 부수 효과(결제 트리거 / 알림) 포함 — 트랜잭션 보장 + 실패 시 롤백.

| CUJ ID | 케이스 | 기대 동작 |
|--------|--------|----------|
| 1-2 | 할 일 칩 카운트 로드 실패 (단일 칩) | 해당 칩만 "-" 표시. 다른 칩은 정상 |
| 1-4 | 이번 주 성과 데이터 일부만 로드 (매출은 OK, 체크인율 에러) | 실패한 메트릭만 "-" 표시 또는 섹션 숨김 |
| 1-5 | 모든 섹션 동시에 에러 | 각각 에러 표시. 전체 화면 차단 X |
| 2-1 | 다가오는 이벤트가 여러 개 + 동시 시작 | 시작 시간 빠른 순 → 같으면 ID 순으로 결정 |
| 2-3 | LIVE 도중 이벤트 취소 | 액션카드 즉시 제거 + 다음 후보 표시 |
| 2-4 | "다음 회차 만들기" 진입 후 원본 이벤트 삭제 | 프리필은 캐시된 값 사용. 신규 생성은 정상 진행 |
| 2-5 | 파티 / 이벤트 모두 없는데 액션카드 영역으로 진입 | 온보딩 스텝 가이드 우선 표시 (액션카드 자리 대체) |
| 3-2 | 인라인 승인 처리 중 동일 신청을 유저가 취소 | 서버 충돌 감지 → "이미 처리된 신청입니다" 안내 + 목록 갱신 |
| 3-3 | 전체 승인 중 일부 실패 (정원 초과) | 성공 건 반영 + 실패 건 안내 + 재시도 옵션 |
| 4-1 | 체크인 탭 진입 직후 이벤트 종료 도달 | 다음 invalidate 시 빈 상태로 전환 |
| 4-2 | 체크인 도중 다른 이벤트도 시작 | 선택 바텀시트 재노출 (다음 진입 시) |
| 4-4 | QR 화면에서 백 → 다크 잔존 | 화면 전환 hook 으로 강제 라이트 복귀 |
| 5-1 | 신규 파트너인데 외부 데이터 fetch 실패 | 스텝 가이드 기본값으로 표시 (가입은 항상 완료 상태) |
| 5-3 | 첫 이벤트 생성 직후 새로고침 안 함 | 다음 홈 재진입 시 일반 대시보드 전환 |

### 바텀 네비게이션 (4 탭 → 5 탭)

| 탭 | 경로 | 설명 |
|----|------|------|
| 홈 | `/` | 할 일 대시보드 |
| 신청관리 | `/applications` | 이벤트별 그루핑된 신청 목록 |
| 체크인 | `/checkin` | QR 스캐너 (이벤트 자동 선택) |
| 정산 | `/settlement` | 매출 요약 + 정산 내역 |

### 이동되는 항목

| 항목 | 변경 위치 |
|------|----------|
| 파티 관리 | 더보기 > 내 파티 관리 |
| 설정 | 더보기 > 설정 섹션 |
| 멤버 관리 | 더보기 > 운영 섹션 |

### 홈 대시보드 구성

```
1. 인사 + 할 일 요약 ("👋 {파트너명} 님 / 오늘 할 일 N건")
2. 할 일 칩 3개 (승인 대기 N / 다가오는 이벤트 N / 미답변 리뷰 N)
3. 이벤트 액션카드 (가장 가까운 이벤트 1건, phase 별 자동 분기)
4. 이번 주 성과 3칸 그리드 (매출 / 신청 / 체크인율)
```

### Phase 별 배지 + 액션 (참고)

| Phase | 조건 | 배지 | 메인 CTA | 보조 액션 |
|-------|------|------|---------|----------|
| 모집 중 | 시작까지 3h 초과 | "모집 중" (초록) + D-N | 신청 현황 보기 | 이벤트 수정 / 공유·홍보 |
| 준비 중 | 시작까지 3h 이하 | "준비 중" (오렌지) + 남은 시간 | 체크인 준비 | 참석자 명단 / 안내 발송 |
| LIVE | 시작 ~ 종료 | "LIVE" (보라 + 펄스) + 경과 시간 | 체크인 계속하기 | 참석 현황 |
| 종료 | 종료 후 ~ 24h | "종료" (회색) + 종료 후 시간 | 다음 회차 만들기 | 상세 결과 |

### 신청관리 탭 구조

```
[대기중 (N)] [승인됨] [거절됨]     ← 탭바
─────────────────────────────
이벤트 A 헤더 (이름 · 날짜)       ← 이벤트별 그루핑
  신청자 1  [거절] [승인]         ← 인라인 액션
  신청자 2  [거절] [승인]
─────────────────────────────
이벤트 B 헤더
  신청자 3  [거절] [승인]
─────────────────────────────
[전체 승인 (N건)]                 ← 하단 고정 일괄 액션
```

### 체크인 탭 진입 분기

```
오늘 진행 중/예정 이벤트가:
  0개 → "오늘 예정된 이벤트가 없습니다" + 다음 이벤트 안내
  1개 → 바로 QR 스캐너 진입
  2개+ → 이벤트 선택 바텀시트 → 선택 후 스캐너
```

"오늘" 범위 = 시작 3시간 전 ~ 종료 후 1시간.

### QR 스캐너 화면

- 상단: 이벤트명 + 체크인 카운터 (N/M명)
- 중앙: QR 스캔 프레임
- 하단: 스캔 결과 카드 (참석자 이름 / 티켓 종류 / 나이 / 성별 / 결제 상태 배지)
- 배경: 다크 (해당 화면만, 앱 전체 테마는 라이트 유지)

### 정산 탭 — 상단 매출 요약 카드 (신규)

```
┌─ 매출 카드 (보라 그라디언트) ────┐
│  이번 달 총 매출: ₩1,280,000   │
│  정산 완료: ₩850,000           │
│  정산 대기: ₩430,000           │
└──────────────────────────────┘
```

기존 정산 내역 리스트는 그대로 유지.

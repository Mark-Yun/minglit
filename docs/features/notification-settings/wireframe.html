⬛ 구조 원칙

  • 4-tier IA: 시스템 권한 → 서비스 마스터 → 카테고리 → 마케팅 (별도 동의)
  • Cascade disabled: master OFF 또는 OS 거부 시 하위 토글 잠금 (값은 유지)
  • 인박스 vs 푸시: 설정은 푸시만 제어. 인박스 user_notifications엔 계속 저장 → "OFF해도 인박스 확인 가능"

⬛ 컴포넌트 매핑

  • MinglitSettingsGroup + MinglitSettingsTile 패턴 활용 (my_page.dart와 동일)
  • 기존 legacy SwitchListTile 교체 (notification_settings_screen.dart)
  • 타일 height 48px → 56px/64px 로 확장 (subtitle 가독성 — 기존 컴포넌트 variant 추가 필요)
  • 권한 배너: NEWOsPermissionBanner 위젯 (warning surface #FEF3C7)

⬛ 디자인 토큰

  • Section header: textTheme.labelSmall · onSurfaceVariant · uppercase · letter-spacing 0.5px
  • Group 배경: surfaceContainerLowest · radius 14px
  • Divider (타일 간): 0.5px · outlineVariant
  • Switch active: colorScheme.primary (#9900FF) · Switch.adaptive
  • Disabled: text/icon 알파 0.38 · switch 알파 0.3
  • 카테고리 leading icon 색상 6종 (구분용, 배경 없이 컬러 아이콘만)

⬛ 인터랙션

  • Optimistic update: 토글 즉시 반영 → EF 실패 시 롤백 + SnackBar "설정 저장 실패"
  • OS 권한 탭: 탭 시 AppSettings.openNotificationSettings() (app_settings 패키지)
  • 권한 실시간 반영: Lifecycle resumed 시 권한 재조회 → 배너 자동 갱신
  • Haptic: 토글 시 selection feedback (기존 패턴 일치)
  • 잠긴 child 탭: 잠긴 toggle 탭 시 SnackBar "서비스 알림 받기를 먼저 켜주세요"

⬛ 데이터 바인딩 (SWE 참고)

  • NEWuser_settings 컬럼 추가 필요 (SWE/architect 설계):
      · 방안 A: 개별 boolean 6개 (notify_application, notify_event_change, ...)
      · 방안 B: JSONB notification_preferences (유연, 후속 확장 유리) ← 권장
  • CHGuser-manage-settings EF 허용 필드 확대 (현재 marketing_consent / service_notification만)
  • CHGnotification-worker: 이벤트 타입 → 카테고리 매핑 후 user_settings 조회해 skip 판단. user_notifications insert는 유지

⬛ 이벤트 타입 ↔ 카테고리 매핑

  • 이벤트 신청: application_approved, application_rejected, new_application
  • 이벤트 변경: event_updated, event_cancelled, event_reminder
  • 매칭 결과: match_result
  • 활동 알림: party_created, user_interaction
  • 인증 알림: verification_result
  • 정산·결제 (Partner only): settlement_ready, settlement_completed, settlement_failed

⬛ 접근성

  • 토글 Semantics(label: '${title}, ${isOn ? "켜짐" : "꺼짐"}', toggled: isOn)
  • Disabled 토글: Semantics(enabled: false, hint: '서비스 알림 받기를 먼저 켜야 변경 가능')
  • 대비율: 모든 text vs bg ≥ 4.5:1 (light/dark 양쪽 verified)
  • 터치 타겟 56px · 최소 폰트 12px

⬛ 다크모드 매핑

  • Group 배경 surfaceContainerHigh · Divider outlineVariant (#3D3D3D)
  • Warning banner: #422006 배경 + #FCD34D 텍스트 (WCAG AA 통과 조합)

## Functional Requirements

> 제품 행동 정의 — DB schema / 컴포넌트 이름 같은 dev detail 은 제외 (코드가 SSoT).

- **FR-1**: 참가 현황 섹션 최상단에 Summary Bar 노출 — "전체 참여 N / M" + 연속 프로그레스 바 (primary 컬러). 입장그룹 유무와 무관하게 표시.
- **FR-2**: 입장그룹 카드는 2그룹 이벤트는 화면에 나란히, 3그룹 이상은 가로 스크롤. 카드 너비 고정, 오른쪽 카드 일부 잘림으로 스크롤 어포던스.
- **FR-3**: 가로 스크롤 영역에서 스와이프 / 드래그로 인접 카드 탐색 가능.
- **FR-4**: 그룹 카드 상단에 3px color strip — 남성 Blue (#60A5FA) / 여성 Pink (#F472B6) / 성별 무관 또는 기타 Primary (#9900FF).
- **FR-5**: 그룹 카드 내 카운트는 "N / M" 단일 표현 (20px bold). "N명 참여" 텍스트 + 게이지 중복 제거.
- **FR-6**: 그룹 카드 프로그레스 바는 연속 (높이 6px, radius 3px). 3칸 배터리 제거.
- **FR-7**: 그룹 카드 영역 하단에 단일 "참여자 정보 ▾" 토글. 탭 시 모든 그룹의 blur 리스트 동시 펼침. 다시 탭 시 동시 접힘.
- **FR-8**: blur 리스트는 그룹 카드 내부에 인라인 표시. 항목당 (a) 나이대 + (b) 인증뱃지(있는 경우) 노출.
- **FR-9**: 노출 금지 — 프로필 사진 / 이름 / 닉네임 / 성별 (이미 그룹으로 분리) / 지역 / 관심 태그.
- **FR-10**: 그룹 내 참여자 3명 미만이면 해당 그룹의 blur 리스트만 "(3명 미만 비표시)" 안내로 대체. 카운트는 정상 표시. 서버는 빈 배열 반환.
- **FR-11**: 비로그인 유저는 Summary Bar + 그룹 카운트 + 프로그레스만 공개. blur 리스트 영역에는 잠금 아이콘 + 로그인 CTA 카드 표시 (primary 5% opacity 배경).
- **FR-12**: 로그인 CTA 탭 시 원래 이벤트 ID 가 보존된 로그인 라우트로 이동. 로그인 후 원래 이벤트 상세로 복귀.
- **FR-13**: 이벤트 메타데이터의 참가자 명단 공개 플래그가 비활성일 때 blur 리스트 토글 미노출. 카운트 + 프로그레스 는 정상.
- **FR-14**: 입장그룹 없는 이벤트는 그룹 카드 영역 비노출. Summary Bar 만 표시.

## Non-Functional Requirements

> 측정 가능해야 함 — "빨라야 함" 금지. 환경 + 분위수 명시.

- **NFR-1**: 참가 현황 탭 첫 paint 300ms 이내 (에뮬레이터 baseline, p50, 캐시 hit 가정). blur 리스트 fetch 추가 시 500ms 이내 (p95).
- **NFR-2**: 개인정보 보호 — 표시 데이터는 나이대 범위(3~4세 폭) + 인증 유형명만. 구체 직장명·학교명·이름·사진 미노출. 그룹 3명 미만 시 빈 배열 반환으로 k-anonymity 보장.
- **NFR-3**: 다크모드 가독성 — color strip 컬러는 다크 배경 대비 4.5:1 이상. 프로그레스 바 트랙은 textSecondary 대비 명확히 구분.
- **NFR-4**: 나이대 분류는 한국 보편 표현(초반/중반/후반) + 3~4세 폭 (20대 초반: 20~23 / 중반: 24~26 / 후반: 27~29, 30대 동일 패턴).

## 화면 구성 (참고)

> dev 가 아닌 product/UX detail 만.

### 6.1 전체 합계 Summary Bar (신규)

```
┌─────────────────────────────────────┐
│ 👥 전체 참여  4 / 20                 │
│ ████████░░░░░░░░░░░░░░░░░░░░░░░░░░  │
└─────────────────────────────────────┘
```

- 섹션 최상단
- 프로그레스 바: 전체 참여율 시각화
- 색상: primary (#9900FF)
- 입장그룹 없는 이벤트에서도 표시

### 6.2 입장그룹 카드 (개선)

#### 레이아웃: 가로 스크롤

```
┌──────────────┐  ┌──────────────┐
│ 🔵 남성       │  │ 🩷 여성       │
│   3 / 10     │  │   2 / 10     │
│ ████████░░░░ │  │ █████░░░░░░░ │
└──────────────┘  └──────────────┘
        ← 가로 스크롤 →
```

| 항목 | 처리 |
|------|------|
| 2그룹 | 나란히, 스크롤 불필요 |
| 3그룹 이상 | 가로 스크롤. 오른쪽 카드 일부 잘림으로 어포던스 |
| 카드 상단 | color strip 3px |
| 프로그레스 바 | 연속 6px / radius 3px |
| 카운트 | "N / M" 20px bold 단일 표현 |

**그룹 색상 정책**:

| 그룹 유형 | 색상 | 코드 |
|----------|------|------|
| 남성 | Blue | `#60A5FA` |
| 여성 | Pink | `#F472B6` |
| 성별 무관 / 기타 | Primary | `#9900FF` |

> 한국 소셜 이벤트 도메인 보편 컨벤션. 차별적 의도 아닌 시각적 구분. 성별 무관은 primary 로 중립.

### 6.3 참여자 Blur 리스트 (신규)

#### 펼친 상태

```
┌──────────────┐  ┌──────────────┐
│ 🔵 남성       │  │ 🩷 여성       │
│   3 / 10     │  │   1 / 10     │
│ ████████░░░░ │  │ ██░░░░░░░░░░ │
│              │  │              │
│ 🔵 20대 후반  │  │ (3명 미만    │
│   · 직장인   │  │  비표시)      │
│ 🔵 30대 초반  │  │              │
│ 🔵 20대 중반  │  │              │
│   · 대학생   │  │              │
└──────────────┘  └──────────────┘
       참여자 정보 ▴    ← 단일 토글
```

#### 표시 정보 (blur 원칙)

| 항목 | 표시 | 비고 |
|------|------|------|
| 나이대 | ✅ | 초반 / 중반 / 후반 범위 |
| 인증뱃지 | ✅ (있을 때) | "직장인", "대학생" 등 유형명만 |
| 프로필 사진 | ❌ | blur 원칙 |
| 이름 / 닉네임 | ❌ | blur 원칙 |
| 성별 | ❌ | 이미 그룹으로 분리 |
| 지역 | ❌ | 이벤트 장소가 이미 공개 |
| 관심 태그 | ❌ | V1 제외 |

| 20대 중반 | 24~26세 | 3세 |
| 20대 후반 | 27~29세 | 3세 |

### 6.4 비로그인 상태 처리

```
┌──────────────────────────────────────┐
│  🔒 로그인하면 참여자 정보를 볼 수    │
│     있어요                            │
│            [로그인하기]                │
└──────────────────────────────────────┘
```

- 카운트 + 프로그레스는 공개 (소셜 프루프 유지)
- 카드 하단 로그인 CTA, primary 5% opacity 배경
- 탭 시 원래 이벤트 ID 보존 + 로그인 후 복귀

### 6.5 메타데이터 정책

| `show_participant_list` | 동작 |
|--------|------|
| `true` (기본값) | 카운트 + blur 리스트 모두 |
| `false` | 카운트만, blur 토글 숨김 |

> false 시 카운트까지 숨기지 않는 이유: 참가 결정에 최소 정보 보장.

### 6.6 다크모드 대응

- 카드 상단 color strip (3px) 으로 그룹 구분
- 카드 배경: `surfaceContainerLowest` (#1A1A1A)
- 프로그레스 트랙: `outlineVariant` (#3D3D3D)
- 텍스트: `text-primary` (#FFFFFF) / `text-secondary` (#AAAAAA)

## Functional Requirements

> 제품 행동 정의 — DB schema / 컴포넌트 이름 같은 dev detail 은 제외 (코드가 SSoT).

- **FR-1**: 체크인 화면 상단(AppBar 바로 아래)에 요약 카드 고정 — 높이 80px. 카메라 프레임은 250 → 220px 로 축소하여 공간 확보.
- **FR-2**: 요약 카드 내용 — (a) 큰 카운트 "N / M" (체크인 완료 / 발급 티켓) (b) 연속 프로그레스 바 (너비 100%, 높이 8px, success 컬러) (c) 우측 정렬 퍼센트 (d) 부가 정보 "진행중 · 남은 인원 N명" (12px, textSecondary).
- **FR-3**: QR 스캔 성공 시 참가자 정보 0.8초간 표시 — 유저명 / 엔트리 그룹 / 시간순 입장 번호 ("홍길동 · 남 20대 · 3번째 입장").
- **FR-4**: 스캔 성공 시 요약 카드 카운트 즉시 +1 (낙관적 업데이트). 서버 응답 실패 시 rollback.
- **FR-5**: 상단바에 새로고침 버튼 — stats 재조회. 네트워크 실패 시 카드에 "불러오기 실패 · 재시도" 링크. QR 스캔은 stats 실패와 독립적으로 정상 동작.
- **FR-6**: 화면 하단에 엔트리 그룹 시트 헤더 (40px) 고정 — "엔트리 그룹별 현황 ▲". pull-up gesture 또는 헤더 탭으로 풀 시트 확장.
- **FR-7**: 이벤트에 엔트리 그룹이 없으면 하단 시트 섹션 자체 숨김 (요약 카드만 노출).
- **FR-8**: 그룹별 row 노출 — 라벨 (예: "남 20대 초반", 16px w600) + 비율 ("N/M", 14px w500) + 프로그레스 바 (6px). 진행률 단계별 색상 — 0~50% primary, 50~90% warning, 90%+ error.
- **FR-9**: 카메라 프레임 아래 보조 컨트롤 row — [플래시 토글] + [수동 체크인 열기] 2개 버튼, 간격 16px, 44x44pt 터치 영역.
- **FR-10**: [수동 체크인] 탭 시 참가자 리스트 바텀시트 오픈 — 이름 검색 필드 + 참가자 row 리스트. row 별 체크인 토글로 처리.
- **FR-11**: 수동 체크인 토글 시 서버 업데이트 → 요약 카드 + 그룹 시트 자동 갱신. 토글 상태 변경 (체크인 완료 표시).
- **FR-12**: 플래시 토글 — 디바이스 플래시 ON/OFF. 버튼에 현재 상태 시각 표시 (아이콘 변경 + 라벨).
- **FR-13**: (P1) Realtime 구독 — 다른 디바이스 체크인 이벤트 수신 시 요약 카드 + 그룹 시트 자동 갱신. 화면 진입 시 구독 / 이탈 시 해제.
- **FR-14**: 에러 토스트 확장 — 중복 체크인: "이미 체크인됨 · HH:mm 입장" / 다른 이벤트 티켓 / 환불된 티켓: 각 사유 명시.
- **FR-15**: 발급 티켓 0건 이벤트는 요약 카드 "0 / 0" + 안내 메시지 + QR 스캐너 비활성.

## Non-Functional Requirements

> 측정 가능해야 함 — "빨라야 함" 금지. 환경 + 분위수 명시.

- **NFR-1**: 체크인 화면 첫 paint 300ms 이내 (에뮬레이터 baseline, p50). stats 로딩 중에는 shimmer placeholder. 카메라 활성화는 별도 측정.
- **NFR-2**: stats fetch + 카드 / 시트 렌더링 1s 이내 (p95, 정상 네트워크).
- **NFR-3**: 수동 체크인 토글 → 서버 응답 1s 이내 (p95). 응답 후 stats 갱신 추가 500ms (p95).
- **NFR-4**: (P1) Realtime 동기화 지연 — 다른 디바이스 체크인 → 본 디바이스 stats 갱신 5s 이내 (p95).
- **NFR-5**: 현장 가독성 — 카운트 폰트 32px+ / 카메라 뷰 어두운 배경 대비 카드 배경 명도 대비 7:1 이상. 야외 / 어두운 조명 환경 운영 고려.

## Open Questions

> 결정 못한 항목 — 1주 이상 방치 시 명시적으로 결정 또는 Non-Goal 로 이동.

- [ ] **수동 체크인으로 체크인 해제 가능 여부** — 운영자가 실수 정정 vs 1회 처리 후 불가 (감사 로그 필요)
- [ ] **요약 카드 탭 시 동작** — v1 무동작 vs v2 전체 참가자 리스트 화면 이동
- [ ] **하단 시트 초기 노출 상태** — 항상 헤더만 vs 첫 진입 시 1초간 펼침 안내
- [ ] **Realtime 끊김 시 사용자 노출** — 무알림 vs 토스트 vs 카드 표시
- [ ] **체크인 시각 (`checked_in_at`) 표시 형식** — HH:mm vs HH:mm:ss
- [ ] **참가자 정보 0.8초 표시 시 페이드** — 즉시 노출 vs 페이드 인/아웃
- [ ] **다른 스태프 동시 체크인 충돌 UI** — v2 multi-device 분리 PR

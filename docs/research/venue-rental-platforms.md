# Venue Rental Platforms — 한국 모임 공간 대여 플랫폼

> Partner workflow Step 2-3 (장소 대여 + 결제) 에서 사용되는 외부 플랫폼들. 향후 minglit이 API 연동을 검토할 후보 자산.

## 1. 스페이스클라우드 (SpaceCloud) — 시장 1위

| 항목 | 내용 |
|------|------|
| **포지션** | 생활공간대여 플랫폼 (1-2시간 단시간 이용 진입장벽 ↓) |
| **회원 수** | 누적 150만+ |
| **거래액** | 2020년 누적 400억원 |
| **카테고리** | 25개 유형 (파티룸, 연습실, 스튜디오, 카페, 컨퍼런스장, 공유오피스, 캠핑장 등) |
| **모델** | 시간 단위 대여 |
| **시작** | 2015년 |
| **앱** | iOS/Android 모두 |
| **URL** | https://www.spacecloud.kr/ |

### minglit 활용도
- **현재**: Partner가 직접 검색·예약 (외부, 미연동)
- **향후 후보**: API 연동으로 Event 등록 시 추천 공간 노출 + 예약 link → 모임 기획 마찰 ↓

## minglit 통합 검토 우선순위

1. **단기**: 자동화 X — Partner가 본인 외부 채널 사용. minglit Event 등록 시 venue 정보(주소·이름·링크)만 자유 입력
2. **중기**: 스페이스클라우드 검색 link 통합 (사용자 조회용 deep link 정도)
3. **장기**: API 연동 → Event 등록 시 자동 venue 추천 + 결제 통합 (Partner workflow 마찰 최대 ↓ 지점)

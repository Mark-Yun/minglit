# Competitive Landscape — 한국 로테이션 소개팅 시장

> minglit이 흡수/공략 대상으로 보는 기존 업체 분석. 데이터는 2025년 공개 자료 기반.

## 1. 감정적인 오렌지들 (Emotional Oranges) — 핵심 벤치마크

> minglit이 사실상 진행 모델을 그대로 차용. 가장 면밀히 분석할 가치 있는 업체.

| 항목 | 내용 |
|------|------|
| **시작** | 2022년 |
| **모델** | 12:12 티키타카 로테이션 소개팅 |
| **규모** | 전국 21개 지역, 매주 1,300명+ 참여 |
| **가격** | 일반: 28,000원 (정가 38,000원) / 프리미엄(한남 특집): 40,000원 (정가 65,000원) / 온라인 구독: 19,900원 |
| **신뢰 장치** | 입장 시 신분증 검사 |
| **수상** | 2025 SBS 생활의 달인 "소개팅 주선의 달인", 중앙일보 2025 소비자 만족도 대상 1위 |
| **사용자 평** | "치킨 한 마리 값에 이성 10명을 만난다" — 가성비 |

### minglit 시사점
- **진행 모델 검증됨** — 12:12 표준 규모, 신분증 검증 패턴은 우리 Identity Verification에 매핑됨
- **가격 reference**: 우리 4-6만원 가격대는 감정적인 오렌지 한남 특집(40-65K)과 유사 → 프리미엄 포지셔닝 가능
- **확장 모델 학습**: 21개 지역으로 빠르게 확장 → 우리 Partner 모델로 같은 효과를 더 빨리 (Partner들이 각 지역 운영)

## 2. 토크블라썸 (Talk Blossom)

| 항목 | 내용 |
|------|------|
| **모델** | 16:16 로테이션 소개팅 |
| **테마 분류** | 결혼희망, STAR, MVP |
| **참가 기준 (필수 1+)** | 직업/능력 인증 (대기업, 공기업, 전문직, 고액 연봉) / 재력 인증 (자가, 사업 매출) / 매력 인증 (비주얼, 다득표) |
| **인증 절차** | 결제 후 1일 이내 신원인증 (명함 등) → 확정자에게만 모임 하루 전 장소 공지 |
| **진행 시간** | 약 3시간 |
| **매칭** | 모임 종료 후 호감 닉네임 제출 → 당일 자정 전 매칭자 핸드폰번호 공유 |
| **타겟** | 20대 중반 ~ 30대 후반 직장인 |

### minglit 시사점
- **차별화된 인증 분류**: 직업/재력/매력 트로이카 → 우리 Qualification Verification 자유폼이 이 모델 수용 가능
- **테마별 큐레이션**: 결혼희망/STAR/MVP는 우리의 Party 컨셉화 패턴과 일치
- **흡수 전략**: 토크블라썸 자체가 1개 업체 운영 → minglit으로 옮기면 N개 Partner가 각자 같은 모델 운영 가능

### 채널

- 인스타: @talkblossom.co.kr
- Frip 입점: frip.co.kr/products/166484

## 3. 시장 시사점 종합

- **단일 업체 모델의 한계**: 두 업체 모두 자체 운영팀 + 자체 인프라 → 지역 확장 비용 큼
- **minglit 우위 가설**: Platform-of-platforms 모델로 Partner들이 minglit 인프라를 빌려 각자 운영 → 더 빠른 확장 + 더 다양한 컨셉
- **사용자 lock-in**: 감정적인 오렌지 사용자가 토크블라썸도 가려면 별도 가입/인증/결제 → minglit은 단일 신원으로 모든 Partner 이용

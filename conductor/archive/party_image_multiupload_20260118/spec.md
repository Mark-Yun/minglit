# 명세서: 파티 상세 이미지 다중 업로드 및 뷰어 구현

## 1. 개요
기존에 한 장만 등록 가능했던 파티 커버 이미지를 여러 장 등록할 수 있도록 개선합니다. 파트너는 여러 장의 이미지를 업로드하고 순서를 변경할 수 있으며, 유저는 상세 페이지에서 캐러셀(Carousel) 형태로 아름답게 이미지를 감상할 수 있습니다.

## 2. 주요 기능

### 2.1. 다중 이미지 업로드 및 편집 (`app_partner`)
- **다중 선택:** 이미지 피커에서 한 번에 여러 장의 이미지를 선택하여 업로드 가능.
- **순서 변경:** 업로드된 이미지 리스트를 드래그 앤 드롭으로 순서 변경 가능.
- **대표 이미지:** 리스트의 **첫 번째 이미지(`index 0`)**를 자동으로 대표 이미지(썸네일)로 사용.
- **삭제:** 개별 이미지 삭제 기능 제공.

### 2.2. 이미지 캐러셀 뷰어 (`app_user`, `app_partner`)
- **Carousel UI:** 좌우 스와이프가 가능한 슬라이더 구현.
- **페이지 인디케이터:** 현재 몇 번째 이미지인지 보여주는 점(Dot) 또는 숫자 인디케이터.
- **확대 기능:** 이미지 클릭 시 전체 화면으로 크게 볼 수 있는 라이트박스(Lightbox) 연동.

### 2.3. 데이터베이스 및 모델 (`minglit_kit`)
- **Schema:** `public.parties` 테이블에 `image_urls` (text[]) 컬럼 추가.
- **Migration:** 기존 `image_url` 데이터를 `image_urls` 배열의 첫 번째 요소로 이관하는 로직 포함.
- **Model:** `Party` 모델 업데이트 및 JSON 매핑 로직 수정.

## 3. 기술 요구사항
- **UI:** `smooth_page_indicator` (인디케이터용 패키지 검토)
- **DB:** PostgreSQL Array Type (`text[]`)
- **패키지:** `minglit_kit` 내 공용 캐러셀 위젯 구현.

## 4. 수락 기준

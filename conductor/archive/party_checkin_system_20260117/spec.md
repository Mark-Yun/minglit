# 명세서: 파티 체크인 및 오프라인 QR 시스템 (Party Check-in System)

## 1. 개요
유저 앱에서 오프라인 상태에서도 접근 가능한 QR 티켓을 제공하고, 파트너 앱에서 이를 스캔하여 체크인하는 시스템을 구축합니다. 복잡한 TOTP 대신 **Ed25519 서명 기반의 정적 QR**과 **화면 애니메이션**을 조합하여 적절한 보안성과 높은 사용자 경험을 제공합니다.

## 2. 주요 기능

### 2.1. 유저 앱 (Ticket Wallet)
- **오프라인 티켓 보관:** 발권된 티켓의 서명 데이터(Signed Token)를 로컬 보안 저장소(`FlutterSecureStorage`)에 캐싱합니다.
- **QR 생성:**
    - 데이터 포맷: `ticket_id` + `signature` (Ed25519)
    - 특징: 짧은 데이터 길이로 인식률 최적화.
- **캡처 방지 UX:**
    - QR 코드 위를 스캔하는 듯한 **움직이는 라인 애니메이션**.
    - 화면 밝기 자동 최대화.

### 2.2. 파트너 앱 (Scanner)
- **QR 스캐너:** 카메라를 통해 유저의 QR 코드를 스캔합니다.
- **온라인 검증:** 스캔된 데이터를 즉시 서버로 전송하여 유효성 및 중복 사용 여부를 확인합니다. (인터넷 연결 필수)
- **결과 피드백:**
    - ✅ **입장 허용:** 화면 전체가 **초록색**으로 변함 + 경쾌한 사운드/진동.
    - ❌ **이미 사용됨:** 화면 전체가 **빨간색**으로 변함 + 경고음 + "이미 체크인된 티켓입니다" 메시지.
    - ❌ **유효하지 않음:** 화면 전체가 **빨간색**으로 변함 + 경고음 + "위조된 티켓입니다" 메시지.

### 2.3. 백엔드 (Server)
- **티켓 발권 (Minting):** `Edge Function`에서 서버의 Private Key로 티켓 정보를 서명하여 반환.
- **체크인 API:** 서명 검증 및 `event_participants` 상태 업데이트 (`ticket_issued` -> `checked_in`).

## 3. 기술 스택
- **암호화:** Ed25519 (Libsodium / Dart `cryptography` 패키지)
- **QR 코드:** `qr_flutter` (렌더링), `mobile_scanner` (스캔)
- **로컬 저장소:** `flutter_secure_storage`

## 4. 수락 기준 (Acceptance Criteria)
- [ ] (유저) 비행기 모드에서도 "내 티켓" 화면 진입 및 QR 생성이 가능해야 함.
- [ ] (유저) QR 화면에 스캔 라인 애니메이션이 부드럽게 동작해야 함.
- [ ] (파트너) QR 스캔 시 1초 이내에 서버 검증 결과를 받아와야 함.
- [ ] (보안) 이미 사용된 QR을 다시 찍으면 "이미 체크인됨" 에러가 떠야 함.
- [ ] (보안) 임의로 조작된 QR 데이터는 "유효하지 않음"으로 거부되어야 함.

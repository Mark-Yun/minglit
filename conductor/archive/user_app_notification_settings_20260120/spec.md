# 명세서: 유저앱 알림 설정 화면 구현

## 1. 개요
유저가 앱 내에서 수신하고자 하는 알림의 종류를 직접 관리할 수 있는 설정 화면을 구현합니다. 사용자의 편의성을 높이고 불필요한 스팸성 알림을 방지하여 더 나은 사용자 경험을 제공하는 것이 목적입니다.

## 2. 주요 기능

### 2.1. 알림 설정 카테고리
- **파티 관련 알림:** 신청한 파티의 상태 변경(승인/반려), 결제 정보, 파티 마감 안내 등 핵심 서비스 알림.
- **이벤트 및 홍보성 알림:** 새로운 파티 추천, 마케팅 이벤트 소식, 혜택 안내 등.

### 2.2. 사용자 경험 (UX)
- **진입점:** 유저 앱 마이페이지(MyPage) 내 설정 메뉴를 통해 진입.
- **인터랙션:** 토글 스위치(Switch)를 사용하여 각 알림 설정을 끄고 켬.
- **동기화:** 토글 스위치 조작 시 즉시 서버 API를 호출하여 반영하는 실시간 동기화 방식 적용.

### 2.3. 데이터 관리
- **저장소:** Supabase 데이터베이스 (`user_settings` 또는 `users` 테이블의 `notification_settings` 필드).
- **영속성:** 서버에 저장하여 앱 재설치나 기기 변경 시에도 설정값이 유지되도록 구현.

## 3. 기술 설계
- **프론트엔드:** Flutter (Riverpod을 사용한 상태 관리 및 API 통신).
- **백엔드:** Supabase Auth & Database (RLS 정책을 통한 본인 데이터 접근 제한).

## 4. 수락 기준
- [ ] 마이페이지에서 알림 설정 화면으로 정상적으로 진입할 수 있음.
- [ ] 두 가지 카테고리(파티 관련, 이벤트/홍보성)에 대한 토글 버튼이 정상 작동함.
- [ ] 설정을 변경하면 서버 DB에 즉시 반영되고, 앱을 껐다 켜도 설정값이 유지됨.
- [ ] `flutter analyze` 결과 Zero Warning 유지.

## 5. 제외 범위
- 기기 시스템 레벨의 알림 권한 요청 (이는 앱 시작 시나 별도 로직에서 처리).
- 알림음 선택, 진동 설정 등 세부 커스터마이징 기능.

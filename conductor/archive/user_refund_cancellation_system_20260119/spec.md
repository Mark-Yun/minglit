# 명세서: 유저 환불 정책 및 취소 시스템 (User Refund & Cancellation System)

## 1. 개요
유저가 구매한 티켓을 자발적으로 취소할 때, 설정된 환불 정책(취소 시점별 수수료)에 따라 환불 예상 금액을 계산하여 보여주고, 동의 시 실제 결제 취소 API를 호출하여 환불을 처리합니다.

## 2. 주요 기능

### 2.1. 환불 정책 로직
- **정책 정의:**
    - 파티 시작 7일 전: 100% 환불.
    - 3일 전: 80% 환불.
    - 1일 전: 50% 환불.
    - 당일/이후: 환불 불가.
- **계산기:** `RefundCalculator` 클래스 구현.

### 2.2. 취소 UI (My Ticket)
- **버튼:** 티켓 상세 화면에 [예매 취소] 버튼 배치.
- **팝업:** 취소 시 예상 환불 금액과 수수료를 명확히 고지하는 다이얼로그(`MinglitDialog`).

### 2.3. 취소 실행 (Backend)
- **API:** `payment-cancel-v1` (기존 `cancel-payment` 리팩토링).
- **로직:**
    - `imp_uid`로 Iamport V1 취소 API 호출.
    - `amount` 파라미터로 부분 환불 금액 지정.
    - `tickets` 상태를 `cancelled`로 변경.

## 3. 기술 스택
- **Backend:** `payment-cancel-v1` (Edge Function).
- **External:** Iamport V1 Cancel API.

## 4. 수락 기준
- [ ] 취소 시점에 따른 정확한 환불 금액이 계산되어야 함.
- [ ] 유저가 동의하면 실제 결제 취소가 이루어지고 카드 승인 취소 문자가 와야 함.
- [ ] 티켓 상태가 '취소됨'으로 변경되어야 함.

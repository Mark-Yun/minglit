# 명세서: 파티 입장 성비 및 그룹 밸런스 자동 관리 (Party Balance System)

## 1. 개요
파티의 건전한 분위기와 매칭 품질을 위해 참여자들의 성비 및 그룹별 비율을 자동으로 조절하는 시스템입니다. 사장님에게는 단순한 "성비 자동 관리" 스위치를 제공하고, 백엔드에서는 `EntryGroup` 간의 예매 수량을 실시간으로 체크하여 티켓 구매 가능 여부를 동적으로 제어합니다.

## 2. 주요 기능

### 2.1. 밸런스 규칙 (Balance Logic)
- **비율(Ratio) 유지:** 설정된 그룹 간 비율(기본 1:1)을 벗어나지 않도록 제어.
- **오차 범위(Tolerance) 허용:** 너무 빡빡하지 않게 `N명` (기본 2명)까지는 불균형 허용.
- **로직:** `그룹A 현재원 / 그룹B 현재원` 비율이 허용 범위를 넘으면, 그룹A 티켓 판매 **"일시 중지(Locked)"**.

### 2.2. 파트너 앱 (사장님용)
- **간편 설정:** 파티 생성/수정 시 **"성비 균형 자동 관리" (ON/OFF)** 스위치 제공.
- **상세 설정 (Advanced):**
    - 허용 오차(Tolerance) 설정 (예: 1명 차이도 안 됨 vs 5명까지 괜찮음).
    - (추후 확장) 특정 연령대 그룹 간 비율 설정.

### 2.3. 유저 앱 (참여자용)
- **일시 품절 표시:** 밸런스 제한에 걸린 티켓은 "남성 매진 (여성 예매 시 오픈)" 같은 문구와 함께 비활성화.
- **대기 알림 (Waitlist):** 밸런스가 풀리면(반대 그룹이 들어오면) 푸시 알림 신청.

## 3. 데이터 모델 변경
- `parties` 테이블에 `balance_config` JSONB 컬럼 추가.
    - 예: `{"enabled": true, "ratio": "1:1", "tolerance": 2, "target_groups": ["male", "female"]}`

## 4. 기술 구현
- **트랜잭션 제어:** `apply_event` 함수 내에서 결제 전 밸런스 체크 로직 수행. (동시성 문제 방지)
- **실시간 상태:** 유저가 티켓 선택 화면에 들어올 때 `rpc`를 통해 현재 예매 가능한지 계산.

## 5. 수락 기준
- [ ] 사장님이 "성비 관리"를 켜면, 한쪽 성별만 계속 예매 시도 시 어느 순간 막혀야 함.
- [ ] 반대 성별이 예매를 하면, 막혔던 티켓이 다시 풀려야 함.
- [ ] 사장님 UI는 스위치 하나로 직관적이어야 함.

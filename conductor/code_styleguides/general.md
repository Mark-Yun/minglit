# 일반 코드 스타일 원칙

이 문서는 프로젝트에서 사용되는 모든 언어와 프레임워크에 적용되는 일반적인 코딩 원칙을 개괄합니다.

## 가독성
- 코드는 사람이 읽고 이해하기 쉬워야 합니다.
- 지나치게 기교를 부리거나 모호한 구조는 피하세요.

## 일관성
- 코드베이스의 기존 패턴을 따르세요.
- 일관된 포맷팅, 명명 규칙, 구조를 유지하세요.

## 단순성
- 복잡한 해결책보다 단순한 해결책을 선호하세요.
- 복잡한 문제는 작고 관리 가능한 부분으로 나누세요.

## 유지보수성
- 수정하고 확장하기 쉬운 코드를 작성하세요.
- 의존성과 결합도를 최소화하세요.

## 문서화
- 단순히 *무엇*을 하는지가 아니라 *왜* 그렇게 했는지를 문서화하세요.
- 코드 변경 사항에 맞춰 문서를 최신 상태로 유지하세요.

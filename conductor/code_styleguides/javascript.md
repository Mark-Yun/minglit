# Google JavaScript 스타일 가이드 요약

이 문서는 Google JavaScript 스타일 가이드의 주요 규칙과 모범 사례를 요약합니다.

## 1. 소스 파일 기본
- **파일 명명:** 모두 소문자, 밑줄(`_`) 또는 대시(`-`) 사용. 확장자는 반드시 `.js`여야 합니다.
- **파일 인코딩:** UTF-8.
- **공백:** ASCII 수평 공백(0x20)만 사용하세요. 들여쓰기에 탭 사용은 금지됩니다.

## 2. 소스 파일 구조
- 새 파일은 ES 모듈(`import`/`export`)이어야 합니다.
- **Export:** 명명된 내보내기(`export {MyClass};`)를 사용하세요. **기본 내보내기(default exports)를 사용하지 마세요.**
- **Import:** 줄 바꿈된 import를 사용하지 마세요. import 경로에 `.js` 확장자는 필수입니다.

## 3. 포맷팅
- **중괄호:** 모든 제어 구조(`if`, `for`, `while` 등)에 필수입니다. 한 줄 블록이라도 사용하세요. K&R 스타일("이집트 괄호")을 사용하세요.
- **들여쓰기:** 새 블록마다 +2 공백.
- **세미콜론:** 모든 문장은 세미콜론으로 끝나야 합니다.
- **열 제한:** 80자.
- **줄 바꿈:** 줄 바꿈된 줄은 최소 +4 공백 들여쓰기하세요.
- **공백:** 메서드 사이에는 빈 줄 하나를 사용하세요. 후행 공백은 없어야 합니다.

## 4. 언어 기능
- **변수 선언:** 기본적으로 `const`를 사용하고, 재할당이 필요한 경우 `let`을 사용하세요. **`var`는 금지됩니다.**
- **배열 리터럴:** 후행 쉼표를 사용하세요. `Array` 생성자를 사용하지 마세요.
- **객체 리터럴:** 후행 쉼표와 단축 속성을 사용하세요. `Object` 생성자를 사용하지 마세요.
- **클래스:** JavaScript getter/setter 속성(`get name()`)을 사용하지 마세요. 대신 일반 메서드를 제공하세요.
- **함수:** `this` 컨텍스트 보존을 위해 중첩 함수에는 화살표 함수를 선호하세요.
- **문자열 리터럴:** 작은따옴표(`'`)를 사용하세요. 여러 줄 문자열이나 복잡한 보간에는 템플릿 리터럴(`` ` ``)을 사용하세요.
- **제어 구조:** `for-of` 루프를 선호하세요. `for-in` 루프는 딕셔너리 스타일 객체에만 사용해야 합니다.
- **`this`:** 클래스 생성자, 메서드 또는 그 안에서 정의된 화살표 함수 내에서만 `this`를 사용하세요.
- **동등성 검사:** 항상 일치 연산자(`===` / `!==`)를 사용하세요.

## 5. 허용되지 않는 기능
- `with` 키워드.
- `eval()` 또는 `Function(...string)`.
- 자동 세미콜론 삽입(ASI).
- 내장 객체 수정 (`Array.prototype.foo = ...`).

## 6. 명명 규칙
- **클래스:** `UpperCamelCase`.
- **메서드 및 함수:** `lowerCamelCase`.
- **상수:** `CONSTANT_CASE` (대문자와 밑줄).
- **비상수 필드 및 변수:** `lowerCamelCase`.

## 7. JSDoc
- 모든 클래스, 필드, 메서드에 JSDoc을 사용합니다.
- `@param`, `@return`, `@override`, `@deprecated`를 사용하세요.
- 타입 주석은 중괄호로 감쌉니다 (예: `/** @param {string} userName */`).

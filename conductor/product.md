# Product Guide

## Initial Concept
Minglit is a verification-based blind meeting service designed to provide a safe and trustworthy environment for singles. It operates on a dual-user model, serving both general users seeking connections and partners who organize events.

## Target Audience
- **General Users:** Singles looking for verified, safe, and exciting blind meeting experiences.
- **Partners:** Venue owners and event organizers who want to host parties, manage events, and verify attendees.

## Core Goals
- **Safety & Trust:** Establish a secure environment through rigorous identity verification.
- **Partner Empowerment:** Provide tools for partners to create, manage, and monetize their own events.
- **Automation:** Streamline the verification process using identity providers like PASS/SMS.
- **Engagement:** Enable partners to attract and engage a broader user base from the platform.
- **Personalization:** Deliver high-quality event discovery through AI-driven recommendation systems.

## Key Features

### For General Users
- **Blind Meeting Matching:** Intelligent matching system based on verified user data.
- **Identity Verification:** Seamless integration with PASS/SMS for identity confirmation.
- **Event Participation:** Ability to browse and purchase tickets for partner-hosted events.
- **AI Curation:** Personalized event recommendations based on user behavior (views, likes, purchases).

### For Partners
- **Event Management:** Comprehensive wizard for creating and managing parties and events.
- **User Qualification:** System for reviewing and approving user qualifications for specific events.
- **Ticket Management:** Tools for issuing tickets and managing ticket templates.
- **User Engagement:** Features designed to help partners reach and engage more users from the Minglit platform.

# 명세서: 유저 앱 알림 설정 화면 연동 (User App Notification Settings Integration)

## 1. 개요
유저가 앱 내 알림 수신 여부를 직접 제어할 수 있는 '알림 설정' 화면을 구현하고 마이페이지에 연동합니다. 설정값은 서버 DB(`user_settings` 테이블)와 동기화되어, 실제 푸시 알림 발송 시 유저의 설정이 반영되도록 합니다.

## 2. 주요 기능

### 2.1. 진입점
- **마이페이지:** 마이페이지 메뉴 리스트에 '알림 설정' 항목을 추가하여 진입합니다.

### 2.2. 설정 항목
다음 항목에 대한 ON/OFF 토글 스위치를 제공합니다:
- **마케팅 정보 수신 동의:** 이벤트 프로모션 등 광고성 정보 수신 여부.
- **서비스 알림:** 예약, 매칭 등 앱의 일반 푸시 알림 수신 여부.

### 2.3. 데이터 동기화
- **저장소:** Supabase DB 테이블 `user_settings`에 설정값을 저장합니다.
- **로직:**
    - 화면 진입 시 DB에서 최신 설정값을 불러와 UI에 반영합니다.
    - 토글 변경 시 `AsyncNotifier`를 통해 DB에 업데이트 쿼리를 보냅니다.
    - `Optimistic UI`를 적용하여 사용자가 스위치를 조작할 때 지연 없이 반응하도록 합니다.

## 3. 기술 스택
- **Frontend:** Flutter (Riverpod)
- **Shared Kit:** `minglit_kit` (Notification Repository & Controller)
- **Backend:** Supabase (Table Update)

## 4. 수락 기준
- [ ] 마이페이지에서 '알림 설정' 메뉴를 눌러 설정 화면으로 이동할 수 있다.
- [ ] '마케팅 수신 동의'와 '서비스 알림' 토글이 정상적으로 표시되고 작동한다.
- [ ] 토글 변경 시 DB에 값이 업데이트되어야 하며, 앱 재실행 시에도 설정이 유지되어야 한다.
- [ ] 에러 발생 시 원래 상태로 복구되고 사용자에게 알림이 표시된다.

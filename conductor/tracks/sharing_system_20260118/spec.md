# Specification: Sharing System (`sharing_system_20260118`)

## Overview
유저가 밍글릿의 이벤트 정보를 친구나 외부 채널에 쉽게 공유할 수 있도록 다이내믹 링크 기반의 공유 기능을 구현합니다. OS 표준 공유 시트를 사용하여 다양한 플랫폼으로의 전송을 지원합니다.

## Functional Requirements
- **공유 콘텐츠 구성:** 파티/이벤트의 제목과 접속 가능한 링크를 포함합니다.
- **공유 방식:** Native OS Share Sheet(`share_plus` 패키지)를 활용하여 모바일 OS의 표준 공유 UI를 호출합니다.
- **다이내믹 링크 지원:**
  - 웹과 앱을 자동으로 판별하여 적절한 환경으로 연결합니다.
  - 앱 미설치 유저에게는 앱 스토어 설치를 유도하거나 웹 뷰로 연결합니다.
- **노출 위치:** 사용자 앱의 이벤트 상세 뷰(`EventDetailView`)에 공유 버튼을 배치합니다.

## Non-Functional Requirements
- **안정성:** 공유 기능 실행 시 앱이 멈추거나 비정상 종료되지 않아야 합니다.
- **사용성:** 한 번의 탭으로 공유 시트가 즉각적으로 응답해야 합니다.

## Acceptance Criteria
- [ ] 이벤트 상세 페이지에 공유 버튼이 정상적으로 표시된다.
- [ ] 버튼 클릭 시 OS 표준 공유 시트가 나타난다.
- [ ] 생성된 링크를 통해 접속 시 해당 이벤트 상세 페이지로 정확히 랜딩된다.
- [ ] 공유된 텍스트에 이벤트 제목이 포함되어 있다.

## Out of Scope
- 카카오톡 직접 공유 SDK 연동 (추후 고도화 예정)
- 파트너 앱 내의 공유 기능

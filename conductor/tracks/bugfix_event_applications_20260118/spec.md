# 명세서: 주요 버그 수정: 파티 신청 및 디테일 데이터 오류

## 1. 개요
파트너 앱의 이벤트 디테일 페이지에서 발생하는 두 가지 치명적인 버그를 수정합니다.
1.  **Issue #5 (Crash):** '참가 신청' 탭 또는 버튼 클릭 시 `TypeError`로 인한 앱 크래시.
2.  **Issue #6 (Data Error):** 참가 신청자가 있음에도 불구하고 '0명'으로 표시되는 문제.

## 2. 문제 원인 분석
- **원인:** 해당 UI 코드가 파티 신청 시스템 개편 전의 레거시 로직을 사용하고 있거나, 잘못된 리포지토리/쿼리를 참조하고 있음.
- **증상:** DB 쿼리 결과 타입 불일치(`List` vs `Map`) 및 데이터 매핑 실패.

## 3. 해결 방안 (Scope)

### 3.1. UI/Logic 리팩토링 (`app_partner`)
- **타겟:** `EventDetailScreen` 또는 관련 탭 위젯.
- **작업:**
    - 기존의 잘못된 데이터 조회 로직을 제거.
    - 최신 `EventRepository` 또는 `EventApplicationController`를 사용하여 올바른 신청자 데이터를 가져오도록 수정.
    - 데이터 타입(`List<EventApplication>`)을 정확히 처리하여 크래시 방지.

### 3.2. 검증 (Verification)
- **TDD 접근:**
    1.  **Unit Test:** `app_partner`의 관련 컨트롤러에 대해 데이터 로드 실패/성공 케이스 테스트 작성.
    2.  **Integration Test:** `integration_scenario_tester`를 통해 실제 신청 데이터가 파트너 앱에서 올바르게 조회되는지 검증.

## 4. 수락 기준 (Acceptance Criteria)
- [ ] 파트너 앱에서 이벤트 디테일 진입 및 '참가 신청' 탭 이동 시 크래시가 발생하지 않아야 함.
- [ ] 실제 신청자가 있는 경우, 정확한 인원수와 리스트가 표시되어야 함.
- [ ] 관련 단위 테스트 및 통합 시나리오 테스트가 모두 통과해야 함.
